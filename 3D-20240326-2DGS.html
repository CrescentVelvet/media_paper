1论文摘要与定位

2D Gaussian Splatting (2DGS) 是高斯泼溅路线从"渲染"迈向"几何准确重建"的里程碑工作。3DGS 虽以可微光栅化实现实时新视角合成,却因 3D 高斯的多视角不一致性而无法准确表示表面。2DGS 的核心主张是:将 3D 体积塌缩为一组 2D 定向平面高斯盘(oriented planar Gaussian disks),每个盘内嵌于 3D 空间、原生具备法线,从而在本质上是表面元素(surfel),保证不同视角下对同一原语求值一致。

论文三大贡献:(1) 以齐次坐标 ray-splat intersection 实现 perspective-correct 2D splatting,避免 3DGS 仿射近似的边缘深度失真;(2) 引入 深度畸变损失 与 法线一致性损失 推动高斯在射线上聚拢、与渲染深度法线自洽;(3) 演示该可微渲染器可恢复无噪声、细节丰富的几何,外观与 3DGS 打平,训练快、渲染实时。

2研究背景与动机:3DGS 的几何缺陷

3DGS 以各向异性 3D 高斯椭球体表示场景,渲染时用仿射矩阵 J 把 3D 协方差投影到 ray space 再做 alpha blending。这一"近似可微渲染"(Keselman & Hebert 2023)在渲染上够好,但在几何上存在四连击缺陷。论文 §3 明确列出:

① 体积-表面冲突

3D 高斯把辐辐度建模在一个"团块"立体里,与表面"薄"的本质相矛盾——同一表面被一团带体积的高斯拟合,几何厚度不为零。

② 多视角不一致(致命)

同一 3D 高斯在不同视角下,与不同的 2D 相交平面求值,导致渲染深度视角间不一致。直接从 3DGS 抽 mesh 会出现层叠伪影。

③ 无法原生建模法线

3DGS 原语没有法线概念,而高质量表面重建依赖法线约束。法线只能事后从协方差特征向量近似,不稳定。

④ 仿射投影近似误差:用 Σ' = J W Σ Wᵀ Jᵀ 把 3D 高斯变换到 ray space 只在高斯中心附近准确,边缘存在透视失真(Zwicker 2004),违反法线一致性,在薄结构处尤其明显。

图1(论文 Fig.2) 左:3DGS 在不同视角用不同 2D 相交平面评估同一 3D 高斯,渲染深度多视角不一致;右:2DGS 的 2D 盘内蕴法线,任意视角下求值一致。

2DGS 的解法:把 3D 体积"塌缩"成 2D 定向盘——第三维缩放强制为 0,法线定义为两切向量叉积 t_w = t_u × t_v。2D 盘本质即 surfel,天然对齐薄表面;用显式 ray-splat 求交替代仿射近似,保证多视角一致;内蕴法线可直接作为正则约束。与经典 surfel 方法(Pfister 2000, Zwicker 2001, DSS/Yifan 2019)的区别在于:2DGS 不需要稠密点云或 GT 法线,仅凭 SfM 稀疏点 + 光度监督即可端到端梯度优化。

3算法总体框架:2D 定向盘 + 三阶段

2DGS 继承 3DGS 的"可微光栅化 + 自适应密度控制"骨架,但把原语从 3D 椭球换成 2D 盘,并扩展光栅器同时输出 颜色图 / 深度图 / 法线图 供正则使用。整体可视为三阶段:

阶段一

2D 高斯参数化

每个高斯由中心 p、两切向量 t_u,t_v(叉积得法线)、缩放 s_u,s_v(第三维=0)、不透明度 α、球谐 SH 外观定义。

阶段二

透视正确光栅化

齐次坐标下用 ray-splat intersection 求像素射线与 2D 盘的交点 (u,v),算深度 z 与高斯值;低通滤波兜底退化;前向 alpha blending 出颜色/深度/法线。

阶段三

正则 + TSDF 提网格

深度畸变损失 + 法线一致性损失约束几何;训练完后渲染多视角深度图,用 truncated TSDF fusion(+ median depth)融合成 mesh。

关键关系:2D 原语本身解决"多视角一致 + 内蕴法线";ray-splat 求交解决"透视正确";两个正则解决"表面聚拢与自洽";TSDF 解决"mesh 化"。四者缺一不可,消融见第 11 节。

42D 高斯表示的数学形式化

每个 2D 高斯(论文 §4.1, Eq.4–6)由以下可学习参数定义:中心点 $\mathbf{p}_k \in \mathbb{R}^3$;两个切向量 $\mathbf{t}_u, \mathbf{t}_v$(构成旋转矩阵 $\mathbf{R}=[\mathbf{t}_u,\mathbf{t}_v,\mathbf{t}_w]$,法线 $\mathbf{t}_w=\mathbf{t}_u\times\mathbf{t}_v$);缩放 $\mathbf{S}=\mathrm{diag}(s_u,s_v,\mathbf{0})$(第三维强制 0,即"塌缩");不透明度 $\alpha$;球谐外观 $c$(代码 sh_degree=3)。

局部切平面参数化(Eq.4–5)

$$P(u,v)=\mathbf{p}_k+s_u\mathbf{t}_u\,u+s_v\mathbf{t}_v\,v=\mathbf{H}(u,v,1,1)^\top$$ $$\mathbf{H}=\begin{bmatrix}s_u\mathbf{t}_u & s_v\mathbf{t}_v & \mathbf{0} & \mathbf{p}_k\\0&0&0&1\end{bmatrix}=\begin{bmatrix}\mathbf{R}\mathbf{S}&\mathbf{p}_k\\\mathbf{0}&1\end{bmatrix}$$ (式 4–5)

2D 高斯密度(Eq.6)

$$\mathcal{G}(\mathbf{u})=\exp\!\left(-\frac{u^2+v^2}{2}\right)$$ (式 6)

设计要点:2DGS 不显式写世界空间协方差 $\boldsymbol{\Sigma}^{-1}$(与 3DGS 不同),而是通过 $\mathbf{H}$ 矩阵隐式定义切平面几何,密度直接在局部 $uv$ 坐标用标准高斯求值。法线由切向量叉积得到,而非协方差特征向量——更稳定、更直观。

5渲染:透视正确的 2D 泼溅

5.1 齐次坐标下的世界→屏幕投影(Eq.7)

设 $\mathbf{W}\in\mathbb{R}^{4\times4}$ 为世界到屏幕的组合变换,屏幕齐次点:

$$\mathbf{x}=(xz,yz,z,z)^\top=\mathbf{W}\,P(u,v)=\mathbf{W}\mathbf{H}(u,v,1,1)^\top$$ (式 7)

$\mathbf{x}$ 表示一条从相机出发、过像素 $(x,y)$、在深度 $z$ 处与 splat 相交的齐次射线。

5.2 Ray-splat intersection(Eq.8–10,核心创新)

Zwicker 原方案用 $\mathbf{M}=(\mathbf{W}\mathbf{H})^{-1}$ 隐式投影 conic,但逆矩阵在 splat 退化为线段(侧视)时数值不稳定——传统做法是阈值丢弃,这在可微渲染里会让优化抖动。2DGS 改用 Sigg 2006 / Weyrich 2007 启发的显式三平面求交:

把像素 $(x,y)$ 的射线参数化为两个正交齐次平面:x-plane $\mathbf{h}_x=(-1,0,0,x)^\top$、y-plane $\mathbf{h}_y=(0,-1,0,y)^\top$。用 Blinn 1977 的 $\mathbf{M}^{-\top}$ 法则把平面变到 splat 局部 $uv$ 坐标(对点用 $\mathbf{M}$ 等价于对平面参数用 $\mathbf{M}^{-\top}$,从而避免显式矩阵求逆):

$$\mathbf{h}_u=(\mathbf{W}\mathbf{H})^\top\mathbf{h}_x,\qquad \mathbf{h}_v=(\mathbf{W}\mathbf{H})^\top\mathbf{h}_y$$ (式 8–9)

交点须同时落在两个变换后的平面上,解出:

$$u(\mathbf{x})=\frac{\mathbf{h}_u^2\mathbf{h}_v^4-\mathbf{h}_u^4\mathbf{h}_v^2}{\mathbf{h}_u^1\mathbf{h}_v^2-\mathbf{h}_u^2\mathbf{h}_v^1},\qquad v(\mathbf{x})=\frac{\mathbf{h}_u^4\mathbf{h}_v^1-\mathbf{h}_u^1\mathbf{h}_v^4}{\mathbf{h}_u^1\mathbf{h}_v^2-\mathbf{h}_u^2\mathbf{h}_v^1}$$ (式 10)

拿到 $(u,v)$ 后,代入式 7 算深度 $z$,代入式 6 算高斯值。

5.3 退化处理 + 低通滤波(Eq.11)

侧视时 2D 高斯在屏幕上退化成线段,可能被光栅化漏掉。用 Botsch 2005 的 object-space 低通滤波兜底:

$$\hat{\mathcal{G}}(\mathbf{x})=\max\!\left\{\mathcal{G}(\mathbf{u}(\mathbf{x})),\;\mathcal{G}\!\left(\frac{\mathbf{x}-\mathbf{c}}{\sigma}\right)\right\},\quad \sigma=\tfrac{\sqrt{2}}{2}$$ (式 11)

工程权衡:$\sigma=\sqrt{2}/2$ 是固定经验值。在薄结构(植物叶、毛发)处仍可能漏渲或 banding,这是 2DGS 的固有脆弱点,也是后续 Mip-Splatting 式自适应滤波的改进入口(见 §12 改进 3)。

5.4 前向 alpha blending(Eq.12)

$$\mathbf{c}(\mathbf{x})=\sum_{i=1}^{K}\mathbf{c}_i\,\alpha_i\,\hat{\mathcal{G}}_i(\mathbf{u}(\mathbf{x}))\prod_{j=1}^{i-1}\bigl(1-\alpha_j\hat{\mathcal{G}}_j(\mathbf{u}(\mathbf{x}))\bigr)$$ (式 12)

按中心深度排序、分 tile、前向 alpha-blending,累积不透明度饱和时提前终止(同 3DGS)。深度图、法线图以同样累积方式渲染,供正则使用。

与 3DGS 投影对比:3DGS 用 $\boldsymbol{\Sigma}'=\mathbf{J}\mathbf{W}\boldsymbol{\Sigma}\mathbf{W}^\top\mathbf{J}^\top$ 仿射近似,删第 3 行 3 列得 2D 协方差;2DGS 用齐次坐标显式 ray-splat 求交。论文 Fig.7 直观显示仿射近似在边缘产生深度失真、违反法线一致性。

图2(论文 Fig.7) 仿射近似 vs 透视正确 ray-splat:边缘处仿射近似的深度失真导致法线不一致,2DGS 的显式求交避免此问题。

6训练与自适应控制

继承 3DGS 的 CUDA 自定义算子框架,基于 hbb1/diff-surfel-rasterization 光栅器扩展输出 depth distortion / depth / normal 三张图供正则。初始化用 SfM(COLMAP)稀疏点云。

自适应密度控制(Densification,与 3DGS 的关键差异)

由于 2DGS 不直接依赖"投影后 2D 中心的梯度",它把 3D 中心 $\mathbf{p}_k$ 的梯度投影到屏幕空间作为近似——这是 2DGS 在 densification 上对 3DGS 做的工程妥协,也是 §7 Limitations 中"densification 偏向纹理丰富区"的根因(见 §12 改进 1)。

7正则化损失与总损失

7.1 深度畸变损失 Depth distortion(Eq.13)

3DGS 体渲染忽略高斯原语之间的距离,沿射线分散的高斯可能产生相同颜色和深度,不像表面渲染那样"射线恰好击中可见表面一次"。借鉴 Mip-NeRF360,但关键区别:Mip-NeRF360 的 $z_i$ 是预定义采样点不可优化,2DGS 的 $z_i$ 是 ray-splat 交点的深度可微,直接推动 splat 在射线上聚拢。

$$\mathcal{L}_d=\sum_{i,j}\omega_i\omega_j\,|z_i-z_j|,\qquad \omega_i=\alpha_i\hat{\mathcal{G}}_i\prod_{j=1}^{i-1}(1-\alpha_j\hat{\mathcal{G}}_j)$$ (式 13)

CUDA 实现细节(附录 A,式 17):由于交点深度可能不按顺序,采用 $\mathcal{L}_2$ 形式并把 $z$ 转到 NDC 空间($m=\mathrm{NDC}(z)$,near=0.2/far=1000)以降权远处高斯。把嵌套求和重排为单次前向:令 $A_i=\sum_{j\le i}\omega_j$、$D_i=\sum_{j\le i}\omega_j m_j$,则 $e_i=m_i^2 A_{i-1}+D_{i-1}^2-2m_iD_{i-1}$,$\mathcal{L}_i=\sum_{j\le i}\omega_j e_j$。marching front-to-back 累加 $A_i,D_i$,梯度 back-to-front 反传——这是 2DGS 光栅器扩展的核心算法工程。

7.2 法线一致性损失 Normal consistency(Eq.14–15)

在体渲染中,把累积不透明度达到 0.5 的中位交点 $\mathbf{p}_s$ 视为真实表面位置,让 splat 法线对齐渲染深度图的梯度法线:

$$\mathcal{L}_n=\sum_i\omega_i\bigl(1-\mathbf{n}_i^\top\mathbf{N}\bigr),\qquad \mathbf{N}(x,y)=\frac{\nabla_x\mathbf{p}_s\times\nabla_y\mathbf{p}_s}{|\nabla_x\mathbf{p}_s\times\nabla_y\mathbf{p}_s|}$$ (式 14–15)

直觉:让"高斯自己定义的法线 $\mathbf{n}_i$"与"渲染深度反推的法线 $\mathbf{N}$"一致,从而深度与法线两套几何自洽。Fig.6 显示:关掉 normal consistency → 法线方向错乱;关掉 depth distortion → 表面噪声;两者都开 → 锐利且平坦。

图3(论文 Fig.6) 正则化消融:关闭法线一致性 → 法线错乱;关闭深度畸变 → 表面噪声;两者全开 → 锐利平坦。

8网格提取:TSDF + median depth

方法:Truncated TSDF fusion(基于 Open3D),不是 Poisson、不是双边滤波。流程:渲染训练视角深度图 → TSDF 融合成 mesh。关键参数(§6.1):体素大小 0.004、截断阈值 0.02。

深度用 median depth(Eq.19)而非 mean/expected depth:

$$z_{\text{median}}=\max\{z_i\mid T_i>0.5\}$$ (式 19)

即累积透射率降到 0.5 之前的最大深度,比 mean/expected 对离群点更鲁棒(消融:+0.11 mm)。法线来源:2D 高斯自带 $\mathbf{t}_w$ 法线,但 mesh 提取阶段实际只用深度图做 TSDF;法线一致性损失已在训练阶段让深度法线与高斯法线对齐,因此隐式保证 TSDF 输入深度质量。

Unbounded mesh(后续更新,README "2024/05/05"):对无界场景(Mip-NeRF360)用空间收缩(space contraction)+ 自适应 TSDF 截断,命令 python render.py -m <model> -s <data> --unbounded --skip_train --skip_test --mesh_res 1024。

12可改进方向分析(代码佐证)

本节从方法、数据与评估、工程实用性三个维度分析 2DGS 的可改进方向,每点附论文/代码佐证与改进建议。

[高优先级] 改进 1 · 方法层面

Densification 对"几何-纹理"偏差的根治

问题:论文 §7 Limitations 自承"densification favors texture-rich over geometry-rich areas",导致薄结构和弱纹理区几何差。根因:2DGS 复用 3DGS 的"投影 2D 中心梯度"近似作为 densification 信号(§6.1),而该信号本质是光度梯度,几何欠拟合区(如平面白墙)梯度小、不被 densify。

代码佐证:arguments/__init__.py 的 densify_grad_threshold = 0.0002 与 3DGS 同源,无几何感知项。

建议:引入几何不确定性引导的 densification——基于渲染深度残差(多视角深度一致性)、法线方差或 SDF 距离场作为补充 densify 信号;或用体素锚点(Scaffold-GS 思路)在几何稀疏区强制 densify。这是 2DGS 留给后续 GOF/Scaffold-2DGS 等工作的最大接口。

[高优先级] 改进 2 · 方法层面

半透明 / 反射 / 玻璃表面的物理建模

问题:Limitations 第 1 条明确:假设完全不透明表面,玻璃等半透明表面无法处理(附录 Fig.12)。2D 盘只有单一 $\alpha$,无法表达透射/折射。

建议:引入透射率 $\tau$ 与折射法线(GaussianShader / GS-IR 思路)或神经 BRDF 分解;对透明表面用多高斯层叠加(前景+背景),TSDF 阶段对半透明区域跳过融合或用概率占用。

图4(论文 Fig.12) 半透明/玻璃表面是 2DGS 的明确局限:假设完全不透明,无法处理透射/折射。

[中优先级] 改进 3 · 方法/工程

ray-splat intersection 在大倾角/极薄结构的退化鲁棒性

问题:式 10 分母 $\mathbf{h}_u^1\mathbf{h}_v^2-\mathbf{h}_u^2\mathbf{h}_v^1$ 在 splat 接近平行视线时趋于 0;式 11 低通滤波兜底,但 $\sigma=\sqrt{2}/2$ 是固定经验值,薄结构(叶、毛发)仍可能漏渲或 banding。

代码佐证:§4.2 "Degenerate Solutions" 坦承阈值丢弃在可微框架下不稳定,改用 max 低通,但 $\sigma$ 固定。

建议:$\sigma$ 自适应于 splat 屏幕投影面积(类 Mip-Splatting 的 2D Mip filter);或改用可微 ray-tracing(社区 diff-surfel-tracing by xbillowy 可参考);对极薄结构引入多尺度 splat。

[中优先级] 改进 4 · 数据/评估

TnT 大场景上对 SDF 方法的追赶

问题:Table 2 显示 2DGS TnT mean F1=0.32,落后 Neuralangelo(0.50)达 0.18,尤其 Barn(0.41 vs 0.70)、Ignatius(0.51 vs 0.89)差距大。根因:大场景 densification 不充分 + TSDF 截断阈值固定 0.02 不适配多尺度。

代码佐证:Mesh 提取 voxel_size=0.004, depth_trunc=0.02 全局固定;无界 mesh 用空间收缩但仍不及 SDF 全局优化。

建议:多尺度 TSDF(近场细体素 + 远场粗体素);引入 SDF 一致性损失(让 2D 盘对齐隐式 SDF,类 NeuSG 但保持 2D 原语);或对大场景做分块重建 + 融合(VOP-GS 思路)。

[低优先级] 改进 5 · 工程

lambda_dist 默认值与文档一致性

问题:arguments/__init__.py 中 lambda_dist = 0.0(关闭深度畸变),而论文结果在 $\alpha=1000$ 下取得;README 文档写成 --lambda_distortion(实际 flag 是 --lambda_dist)。新用户直接 python train.py 会得到几何退化的模型,且参数名找不到。

代码佐证:OptimizationParams.lambda_dist = 0.0,PipelineParams.depth_ratio = 0.0(DTU 需手动设 1)。

建议:把 lambda_dist 默认改为场景自适应(检测有界/无界自动设 1000/100);修正 README 文档;train.py 启动时打印当前正则权重警告。低成本、高用户体验收益。

132DGS 是否过时?更先进的方法辨析

这是用户的核心问题。结论是分场景:作为"DTU/TnT 纯表面重建 SOTA 刷榜方法"已在 2024 下半年被取代;作为"2D 定向盘 + 深度/法向正则"的范式奠基者与轻量可微分几何前端,2026 年仍有不可替代价值。

13.1 关键后继:GOF — Gaussian Opacity Fields ★

GOF(arXiv 2404.10772,SIGGRAPH Asia 2024 / ACM TOG)是 2DGS 同实验室同作者(Zehao Yu, Andreas Geiger — 图宾根 + Tübingen AI Center)的官方后继。它用射线-高斯相交的体渲染建立"高斯不透明度场",对其 level-set 用 Marching Tetrahedra 直接提网格,摒弃 2DGS 依赖的 TSDF/Poisson 后处理;并直接复用 2DGS 的深度畸变 + 法向一致性正则。

GOF 项目页原文:"2DGS fails to reconstruct background geometry, while our method can reconstruct more detailed geometry for both foreground objects and backgrounds"。GOF 在 2DGS 自己的强项(几何质量)上全面超越,且来自同实验室同作者——这是让 2DGS 在"纯表面重建 SOTA 榜单"上过时的决定性方法。代价:训练更慢、需自定义 CUDA ray-tracing 内核。

最终判断:

① 过时成立的部分:作为"在 benchmark 上刷几何质量"的方法,2DGS 自 2024 下半年已被同实验室的 GOF 取代(DTU 0.80→0.74、TnT 0.32→0.46),2026 年又被 Gaussian Wrapping / SOF / GSPrior 进一步推远。

② 未过时的部分:作为"2D 定向盘 + 深度/法向正则"的范式奠基者——其提出的深度畸变 + 法向一致性正则被 GOF 直接复用,2D 盘思想被 PGSR/GaussianSurfels 及几乎所有 surfel 系(SLAM/4D/avatar/IR)继承——它已是基础设施而非可丢弃的旧物。同时轻量与简洁(纯 2D 盘、无需 ray-tracing CUDA 内核、无需 Marching Tetrahedra、训练 10.9 min vs GOF 18.4 min)使其在资源受限、教学/原型、或作为更大系统的可微分前端时仍是合理选择。

③ 推荐主线:3DGS → 2DGS(范式奠基/轻量)→ GOF(同实验室后继,几何超越)→ Gaussian Wrapping / SOF / GSPrior(2026 新一代),并按场景向 surfel-SLAM / 4D / avatar 分支演化。

14总结

2DGS 把高斯泼溅从"渲染优先"推进到"几何准确":以 2D 定向盘解决多视角不一致与内蕴法线,以 ray-splat 求交解决透视正确,以深度畸变+法线一致性正则解决表面聚拢与自洽,以 TSDF + median depth 解决 mesh 化。在 DTU 上 CD 0.80(比 3DGS 降 59%)、存储 52MB、训练 10.9 min,确立了"轻量几何准确辐射场"的范式。

2DGS 的历史地位

① 范式奠基者:深度畸变 + 法向一致性正则被 GOF 直接复用;② 2D 盘思想被 PGSR/GaussianSurfels 及 surfel-SLAM/4D/avatar/IR 大量继承;③ 轻量基准:纯 2D 盘、无 ray-tracing 内核、训练快。

2DGS 的局限与被超越

① 大场景 TnT 落后 SDF(0.32 vs 0.50);② 半透明/玻璃无法处理;③ densification 偏向纹理区;④ 同实验室后继 GOF 在 DTU/TnT 双双超越(0.74/0.46),2026 年 Gaussian Wrapping 等进一步推远。

一句话:2DGS 作为"几何 SOTA 刷榜方法"在 2024 下半年已被 GOF 取代、2026 年又被 Gaussian Wrapping 等推远——在此意义上"过时"成立;但作为"2D 定向盘 + 深度/法向正则"的范式奠基者与轻量可微分几何前端,其思想正被 SLAM/4D/数字人/逆向渲染等大量 2025–2026 顶会工作沿用,2026 年仍有不可替代价值。
