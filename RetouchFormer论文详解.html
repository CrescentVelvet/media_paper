1.1 任务定义

人脸修图（Face Retouching）是在保留图像内容的前提下美化人脸——去除面部瑕疵（痘印、斑点、皱纹等）并用正常皮肤填充。

1.2 核心问题

问题说明
缺乏瑕疵定位通用图像增强方法无法准确定位瑕疵区域，导致大尺度斑点去除不完整
依赖配对数据现有方法需要大量"修图前-修图后"配对训练数据，获取成本高
内容保真度不足简单修复方法可能在去除瑕疵的同时改变正常皮肤纹理

二、核心创新概述

创新一：将人脸修图建模为"软修复"任务

将人脸修图视为图像修复（inpainting）的广义"软"版本——同时识别瑕疵并合成真实内容。不同于硬修复（先检测后修复两阶段），RetouchFormer 在单一网络中联合完成定位和合成。

创新二：潜在字典（Latent Dictionary）捕获干净人脸先验

学习一个潜在字典来捕获干净人脸的先验知识。通过字典查询机制，瑕疵区域的 token 可以从字典中获取正常皮肤的参考信息。

创新三：基于先验的选择性自注意力

根据瑕疵定位结果，在自注意力计算中显式抑制瑕疵区域的 query，使其只能从正常皮肤的 key-value 对中获取信息。这确保瑕疵区域被替换为真实皮肤纹理，而非自我重建。

创新四：多尺度特征 token + 半监督训练

多尺度 token 提供处理不同尺度瑕疵的灵活性。半监督训练范式减少对配对数据的依赖。

3.1 潜在字典（Latent Dictionary）

核心思想：学习一个可查询的潜在字典来存储干净人脸的先验知识。

  • 字典由一组可学习的码本向量组成，在训练中从干净人脸区域中学习
  • 当遇到瑕疵区域的 token 时，通过字典查询获取正常皮肤的参考信息
  • 这使得模型具有"知道干净皮肤长什么样"的先验知识
  • 字典学习是半监督的：干净区域提供字典学习信号，无需严格的修图前后配对数据

3.2 重建导向的瑕疵定位模块（Reconstruction-Oriented Localization）

不同于传统的"先检测后修复"两阶段方法，RetouchFormer 通过重建导向的方式预测瑕疵区域：

  • 利用潜在字典的重建能力：当某区域无法用字典中的干净先验良好重建时，该区域被标记为疑似瑕疵
  • 这种"重建差 → 瑕疵"的策略无需显式的瑕疵标注
  • 定位结果作为空间掩码，指导后续的选择性自注意力计算

3.3 基于先验的选择性自注意力（Prior-Based Selective Self-Attention）

这是 RetouchFormer 的核心创新——在 Transformer 自注意力计算中显式抑制瑕疵区域：

维度标准自注意力选择性自注意力
Query 来源所有 token（含瑕疵和正常区域）瑕疵区域的 query 被抑制
Key-Value 来源所有 token主要来自正常皮肤的 key-value
效果瑕疵区域可能自我重建 → 去除不彻底瑕疵区域强制从正常皮肤合成 → 干净填充
核心直觉：标准自注意力中，瑕疵像素的 query 会与自己的 key-value 匹配，导致瑕疵被"重建"而非"去除"。选择性自注意力让瑕疵像素的 query 只能关注正常皮肤的 key-value，强制其合成干净皮肤纹理。

3.4 多尺度特征 Token

  • 提取多尺度特征 token，提供处理不同尺度瑕疵的灵活性
  • 小尺度 token 处理细小斑点；大尺度 token 处理大区域瑕疵
  • 多尺度设计带来更高的有效性和效率

四、训练方案与数据

4.1 半监督训练范式

RetouchFormer 的核心优势之一是减少对配对修图数据的依赖：

  • 干净人脸先验：从无标注的干净人脸图像中学习潜在字典
  • 联合定位+合成：通过重建导向的方式自动发现瑕疵区域，无需显式瑕疵标注
  • 选择性自注意力：利用先验知识在注意力层面抑制瑕疵，端到端训练

4.2 训练数据

维度规格
数据集Flickr-Faces-HQ-Retouching (FFHQR)
训练集结构source（修图前）/ target（修图后）配对
环境Python 3.8, conda
依赖requirements.txt（PyTorch 生态）

4.3 推理

  • 预训练权重 gen_best.pth（百度网盘提供）
  • 推理命令：python image_retouching.py
  • 输入含瑕疵人脸图像 → 输出高保真干净人脸

五、实验结果

5.1 评测

论文在大量实验中验证了 RetouchFormer 的有效性：

  • 在人脸修图任务上超越先进方法
  • 合成干净人脸图像，保持高保真度
  • 半监督训练范式下减少对配对数据的依赖

5.2 消融实验要点

组件作用移除影响
潜在字典提供干净皮肤先验模型缺乏干净皮肤参考 → 修图质量下降
选择性自注意力抑制瑕疵区域自重建瑕疵可能被重建而非去除
重建导向定位自动发现瑕疵区域缺乏定位 → 修复不完整
多尺度 token处理不同尺度瑕疵大/小瑕疵处理不灵活
