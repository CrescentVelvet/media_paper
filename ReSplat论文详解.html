1.1 核心问题

前馈式高斯泼溅模型（Feed-Forward Gaussian Splatting）能直接从输入图像预测 3D 高斯参数，无需昂贵的逐场景优化。但存在两大限制：

限制说明现有方法的问题
单步推理用一次前向传播预测所有高斯复杂场景下质量受网络容量限制；难以泛化到未见数据
逐像素高斯每像素预测一个或多个高斯多视角/高分辨率时产生数百万高斯 → 计算量大、难以扩展

1.2 核心洞察

ReSplat 的核心洞察：高斯泼溅的渲染误差是一个丰富的反馈信号。渲染当前预测后，将渲染图与真实输入图比较，误差可以指导网络学习如何更新高斯参数——无需显式计算梯度（gradient-free）。

与逐场景优化的对比：3DGS 优化通过梯度下降迭代数千步更新高斯；ReSplat 用学习式循环网络模拟这一迭代过程，100× 更快，且能自适应未见数据（因为渲染误差在测试时自然反映数据分布）。

二、核心创新概述SOTA

创新一：紧凑初始化 — 16× 子采样空间

在 1/16 子采样空间中预测初始高斯，产生比逐像素模型（如 MVSplat、DepthSplat）少 16 倍的高斯。大幅降低计算开销，使后续循环更新高效可行。通过 kNN 注意力 + 全局注意力补偿信息损失。

创新二：无梯度循环更新

训练权重共享循环网络，利用渲染误差作为反馈信号，迭代精炼高斯参数。无需显式梯度计算，4 次迭代后收敛。每个高斯同时维护参数和隐藏状态（类似 GRU/LSTM）。

创新三：渲染误差反馈机制

渲染输入视角 → 计算渲染误差（像素空间 + 特征空间）→ 全局注意力传播到 3D 高斯 → 预测增量更新。该反馈信号在测试时自然适应未见数据分布，实现跨数据集、跨视角数、跨分辨率的鲁棒泛化。

3.1 紧凑初始化重建

16× 子采样空间

  • 基于 DepthSplat 架构，但将深度预测从全分辨率降至 1/4 分辨率（N×H/4×W/4）
  • 反投影到 3D 得到 M = N×H×W/16 个点（比逐像素模型少 16 倍）
  • 每个 3D 点 pⱼ 关联特征向量 fⱼ ∈ ℝC₀（C₀=256 small / 512 base）
{Iᵢ, Kᵢ, Rᵢ, tᵢ}ᵢ₌₁ᴺ → {(pⱼ, fⱼ)}ⱼ₌₁ᴹ

3D 上下文聚合

由于点数减少了 16 倍，直接从 fⱼ 预测高斯参数会导致性能下降。使用 6 个交替的 kNN 注意力和全局注意力块建模局部和全局 3D 上下文：

{(pⱼ, fⱼ)}ⱼ₌₁ᴹ → {(pⱼ, fⱼ*)}ⱼ₌₁ᴹ

解码为高斯

  • 点云 {pⱼ} 作为高斯中心
  • 其他参数（不透明度 α、协方差 Σ、球谐 sh）由两层 MLP 从 fⱼ* 解码
  • 初始隐藏状态 zⱼ⁰ = fⱼ*（用聚合特征初始化）
  • gⱼ⁰ ∈ ℝC₁（C₁=59，所有高斯参数拼接）
𝒢⁰ = {(gⱼ⁰, zⱼ⁰)}ⱼ₌₁ᴹ

3.2 循环高斯更新

在初始化 𝒢⁰ 基础上，训练权重共享循环网络迭代精炼。每次迭代 t：

gⱼᵗ⁺¹ = gⱼᵗ + Δgⱼᵗ,    zⱼᵗ⁺¹ = zⱼᵗ + Δzⱼᵗ

增量更新 Δgⱼᵗ 和 Δzⱼᵗ 从渲染误差和当前高斯状态预测，无需梯度计算。

3.3 渲染误差反馈机制（核心创新）

计算渲染误差

  • 用当前高斯 𝒢ᵗ 渲染输入视角 → 得到 Îᵢᵗ
  • 像素空间误差：Îᵢᵗ − Iᵢ，4× 下采样（pixel unshuffle 对齐维度）
  • 特征空间误差：用 ResNet-18 提取渲染图和真实图的前三阶段特征（1/2、1/4、1/8 分辨率），缩放到 1/4 后相减
  • 两者结合：通过线性层+LayerNorm 将像素误差投影到特征空间，然后逐元素相加
Êᵗ = {F̂ᵢᵗ − Fᵢ} + proj({Îᵢᵗ − Iᵢ})

渲染误差传播到 3D 高斯

直接拼接的问题：第 j 个高斯只能接收第 j 个渲染像素附近的局部信息。但一个高斯在渲染时可能贡献到多个像素。

解决方案：对所有渲染误差应用全局注意力，让每个高斯接收所有视角的渲染误差信息：

Eᵗ = global_attention(Êᵗ) = {eⱼᵗ}ⱼ₌₁ᴹ

然后将高斯与全局聚合的渲染误差拼接：{(gⱼᵗ, zⱼᵗ, eⱼᵗ)} → 预测增量 {(Δgⱼᵗ, Δzⱼᵗ)}。

核心直觉：渲染误差 = "当前预测哪里不够好"。全局注意力让每个高斯知道"整个场景哪里有问题"，然后学习如何修正。这模拟了 3DGS 优化中"渲染→检查→修正"的迭代过程，但用学习式网络替代梯度下降——100× 更快。

Stage 2 的循环训练：每次迭代的渲染预测都用渲染损失监督。训练时随机采样迭代步数 T，让模型学习从 1 到 4 次迭代的不同深度。深度平滑损失不需要 GT 深度，仅用作正则化。

5.3 泛化能力

模型仅在 DL3DV（8视角，512×960）上训练，测试零样本泛化：

  • 跨数据集（→RealEstate10K）：循环模型改进比单步模型更显著——渲染误差自然适应域差距
  • 跨视角数（2/8/16/32）：循环模型更好地利用额外视角信息
  • 跨分辨率（256×256 ~ 540×960）：循环模型在分辨率偏离训练时仍提升 5 dB PSNR
关键发现：渲染误差作为测试时反馈信号，让模型自然适应未见数据分布——这是单步前馈模型无法做到的，也是 ReSplat 泛化能力的核心来源。
