1报告概要与核心结论

一句话结论:四篇论文解决同一个问题 —— 多视角输入存在光度/色度不一致时如何重建出干净、可泛化到新颖视角的 3D 场景;它们的分歧不在目标,而在"校正变换用什么参数化、挂在管线哪个位置、新视角的校正参数从哪来"三个设计点上,且存在明确的容量-泛化-可解释性三角权衡。

核心判断(先给结论):
  • 要泛化到新颖视角 + 可解释可控 → PPISP 是当前最优解:物理约束等于把归纳偏置做对,容量刚好覆盖真实 ISP 自由度;Tanks&Temples 上训练/新视角 PSNR 差仅 1.23 dB(25.85/24.62),而 BilaRF 差 7.09 dB(26.87/19.78,Table 5);且它是唯一正面回答"新视角校正参数从哪来"的(controller,类比相机 AE/AWB)。
  • 自动驾驶大场景(多相机×时序) → bilateral-driving:多尺度金字塔是"appearance code 与双边网格的中间点",收益主要体现在几何指标(Waymo CD −28.2%);但插值方案依赖时序近邻,静态多视角场景不适用。
  • 要 3D 编辑/修图能力 → BiLaRF 仍是唯一:低秩 4D 网格把单张 2D 修图升维到全场景,其余三篇都不做编辑;且 nerfstudio 官方集成使其工程接入成本最低。
  • 低光/过曝/色温极端退化 → Luminance-GS++:唯一针对亮度+色度联合退化设计,训练仅 0.23 GPUh;但校正被"烤进"高斯属性、不可逆、不可解释,且未开源。

2共同问题:光度不一致如何毁掉重建

NeRF/3DGS 的优化目标是让同一 3D 点在所有视角渲染出一致颜色。但真实采集中,相机 ISP(自动曝光、自动白平衡、局部色调映射)对每张图独立处理;多相机 rig 之间、同一相机不同时刻之间,传感器响应与 ISP 决策都在漂移。光度矛盾无法被"颜色一致"满足,优化器就把它解释成几何 —— 在空中造出薄纱状密度(floaters)来分别讨好各视角。

四篇共同承认的失败链

输入图光度不一致 → photometric consistency 假设被破坏 → 辐射场/高斯把 ISP 残差建成几何或烘进外观 → floaters / 重影 / 色调漂移 → NVS 指标与几何精度(CD / Depth)同时受损。

既有朴素方案为何不够(四篇共同批评)

① per-frame 全局嵌入(GLO / appearance code):一个 code 管整图,表达不了局部变化(BiLaRF 附录 D:高光被烘进场景;bilateral-driving Fig.1a:栅栏被抹糊);② 全局逐通道曲线(HDRNeRF):表达不了局部色调映射(BiLaRF Table 1 SSIM 0.6451 断崖);③ 单张大双边网格:容量过大难优化(bilateral-driving Tab.1:w/BG 在 Waymo NVS 反掉到 21.51 vs 基座 26.40;PPISP Table 5:TV 26.87 / NV 19.78 严重过拟合);④ RAW 路线(RawNeRF):多数设备拿不到 raw。

一个被 PPISP 点破的评估陷阱(全报告最重要的方法论提醒):RawNeRF / mip-NeRF 360 以来,这类方法的评测常对渲染图与 GT 做逐通道仿射对齐(-CC)再算指标。PPISP(§1/§2/§5)指出该协议 ① 现实中拿不到 GT 新视角,根本做不了对齐;② 对齐本身会补偿掉方法间差异,"mask differences between methods"。BiLaRF 与 Luminance-GS++ 的主指标都依赖对齐类协议;bilateral-driving 不做对齐但只报驾驶数据集;PPISP 是唯一把"未对齐 PSNR 也能打"作为核心卖点并正面设计评估的(其未对齐 PSNR 甚至超过 BilaRF 的 PSNR-CC,§5.1)。

4四篇论文速览卡

① BiLaRF(2406.00448,SIGGRAPH/TOG 2024,CUHK)

问题:手机 ISP 逐张增强毁多视角一致性 → floaters。
方法:每训练视角挂一个 3D 双边网格(16×16×8×12,每格 3×4 仿射,恒等初始化,TV×10)吸收 ISP 残差,辐射场只学干净场景;训完网格丢弃、推理零开销。另用 CP 低秩 4D 网格(秩 5/8)把单视角 2D 修图升维 3D。
关键数字:自采 7 夜景,CC-PSNR 27.53 / SSIM 0.8696 / LPIPS 0.1336,vs GLO 26.54、ZipNeRF 25.17(Table 1);训练 ≈2.25h@3090。
一句话:双边网格范式开山与参照系;nerfstudio 已官方集成(use_bilateral_grid)。→ 库内深度笔记

② bilateral-driving(2506.05280,NeurIPS 2025,BAAI/AIR-THU)

问题:驾驶场景多相机×时序不一致;AC 太粗(栅栏糊)、单大网格不收敛(Waymo NVS 21.51 vs 基座 26.40)。
方法:三级金字塔 2×2×1 / 4×4×2 / 8×8×4(每格 12 维仿射),粗层≈AC、细层≈BG、中间实现 patch-wise;adaptive TV + circle 正则;新时刻只对粗/中层做时序线性插值,细层不插值。
关键数字:Waymo CD 0.989(vs AC 1.378,−28.2%);参数 3.969M vs 单网格 27.843M;训练 2.10h@L40(+9%);推理 54→42 FPS(Tab.1/4)。
一句话:用"尺度分解"而不是"更强约束"解决网格难优化;收益主要在几何。

③ PPISP(2601.18336,NVIDIA,2026-01)

问题:GLO/BilaRF 无物理约束 → 过拟合、不可解释、新视角没参数;CC 对齐评估协议失真。
方法:物理 ISP 四模块按序作用于渲染 radiance(线性域):曝光(per-frame,$2^{\Delta t}$)/ 暗角(per-camera 多项式)/ 色彩 homography(per-frame,8 参)/ CRF(per-camera 分段幂函数);再训 controller 从渲染图预测新视角的 9 个 per-frame 参数(类比 AE/AWB),可融合 EXIF metadata。两阶段训练 30k + 5k 迭代。
关键数字:五数据集 PSNR 全超 BilaRF/ADOP;T&T NV 24.62 vs BilaRF 19.78;渲染 +0.84ms(+26%,RTX 5090);metadata 加持下 HDR-NeRF 集 PSNR 34.30(Table 1/3/4/5)。
一句话:物理归纳偏置 = 容量-泛化甜区;已开源(nv-tlabs/ppisp)。

④ Luminance-GS++(2602.18322,2026-02,东大/东北大/UC Merced)

问题:低光/过曝/色温极端退化下 3DGS 崩坏;前作 Luminance-GS 只有全局曲线、缺局部精修。
方法:不改表征,给每高斯加可学习线性修正 $c_i^{out}=a_i c_i+b_i$;伪增强标签 = 视角自适应曲线(共享 256-LUT + 相机矩阵作 query 的注意力偏置)+ 3×ConvNeXt 局部残差(clip ±0.1/±0.5);双路渲染把增强蒸馏进 $c_i^{out}$,推理零额外开销。
关键数字:LOM 低光 20.74/0.823/0.272 vs 前作 18.34(+13.1%);MipNeRF-360 混合退化 17.86 vs 3DGS 15.87;训练 0.23 GPUh(Aleth-NeRF 14.08)(Tab.I/III/IV)。
一句话:极端退化场景的增强路线;未开源、校正不可逆。

6机制对比一:校正模型的数学形式

四种参数化决定了"能表达什么、不能表达什么"。按表达力从强到弱(也即归纳偏置从弱到强)排列:

① BiLaRF:亮度索引的局部仿射(表达力最强,约束最弱)

(式 1,BiLaRF 式 3) $$C_e = \mathcal{A}(u,v,g)\,[C \mid 1]^{\top},\qquad \mathcal{A} = \text{trilerp}\big(A \in \mathbb{R}^{16\times16\times8\times12},\ (u,v,g(\widehat{C}))\big)$$

每个网格 cell 存一个 $3\times4$ 仿射颜色矩阵,按像素位置 $(u,v)$ 与引导灰度 $g$ 三线性插值取出。$g$ 使等亮度区域共享变换(边缘感知),这是它超越纯空间网格的关键。约束只有恒等初始化 + TV($\lambda=10$)+ 刻意低分辨率 —— 都是软约束,所以它能建模光度以外的东西(这正是 PPISP Table 5 攻击的点)。

② bilateral-driving:由粗到细的网格复合(表达力分级)

(式 2,bilateral-driving 式 8) $$I^{e} = T^{(2)} \circ T^{(1)} \circ T^{(0)}(I^{r}),\qquad T^{(l)}(x) = \bar{M}^{(l)}(u,v,d)\,x + \bar{t}^{(l)}(u,v,d)$$

三个尺度 $2{\times}2{\times}1$ / $4{\times}4{\times}2$ / $8{\times}8{\times}4$ 各自在下采样 guidance map 上 slice,再函数复合 —— 粗层学全局基线(等价 appearance code),细层只学残差。关键工程发现:全分辨率 guidance 会过拟合噪声(Tab.5a,(1,1,1) 反而掉点),最佳下采样为 (2,2,1);去掉最粗层 CD 从 1.161 恶化到 1.94+(Tab.5b),证明全局分量对几何一致性必不可少。

③ PPISP:相机成像物理的显式分解(表达力最受限,约束最强)

(式 3,PPISP 式 3-16 合写) $$I^{out} = \underbrace{G\Big(\underbrace{h\big(\underbrace{I^{exp}\cdot v(r;\alpha)}_{\text{暗角(每相机)}};\ H(\Delta c)\big)}_{\text{色彩 homography(每帧,8 参)}};\ \tau,\eta,\xi,\gamma\Big)}_{\text{CRF(每相机)}},\qquad I^{exp} = L \cdot 2^{\Delta t}\ \text{(每帧)}$$

每个模块只被允许做物理上成立的事:曝光只能整体缩放亮度($2^{\Delta t}$,EV 语义);暗角是径向六次多项式(每相机、每通道);色彩校正是在 RG 色度 + 强度上施加由 4 个色度偏移(8 标量)构造的 homography,且做强度归一化以解耦曝光与白平衡(附录 A.1 的 PCC 实验证明其耦合显著低于 ADOP 的逐通道增益);CRF 是 $C^1$ 连续的分段幂函数(每通道 4 参),单调光滑 —— 对比 ADOP 的 25 节点插值 CRF 需要额外光滑正则仍可能非单调。参数全部有物理意义,可手动调节,附录 A.2 还证明同相机的暗角/CRF 曲线跨序列重合(在线标定性质)。

④ Luminance-GS++:曲线伪标签 + 蒸馏(表达力转移到伪标签生成器)

(式 4,Luminance-GS++ 式 4/7) $$c_i^{out} = a_i \cdot c_i + b_i,\qquad C_k^{out} = \mathbb{L}_k\big(C_k^{in} \cdot \mathcal{M}_k\big) \cdot \mathcal{M}_k^{-1} + \mathbb{R}(C_k^{in}),\quad \mathbb{L}_k = \mathbb{L}^{g} + \mathbb{L}_k^{b}$$

校正分两层:伪标签侧(视角自适应曲线 $\mathbb{L}_k$ = 共享 256-LUT + 相机矩阵作 query 的 cross-attention 偏置,外加 3×ConvNeXt 残差,clip 到 ±0.1/±0.5)决定"想要什么效果";3D 侧每高斯只学一个线性修正 $(a_i, b_i)$,双路渲染把伪标签蒸馏进 $c_i^{out}$。3D 侧的容量被刻意压到线性,表达力全在 2D 伪标签生成器里 —— 这也是它推理零开销但不可逆的原因。

对比结论:四种形式恰好构成"表达力 vs 约束"的光谱 —— BiLaRF(每 cell 12 参自由仿射)> bilateral-driving(同仿射但粗到细分解,细层只学残差)> Luminance-GS++(per-Gaussian 线性 + 2D 曲线/残差)> PPISP(物理允许的最低维变换)。§8 将看到,这个光谱与新视角泛化能力几乎负相关。

11对 vggt_human pipeline 的选型建议

我们的链路(COLMAP → 3DGS → HYPIR → SAM3)在人脸/人体多视角采集上同样面临光度不一致:多相机 rig 的传感器差异、单相机环绕拍摄时自动曝光/白平衡漂移,会在 head_gs 纹理上产生 floaters 与 albedo 不一致,并可能污染后续 3DMM 对齐(纹理不干净时 657 点 landmarks 的光度监督会带偏 id/exp 系数)⚠️【推测】关于对 3DMM 阶段的传导效应,未实验验证。

我们的场景推荐理由与接入方式
静态人体/人脸多视角重建(默认情形)PPISP(首选)与 3DGS/GSplat 管线直接兼容、有官方代码;新视角泛化最好(§8);物理参数可解释,排查问题时能直接看 EV/白平衡曲线;推理 +0.84ms 可忽略

12局限与开放问题汇总

  • 四家没有同场竞技:PPISP 只在 3DGUT/GSplat 上比了 BilaRF/ADOP;bilateral-driving 只在 OmniRe 系上比了 AC/BG;Luminance-GS++ 与前三家零定量交集。同一数据集、同一基座、同一协议(尤其统一是否 CC)的四方对比至今不存在,是本领域最显眼的空白。
  • 评估协议分裂:CC 对齐派(BiLaRF、Luminance-GS++)vs 未对齐派(PPISP)。PPISP 的批评在逻辑上成立,但 CC 指标对"只关心几何/结构"的下游仍有用 —— 需要分场景看。
  • 动态场景的光度校正无人做好:bilateral-driving 处理"动态场景里的静态背景+运动体",但其网格仍是 per-frame 的;BiLaRF 明说处理不了瞬态物体;4D 动态重建(我们关注的方向之一)里的时变 ISP 校正基本空白。
  • 编辑与校正的统一:BiLaRF 有编辑但网格不可解释;PPISP 可解释但无编辑框架。"物理参数化的 3D 修图"(比如直接调 EV/白平衡曲线重打光整个场景)是 PPISP 留了接口但没做的事。
  • 伪标签路线的上限:Luminance-GS++ 自述伪标签质量是瓶颈;把扩散先验引入伪增强是开放方向(其 §VI)。

13总结

这条 2024→2026 的演进线讲了一个清晰的故事:校正模型的表达力越做越克制,泛化与可控性越做越强。BiLaRF 证明局部仿射网格足以吸收 ISP 残差(并附带打开 3D 编辑的大门);bilateral-driving 证明网格的难优化可以用尺度分解驯服,并首次把收益量化到几何;bilateral grid 的两个软肋(过拟合、新视角无参数)最终被 PPISP 用物理参数化 + controller 同时解决;Luminance-GS++ 则从另一个极端(极端退化增强)证明,当问题从"轻微不一致"变成"严重退化"时,蒸馏伪标签比建模 ISP 更直接。对我们的 pipeline:默认 PPISP,快速验证用 nerfstudio 的 BiLaRF 开关,修图需求用 BiLaRF finishing,采集端尽量锁 AE/AWB 并保留 EXIF。
