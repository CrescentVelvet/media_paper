TripoSplat：基于学习密度控制的生成式3D高斯

Generative 3D Gaussians with Learned Density Control
Runjie Yan (清华), Yan-Pei Cao, Peng Wang, Ding Liang, Yuan-Chen Guo (VAST / TripoAI)
arXiv:2605.16355 · SIGGRAPH 2026 Conference Papers · 2026年5月
3D生成 高斯泼溅 单图转3D MIT License

TripoSplat 是 VAST-AI Research / TripoAI 推出的单图转3D高斯生成模型。核心创新有三：(1) 密度采样高斯（DeG）——将高斯中心建模为从可学习概率密度函数中采样，支持任意数量的高斯输出；(2) 渲染损失贡献梯度——将3DGS的离散致密化/剪枝替换为全可微的密度优化；(3) VecSeq重排序——通过最优传输将无序潜在token映射到确定性的3D Sobol序列，解决扩散模型在集合数据上的排列歧义问题。

摘要

本文提出密度采样高斯（Density-Sampled Gaussians, DeG），一种全新的3D表示方法，旨在弥合自适应渲染原语与可扩展生成建模之间的差距。

现有方法将3D高斯约束在固定的体素网格或数组上，而DeG将高斯中心建模为从定义在八叉树上的可学习概率密度函数中采样的样本。这一公式提供了一个严格的数学框架来实现自适应密度控制：通过在渲染监督下联合优化空间密度和高斯属性，模型自然地将原语集中在几何复杂度高的区域。

为实现生成式合成，作者在DeG上训练了潜在扩散模型，并提出了VecSeq——一种规范重索引机制，将潜在token锚定到确定性的3D Sobol序列上，将无序集合生成问题转化为鲁棒的序列建模任务。实验证明该流程在单图转3D生成中达到了SOTA质量。

1. 引言

3D生成模型在图形学和视觉领域日益重要，广泛应用于AR/VR、仿真、机器人和交互应用。3D高斯泼溅（3DGS）因其灵活性、高视觉质量和有前景的渲染速度而成为一种引人注目的表示方法。

核心挑战：3DGS的质量主要源于密度控制策略——迭代致密化和剪枝。但这个过程是不可微且难以向量化的，在可泛化的学习设置中不实用。因此，现有的高斯生成方法通常将3D场景表示为绑定在预定义结构上的固定数量高斯：

  • GaussianCube：优化固定的 N³ 个高斯，用最优传输重排到网格
  • 结构化潜在方法（TRELLIS, UniLat3D）：给每个体素分配固定数量的高斯
  • 像素对齐方法（LGM, DiffusionGS）：每个像素/图块预测固定数量的高斯

这些方法都无法根据局部复杂度自适应分配高斯，导致需要过多的高斯才能达到高保真度。

本文方案：提出一个恢复3DGS自适应能力的生成框架，无需逐场景优化。引入DeG——高斯中心从学习的3D概率密度函数中动态采样，将原语的空间分布与其属性解耦。推理时可从该密度中采样任意数量的锚点，实现从轻量移动端资产到超高保真渲染的灵活权衡。

核心贡献

  1. 密度采样高斯（DeG）：一种面向生成建模的3D表示，通过从可学习密度函数采样中心来支持可变大小输出和高斯的自适应分配。
  2. 渲染损失贡献梯度：一种高效信号，仅使用图像重建损失即可端到端优化随机密度函数，有效学习最优原语放置——相当于3DGS致密化/剪枝的全可微替代。
  3. VecSeq重排序机制：通过将token锚定到确定性空间结构来稳定集合数据上的扩散训练，实现更快收敛和SOTA生成质量。

2. 相关工作

2.1 3D高斯泼溅

3DGS将场景或物体表示为一组各向异性高斯，通过可微光栅化（泼溅）渲染，达到实时速度和高视觉质量。近期改进包括增强致密化、高效训练、稀疏视图重建和即时前馈推理。F4Splat将致密化扩展到前馈重建。但这些工作面向重建，通常缺乏生成3D高斯的能力。

2.2 3D生成模型

早期方法使用对抗训练建模类别级形状分布。SDS（Score Distillation Sampling）通过冻结的扩散模型梯度实现3D生成。近年来潜在扩散模型启发了3D原生潜在表示：3DShape2VecSet提出将SDF编码为无序token集合并在潜在空间进行扩散的范式；CLAY进一步扩展；后续包括TripoSG、Hunyuan3D 2.1、Direct3D、LATTICE等。另一分支通过稀疏体素层级或稀疏结构改进几何细节，但主要面向表面几何生成。

2.3 3D高斯生成

现有高斯生成方法受限于神经输出参数化：结构化潜在方法给每个体素分配固定数量高斯；像素对齐方法预测每个像素/图块的固定高斯数。GaussianCube尝试通过OT映射恢复输出灵活性，但引入大量训练开销（逐物体高斯拟合），且仍受网格分辨率限制。AtlasGaussian在UV图块内均匀采样，不建模全局自适应分布。MaskGaussian将高斯视为概率实体，但仍操作在固定空间支架上。

关键差距：现有方法都无法像原始3DGS那样根据局部复杂度自适应分配高斯。TripoSplat通过将密度控制"烘焙"进生成模型来解决这一问题。

3. 方法

3.1 总览

整个流程遵循潜在扩散范式，但摒弃将高斯约束在规则固定大小结构上的做法。方法由两个核心组件构成：

组件 1：DeG-VAE（密度采样高斯VAE）

将3D资产编码到紧凑的潜在空间，通过学习的空间概率密度解码。允许模型动态分配高斯基元，并通过新颖的密度感知多视图渲染损失端到端训练VAE。

组件 2：VecSeq扩散Transformer

建模这些潜在token的分布，训练以在单张输入图像条件下恢复潜在表示。VecSeq引入基于最优传输的规范重索引机制，解决无序集合上扩散训练的收敛挑战。

3.2 密度采样高斯VAE

表示的核心是将几何分布（原语存在于何处）与原语属性（外观和局部形状）解耦。

集合编码器

对于3D资产 𝒪，将其几何和外观表示为潜在token集合 𝒵 = {zᵢ ∈ ℝᶜ}ᵢ₌₁ᴹ。为捕获高保真细节，从两个来源聚合信息：

  • DINOv3：语义一致性特征
  • FLUX.2 VAE：高频纹理细节

同时从资产表面采样密集点云 𝒫，将每个点投影到多视图特征图上并跨视图平均检索特征。得到两组互补的特征增强点集，用基于Transformer的集合编码器 ℰθ 压缩为固定大小的潜在集合：

𝒵 = ℰθ( FPS(𝒫) | 𝒫dinov3, 𝒫flux2 )

其中FPS表示最远点采样，选择M个代表性中心作为编码器注意力的种子。

随机密度解码

标准3D解码器通常将潜在token映射到固定数量的原语或均匀体素网格。本文将高斯中心预测公式化为从学习的条件概率密度 qθ(x|𝒵) 中的采样过程：

𝒫anchor = {xᵢ}ᵢ₌₁ᴸ ∼ qθ(·|𝒵)

关键：P 不是由架构固定的，可在推理时调整以权衡渲染速度与保真度。

高效八叉树采样

在密集体素网格上定义 qθ 计算上不可行（O(N³)）。改用 L层八叉树分解，有效分辨率 (2ᴸ)³ 同时保持稀疏计算。联合概率分解为：

qθ(x|𝒵) = ∏ₗ₌₁ᴸ qθ(x₀:ₗ | x₀:ₗ₋₁, 𝒵)

每项是父节点的8个子节点的分类分布。通过高效祖先采样实现：维护一个包含样本的活动单元前沿，每层只为活动单元评估概率logits，根据 qθ 将样本路由到子节点。空分支自然剪枝，重复直到第L层。叶节点索引通过叶体积内均匀采样去量化为连续锚点位置。

属性解码与局部扩展

给定锚点和全局潜在 𝒵，使用基于Transformer的属性解码器预测高斯基元参数（不透明度、缩放、旋转、球谐系数）。为捕获局部表面细节，实现局部扩展机制：每个锚点 xᵢ 生成 K 个独立高斯，带有学习的局部偏移：

{ {gᵢᵏ}ₖ₌₁ᴷ }ᵢ₌₁ᴸ = 𝒟θ( 𝒫anchor | 𝒵 )

这种"全局密度采样 + 局部扩展"的层次方法使模型能用少量锚点表示大的均匀区域，同时在复杂细节处密集填充，共产生 N = P·K 个泼溅。

3.3 可微密度优化

核心挑战：优化空间密度 qθ。标准方法仅依赖结构监督（如对表面体素的交叉熵），这与渲染需求不一致——会将过多原语分配给平坦的纹理表面，而过少分配给薄几何结构。

由于锚点位置是 qθ 的采样，渲染损失 ℒrender 对密度参数 θ 不可直接微分。为此推导渲染损失贡献梯度，将渲染反馈反向传播到概率密度中。

结构初始化

首先用显式几何锚定密度。给定从表面点导出的目标分布 p(x)，最小化八叉树结构上的交叉熵损失：

ℒCE = -∑ₓ₀:ₗ p(x₀:ₗ) log qθ(x₀:ₗ | 𝒵)

渲染监督

采样相机位姿 π，最小化渲染图像与目标图像之间的重建损失（L1 + SSIM + LPIPS的加权和）：

ℒrender = ℒl1 + λssim ℒssim + λlpips ℒlpips

将渲染反向传播到密度

不同于先前工作将结构和外观视为分离的优化问题，本文统一两者。利用策略梯度和差异奖励（difference reward）推导梯度：

∇θ ℒrender = 𝔼[ ∑ⱼ₌₁ᴾ (ℒ({xᵢ}ᵢ₌₁ᴸ) - ℒ({xᵢ}ᵢ≠ⱼᴸ)) ∇θ log(qθ(xⱼ)) ]

差异项 Δℒrender = ℒrender(全部锚点) - ℒrender(去掉xⱼ的锚点) 度量锚点 xⱼ 降低了多少渲染损失。直观上，这一项增加了锚点 xⱼ 存在时导致渲染误差更大降低的位置的概率密度。

高效的渲染损失贡献梯度

直接评估上式不切实际（每个锚点需要额外的留一渲染）。关键观察：对于 ℒl1 项，标准3DGS反向光栅化已经维护了估计移除原语导致的损失变化所需的透射率和累积背景色。因此在同一个CUDA反向传播中以可忽略的开销累积原语级贡献，按同一锚点的原语求和，直接反向传播锚点级信号到 log(qθ(xⱼ|𝒵))。

最终VAE训练损失：

ℒVAE = λstructℒCE + λrender(ℒrender + ℒ̂render) + λregℒreg + λklℒkl

其中 ℒ̂render 即渲染损失贡献梯度。

三阶段训练课程

阶段1：结构初始化（~6%训练时间）

仅用 ℒCE 优化 ℰθ 和 qθ，建立粗略几何外壳，防止退化解（如零不透明度坍缩）。

阶段2：外观（可选）

用少量高斯和大批量训练属性解码器 𝒟θ，使用 ℒrender + ℒCE，锁定外观，加速收敛。

阶段3：联合精炼

端到端训练所有参数，使用完整 ℒVAE，使 ℒ̂render 提供密度重分配信号。同时随机化锚点数 P 以鼓励模型泛化到不同分辨率预算。

3.4 VecSeq扩散

使用扩散Transformer建模潜在码 𝒵 的分布，采用 Flow Matching 框架和 S3-DiT 骨干。训练目标：

ℒFM = 𝔼t,x₀,ε ‖vθ(xₜ, t) - (ε - x₀)‖²₂

同时联合预测一个紧凑的噪声相机token cₜ 并拼接到 xₜ，用于恢复条件视图位姿。

排列歧义问题

集合编码器产生的无序token集合 𝒵 = {zᵢ}ᵢ₌₁ᴹ 没有内在顺序。如果直接送入扩散模型，噪声token与数据token的配对变得任意（M! 种可能配对），模型被迫学习所有排列的平均，导致收敛缓慢和模糊的模态平均生成。

VecSeq：通过最优传输的规范序列化

将无序潜在集合转换为规范有序的向量序列。选择 3D Sobol序列 𝒮 = {sⱼ}ⱼ₌₁ᴹ 作为锚定结构——Sobol序列是低差异准随机序列，比标准随机采样更均匀地覆盖单位立方体 [0,1]³。

训练时计算最优分配 π*，将资产特定的FPS点 {pᵢ} 匹配到固定的Sobol锚点 {sⱼ}，最小化总传输成本：

π* = 3D OT Assign({pᵢ}, {sⱼ})

然后按此映射重排潜在token，得到序列 𝒵̃ = {z̃ⱼ}ⱼ₌₁ᴹ，其中 z̃ⱼ = zπ*(j)。此分配作为离线预处理步骤计算一次，训练和推理时零成本。

将 sⱼ 的正弦位置嵌入添加到第j个token，注入空间先验。推理时模型只需预测长度为M的序列，隐含知道第j个输出对应空间位置 sⱼ。这有效地将困难的集合生成问题转化为稳定的序列生成问题。

与GaussianCube的区别：GaussianCube用OT将高斯原语直接分配到固定立方体结构；VecSeq是在潜在token上执行OT分配，且使用单一通用模板（Sobol锚点），允许每个物体独立匹配，复杂度为O(N)，而经典排列同步方法需要O(N²)。

Algorithm 1: 高效批量八叉树采样

Algorithm 1: Efficient Batched Octree Sampling
Input: 潜在码 𝒵, 总采样数 P, 最大层级 L
Output: 3D锚点集合 𝒫anchor, 对数概率 ℒ
// 用根节点初始化活动前沿
Initialize active frontier ℱ₀ ← { (root, P, 0) }
for l ← 1 to L do
ℱₗ ← ∅
foreach active cell (cparent, nparent, log pparent) ∈ ℱₗ₋₁ do
// 从潜在码预测子节点分布
Compute logits: h ← Model(cparent, 𝒵)
Compute probabilities: D ← Softmax(h)
Compute log-probabilities: log D ← LogSoftmax(h)
// 将父节点样本分配到子节点
Distribute nparent into {n₀,...,n₇} according to D with systematic sampling
for k ← 0 to 7 do
if nₖ > 0 then
// 更新累积对数概率
log pchild ← log pparent + log D[k]
ℱₗ ← ℱₗ ∪ { (cparent·8+k, nₖ, log pchild) }
end if
end for
end foreach
end for
𝒫anchor ← ∅; ℒ ← ∅
// 将叶节点索引转换为连续坐标
foreach leaf cell (cleaf, nleaf, log pleaf) ∈ ℱₗ do
Determine spatial bounds B of cell cleaf
Sample nleaf points {x⁽ʲ⁾} ∼ Uniform(B)
𝒫anchor ← 𝒫anchor ∪ {x⁽ʲ⁾}
ℒ ← ℒ ∪ {log pleaf}
end foreach
return 𝒫anchor, ℒ

算法核心思路：从八叉树根节点开始，逐层预测每个活动体素的8个子节点的概率分布，用系统采样将父节点的样本数分配到子节点。空分支自然剪枝，最终在叶节点内均匀采样得到连续坐标的锚点。整个过程高度并行化，复杂度远低于O(N³)的密集网格。

4. 实验

4.1 实现细节

  • 训练数据：Objaverse + Objaverse-XL 子集（TRELLIS-500K数据集）
  • 阶段1：1024个潜在token，交叉熵监督8192个点
  • 阶段2：随机采样1024-8192个token和2048个锚点用于GS渲染
  • 阶段3：随机采样1024-8192个token和1024-8192个锚点（两者不必相同）
  • 硬件：VAE训练约10天（32×A800），Flow Matching模型约11天（32×A800）
  • 评测：Toys4K数据集（训练中未见），定量和定性评测

5. 结论与展望

TripoSplat提出了密度采样高斯（DeG），用定义在八叉树上的可学习、渲染优化密度取代不可微的致密化和剪枝。通过从该密度采样高斯中心，DeG支持可变大小输出和高斯向局部复杂区域的自适应分配。

进一步引入了配对学习流程，训练自编码器将3D资产压缩为紧凑潜在token并解码为DeG，密度在渲染监督下端到端优化。实验表明该设计在可比高斯预算下显著提升重建质量，渲染损失贡献梯度(ℒ̂render)提供一致增益（尤其在低预算区域）。DeG还展现出强缩放行为。

最后，通过VecSeq解决了向量集潜在上生成建模的关键收敛挑战——扩散训练中的排列歧义。通过最优传输分配token位置以启用位置编码，实现更快收敛和更高质量的单图条件生成。

局限性

  • 作为单图转3D方法，背面区域在推理时未被观测，质量可能较低
  • 当前表示仅针对3DGS而非网格；但潜在空间已忠实重建3D形状和纹理，可能已包含带纹理网格解码器所需信息
