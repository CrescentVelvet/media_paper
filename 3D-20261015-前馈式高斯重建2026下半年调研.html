1摘要与核心结论

前馈式高斯重建（feed-forward Gaussian reconstruction）用在大规模多视角数据上预训练的 Transformer，把「从图像到 3D 高斯」的过程压缩成一次网络前向，取代逐场景梯度优化。它继承了 3DGS 的实时渲染与显式可编辑表示，又丢掉了「每个场景都要重训」的包袱。

一句话核心结论

2026 下半年的前馈高斯重建，主题已从「能不能一次前向出结果」变成「稀疏视角下能不能跑准」。绝大多数新论文都在补同一块短板 —— 单次前向受网络容量约束、稀疏输入下信息不足 —— 并由此分出三条技术主线：① 迭代精修（保留前馈效率、加轻量闭环）、② 注入生成先验（用扩散/流匹配补未观测区域）、③ 去像素耦合（体素/锚点/查询对齐，让图元数脱离图像分辨率）。

2研究背景与动机

2.1 逐场景优化 3DGS 的失败模式

失败模式一:训练成本与不可泛化

原版 3DGS 每个新场景都要从随机初始化跑一遍梯度优化（分钟~小时级），优化的产物只对该场景有效，换一个场景必须重来。这在需要「随手拍一段就出 3D」的场景里不可接受。

失败模式二:依赖可靠的相机位姿

逐场景优化通常要先跑 SfM/COLMAP 拿到标定位姿；位姿估计失败或精度不足时，整个重建链条崩掉（"garbage-in-garbage-out"）。

失败模式三:稀疏视角下退化

视角少时，优化式方法会过拟合到输入视角，新视角出现空洞、漂浮点（floater）与模糊。这正是前馈方法也想解决、但目前同样吃力的地方。

核心洞察:短板在「证据不足」，不在「渲染头」

DensiTok 明确把稀疏视角的质量瓶颈定位到重建头之前：从少量无位姿视角得到的内部表征，本身就没有关于未观测区域的证据，于是渲染出空洞、漂浮点与模糊。常见补救是「用图像/视频生成器合成额外视角再重新编码」，但这样既昂贵、又天然不保证 3D 一致。2026 下半年的主线，正是绕开这条昂贵路径去补证据。

2.3 三条补短板主线

① 迭代精修

保留前馈可泛化与低延迟，挂一个轻量 refinement 循环：渲染当前高斯 → 用渲染残差预测增量 → 更新。代表：InfiniSplat v2、DeltaSplat、GIFSplat。

② 注入生成先验

用扩散/流匹配生成未观测视角的表征（而非像素），避免"生成再编码"的昂贵与不一致。代表：DensiTok（latent 补全）、VidSplat、GIFSplat。

③ 去像素耦合

把高斯基元从像素网格解放到 3D 空间（体素格 / 锚点 / 稀疏查询 / 内容自适应分配），让图元数不再随分辨率与视角数膨胀。代表：CompactSplat、GrapeSplat、AnchorSplat、iLRM。

3前馈高斯重建总体框架

虽然各方法细节不同，但共享一条主干：图像编码 → 多视图融合 → 高斯解码 → 可微光栅化。三条主线分别作用在「融合」与「解码」这一段。

3.1 输入 / 输出定义

  • 输入：$N$ 张图像 $\{I_i\}_{i=1}^{N},\ I_i\in\mathbb{R}^{H\times W\times 3}$；位姿视方法而定 —— 早期需 GT 位姿，2026 新一代多为 pose-free（内部同时估计相机）；人物线额外可带参数化人体先验（SMPL-X / FLAME）。
  • 输出：一组 3D 高斯 $\mathcal{G}=\{(\mu_k,\Sigma_k,\alpha_k,c_k)\}_{k=1}^{K}$（位置、协方差、不透明度、颜色/球谐），可经可微光栅化渲染任意新视角。

3.4 几何基座谱系:VGGT → π³ → VGGT-Ω / DA3

前馈高斯方法并不从零学「图像 → 几何」。它们几乎都站在一个预训练的几何基座模型（geometry foundation model，下称基座）之上：基座负责从多视图恢复相机位姿 + 稠密几何（深度 / 点图），前馈头只负责把这份几何「翻译」成高斯。因此 VGGT / π³ / VGGT-Ω / DA3 不是本报告方法的同级竞品，而是整条链路的上游供给层 —— 基座升级一次，挂在它上面的前馈方法就可能「免费」受益。这也是本报告把它单独成节、放在总体框架里的原因。

一句话定位（四个基座各自解决了什么）

  • VGGT（2025-03）把「多视图图像 → 相机 + 点图 + 深度 + 轨迹」统一进一次前向，把「几何基座」做成了事实标准；
  • π³（2025-07）是对 VGGT 的减法改进：删掉 camera token 与帧索引位置编码，让架构本身排列等变（去掉顺序归纳偏置），速度与位姿精度双升；
  • VGGT-Ω（2026-05）是对 VGGT 的规模化升级：register 注意力压缩帧间二次复杂度 + 4M 监督 / 18M 自监督，首次验证前馈 3D 重建的 Scaling Law，并把训练显存压到原版 ~30%；
  • DA3（Depth Anything 3）是同期另一支头部路线：单目 RGB → 深度 / 相机，附 Gaussian head；在 Ω 出现前是几何轨道的次优参照。

为什么值得单独一节:基座是唯一「可跨任务替换」的先验

本报告第 7 节的共性观察与此处呼应：场景线用几何基座（VGGT / DA3）做位姿与几何蒸馏，人物线用参数化模板（SMPL-X / FLAME）做绑定，物体线用本征分解（IDM）做材质解耦。三条线里只有几何基座可以跨任务替换、且升级后下游「免费」受益。所以第 14 节把「把几何基座当作可替换先验，让前馈头随基座升级而受益」列为改进优先级之一（F-RNG 已示范「不重训基座」的思路）。据此，本方向的方法演进应当理解为「换更好的基座」+「补更好的头」两条腿并行，而非只卷解码器。

注意式 7 的关键约束：精修只更新属性、不改动高斯中心与数量（$\bm\mu_m^{t+1}=\bm\mu_m^0$），高斯数量由初始阶段一次性确定。

③ 前向流程（精修阶段）

  1. 用冻结几何分支 + 属性分支得到 $\mathcal{G}^0$（初始场景）；
  2. 把 $\mathcal{G}^t$ 渲染到目标视角，取渲染梯度 $\mathbf{g}^t=\operatorname{RenderGrad}(\mathcal{G}^t;\mathcal{I}_{\mathcal{F}},\bm\Pi^{\mathrm{fb}})$；
  3. 编码器 $E$ 融合 $(\mathcal{G}^t,\operatorname{sg}(\mathbf{g}^t),\mathbf{f})$ 得隐状态 $\mathbf{h}^t$；
  4. 更新器 $U$ 输出属性增量，$\operatorname{Apply}$ 写回；重复 $K_r\in\{1,2,3\}$ 步（推理默认 3 步）；
  5. 梯度经代理损失（式 17/18）回传——用 stop-gradient 构造代理，避免对光栅化直接反传的高开销。

4.2 迭代精修:DeltaSplat

DeltaSplat（arXiv:2610.09853，2026-10-07，成均馆大学 / 延世大学）把精修模块做成即插即用的轻量件（仅增 ~2.2% 参数），挂在 post-hoc 优化模型 YoNoSplat（由 π³ 初始化）之上。

① 结构

  • Backbone：YoNoSplat（π³ 预训练初始化），输出相机 + 初始像素对齐高斯；
  • Delta Decoder（权重共享，迭代 K 次）：
  • · Geometry-Guided Residual Encoding：残差(3)+渲染(3)+Plücker(6)+深度(1)=13 通道软几何先验，解 2D→3D 欠定；
  • · Dual-branch Mixer：Coarse 半分辨率膨胀卷积 + Detail 全分辨率轻量卷积，相加融合（比单分支快 1.84×）；
  • · Per-attribute Head：三个并行 MLP 解出 position/opacity/color，输出层零初始化。

② 公式与监督

  • (6) $\Delta^{(k)}=h_\phi(\{r_i^{(k)},\hat I_i^{(k)},d_i^{(k)},\ell_i\},\mathcal{G}^{(k)})$
  • (7) $\mathcal{G}^{(k+1)}=\mathcal{G}^{(k)}\oplus\Delta^{(k)}$
  • (9) $\mathcal{L}=\sum_{i\in\mathcal{C}\cup\mathcal{T}}\big(\|\hat I_i^{(K)}-I_i\|_2^2+\lambda_{\mathrm{lp}}\mathrm{LPIPS}\big)$，$\lambda_{\mathrm{lp}}=0.1$
  • 损失在 K 次精修之后计算，梯度穿过光栅化器与整个展开序列端到端反传。
  • 尺度 $s_g$、旋转 $q_g$ 全程固定，仅更新位置/不透明度/颜色。

③ 前向流程

  1. YoNoSplat 前向得 $\mathcal{G}^{(0)}$ 与相机 $p_i$；
  2. 渲染 context 视图，算残差 $r_i^{(k)}=I_i-\hat I_i^{(k)}$；
  3. 13 通道特征 → Delta Decoder → 属性增量；
  4. 写回得 $\mathcal{G}^{(k+1)}$；重复至 $K=3$。

④ 监督与结果

训练：DL3DV-10K；分辨率 224×224；context 6/12/24；50k 步；单张 RTX PRO 6000。DL3DV 上 6 视图 pose-free+已知内参达 26.64 dB（YoNoSplat 24.89，+1.75 dB），甚至超过给了 GT 相机的对照；精修 K=3 每场景仅 +~0.11 s。消融（Tab.4(b)）：K=0→24.80、1→26.02、2→26.45、3→26.64、4→26.48、5→26.32、6→26.17 —— K=3 最优，K 再大反而退化（对应耗时 54→266 ms）。【待核实】原文未给出代码仓库/权重链接。

4.3 注入生成先验:DensiTok

DensiTok（arXiv:2610.07958，2026-10-06，延世大学 / NAVER AI Lab / KIST）的做法很关键：不合成像素，而是直接稠密化内部 geometry token，让冻结的 backbone 「以为」自己看了更多视角。

模块作用关键维度
LAM-VAE 编码器把几何编码器多层特征压到紧凑潜变量空间（层级自适应融合 + VAE transformer + 层级残差）潜变量 $Z\in\mathbb{R}^{N\times K\times d_z}$，$d_z=4$；隐层 512，6 对 block
DiT 潜变量补全以观测潜变量 + 掩码 + 全 N 相机（编码为 Plücker 射线）为条件，用 rectified flow matching 单步补全未观测视角的潜变量隐层 768，12 对 block，12 头；每步重置观测视角为 $Z^{obs}$
Appearance Fusion用预测相机+深度 warp 观测图像得颜色先验，无效像素填可学习 missing-view embedding微调 $h_{img}$

损失（Stage 1 VAE）：$(\lambda_{feat},\lambda_{KL},\lambda_{rgb},\lambda_{perc},\lambda_{pose},\lambda_{depth})=(0.1,10^{-3},1,0.05,10,1)$；Stage 2 DiT：$(\lambda_{FM},\lambda_{rgb},\lambda_{perc},\lambda_{pose},\lambda_{depth})=(1,1,0.05,10,1)$。训练用 RE10K + DL3DV-10K，N=16，$n\in\{2,\dots,8\}$，4×RTX 6000 Ada。

为什么值得关注:插在「冻结编码器」与「重建头」之间的插件

同一模块设计可插入 AnySplat / WorldMirror / Depth Anything 3 三种 backbone，backbone 与重建头全程冻结。核心成果：仅 n=3 输入，AnySplat+DensiTok 在两个数据集的三项外观指标上全面超过 N=16 dense 参考（RE10K PSNR 22.47→24.28）。代价：时间 0.109→0.258 s、峰值显存 5.527→9.471 GB（N=2→16）。
明确局限（原文第 5 节）：只支持视图插值、不支持外插（虚拟相机仅在首末观测相机之间插值），保证不了区间外观视角的重建质量。【待核实】原文未给代码/权重链接，仅项目页 hydragon.co.kr/DensiTok。

4.4 去像素耦合:CompactSplat 与 GrapeSplat

CompactSplat（NeurIPS 2026 · arXiv:2610.13177 · 上海交大）

打破「每像素 1~N 个高斯」的均匀分配，改为内容自适应：

  • TAP 分区器：按通道强度极差 $\Delta(B)=\max_c(\max_{B}I_c-\min_{B}I_c)$ 做四叉树递归划分，叶节点给归一化中心 + 尺寸 + LoD；
  • HPS 采样器：按 LoD 路由到尺度金字塔层做 GridSample，尺度调制 $\mathbf{s}_k=\Delta\mathbf{s}_k\odot\mathbf{b}_k$；
  • 复杂区域密集高斯、平坦区域用「放大尺度」高斯平铺；
  • 推理时阈值 $\tau$ 动态控稀疏度，单一 checkpoint 遍历质量-紧凑度 Pareto 前沿，无需重训；
  • RE10K：GPP 仅 0.554（SurfSplat 1.000）却达 26.39 PSNR；总损失 MSE + 0.05·LPIPS。
  • 注意：CompactSplat 需要已知内参+外参（非 pose-free）。

GrapeSplat（arXiv:2609.23182 · 台大 · ✅ 开源）

把多视图线索融合进体素对齐表示，直接从学到的网格解码高斯：

  • Atlas Encoder：把各视角提升为锚定在预测 3D 点上的逐像素几何+外观特征；
  • PEACH-Vox：用带精确闭式逆的平滑逐轴映射，把无界场景压进有界稀疏网格；
  • Sparse Decoder：稀疏卷积从每个被占据体素解码多个高斯；
  • 高斯数量跟随占据体素、随视角覆盖饱和，不再绑图像分辨率与视角数；
  • 8 视图训练（2D+3D 监督），零样本泛化 4→64 视图；无需位姿、无需后处理。

另有 AnchorSplat（CVPR 2026，锚点对齐 + Gaussian Refiner）、iLRM（见 6.2）同属这条路线。【待核实】GrapeSplat 部分数字取自 arXiv HTML 摘要，未逐表核对。

6物体重建线与可重光照

物体线要区分两条不同的路：重建（从已知图像恢复物体几何/外观）与生成（从单图/文本凭空生成物体）。前馈高斯重建属于前者；生成式 LRM 系属于后者，选型时不能混。

6.1 以物体为中心:ParticleSplat

ParticleSplat（arXiv:2609.19463v1，2026-09-16，CMU Robotics Institute：Lyuxing He / Daniel Guo / Elizabeth Terveen / Deepak Pathak / David Held / Tal Daniel）把「以物体为中心」的先验注入前馈高斯重建，是物体线里少见的自监督方案。

思路与结构

  • 基于 Deep Latent Particles (DLP)：把图像表示为一组带位置/尺度/外观属性的「粒子」；
  • DLP 本质是 2D 的，无法做显式 3D 空间与几何推理 —— 本文补上这一维；
  • 前景粒子属性从 DLP 的 $6+d_{obj}$ 扩到 $7+d_{obj}$：新增 depth extent $z_e$，控制粒子沿视线的厚度；
  • 编码器 $q_\phi(\mathcal{Z}\mid\mathcal{O})$：可微空间 softmax → STN 取局部 glimpse → CNN 预测属性 → Plücker 射线嵌入做相机条件化 → 跨视图注意力精炼；
  • 解码器三步走：粒子 → 规范高斯 patch → 图像平面高斯（协方差经雅可比 $\mathbf{\Sigma}'=\mathbf{J}\mathbf{W}\mathbf{\Sigma}\mathbf{W}^T\mathbf{J}^T$）→ 世界空间 3D 高斯；背景另用 $H\times W$ 稠密像素对齐高斯；
  • 表达极省：$L=20$（RLBench）/ $40$（真实）个粒子即可重建整场景，标称压缩比 819.2×。

能力与结果（已核实）

  • 无需掩码监督，自监督学出物体分解；可在 latent 里改粒子做 3D 场景编辑；
  • NVS（表 1）：RLBench 1×RGB-D PSNR 25.35；2×RGB-D 28.77；真实场景 2×RGB 24.24；
  • 语言条件 RLBench 模仿学习（表 2）：Overall 成功率 73.0%，DLP 46.6%、GNFactor 31.7%；
  • MimicGen 多视图（表 3）：Overall 56.1%（DLP 34.1%）；
  • 运行时（A.5.1）：单视图峰值 251.1 MiB / 30.91 ms；两视图 347.3 MiB / 33.65 ms；
  • 训练（A.4）：50,000 步、batch 8、lr 8e-5、单张 A6000，RLBench ≈30 h、真实数据 ≈2 h。

硬约束：① 训练与推理都需 GT 相机位姿（消融去掉位姿条件后 PSNR 25.35→23.91）；② 粒子预算 $L$ 固定，超预算的物体会被吸收进背景；③ 深度监督在单视图下至关重要（去掉后 25.35→19.63），多视图下影响很小。代码与视频见项目页 lyuxinghe.github.io/ParticleSplat-website/（权重发布未提及）。

6.2 可扩展性:iLRM

iLRM（arXiv:2507.23277v3，2025-07-31 首版 / 2026-05-31 修订，成均馆 + 延世 + Rembrand + Meta：Gyeongjin Kang 等 7 人）针对 Transformer 类前馈重建的可扩展性瓶颈：全注意力跨多视图图像 token 的复杂度是 $O\!\big(N^2(hw)^2\big)$，视角数或分辨率一涨就爆。

  • 解耦场景表示与输入图像：紧凑的 viewpoint tokens（由 Plücker 射线嵌入按 $p=8$ patch 切分后线性投影）与高分辨率 image tokens 分离，输出高斯的 $H^v W^v$ 不绑定输入分辨率；
  • 每层 = 1 个 cross-attention + 1 个 self-attention，共 12 个 update layer、隐藏维 $d=768$、12 头：cross-attention 让每个 viewpoint token 只对自己那张图的 image token 一对一细化，self-attention 再做跨视图全局聚合；
  • token uplifting（$k=2$）与 mini-batch cross-attention（Quarter 版）进一步压算力：16×256² 输入下相对算力比 (a):(b):(c):(d) = 1 : 1 : 0.25 : 0.08；
  • 容量与速度（表 1，RE10K）：8 视图 PSNR 31.57 / 131,072 高斯 / 0.028 s / 185 M 参数，优于 GS-LRM（28.10）与 DepthSplat（27.47）；
  • 可扩展性（表 3/4，DL3DV）：24 视图 PSNR 27.38、仅 2.01 GB、0.123 s；12 视图 @512×960 用 1,474,560 高斯 / 3.53 GB，而 DepthSplat 在此设置直接 OOM；
  • 宽覆盖（表 5，540×960）：32 视图 0.53 s / 24.30 dB，快于 Long-LRM（0.84 s / 23.97）。

训练：AdamW（$\beta_2=0.95$、wd 0.05）、峰值 lr 2e-4、warmup 2500；主力配置 8×H100、batch 256、50k 步（4 视图版用 8×RTX 4090、batch 128、100k 步）。损失为 MSE + 感知，$\lambda=0.5$。

局限：① 需准确相机位姿且仅限静态场景；② 视角数很大时自注意力仍是瓶颈；③ 以渲染监督为主，几何精度可能弱于显式几何监督方法。与 §4.4 的 CompactSplat、GrapeSplat 同属去像素耦合思路：把「每个像素一个高斯」改成「先有一组紧凑 3D 锚点/查询，再长出高斯」。

F-RNG（arXiv:2605.25975v2，2026-05-25 首版 / 05-28 修订，南开 + 南大 + NVIDIA：Guangming Fu† / Jiahui Fan† / Jian Yang / Miloš Hašan / Beibei Wang‡）解决前馈高斯的一个实用缺口：光照烘焙死，无法重打光。

6.5 物体线小结

物体线的「前馈高斯重建」体量明显小于场景线与人物线：ParticleSplat（以物体为中心的语义分解）、iLRM（可扩展性）、F-RNG（可重光照）分别代表了「语义 / 规模 / 材质」三个正交方向。真正的「物体级前馈高斯重建」在 2026 下半年更多以 场景级方法的小场景变体（GrapeSplat 的 DTU 实验即为一例）出现，而非独立范式。

9.2 落地坑（按踩坑概率排序）

  1. 数据集门槛 > 模型门槛：RE10K / DL3DV / Objaverse 等训练集动辄几百 GB~TB，多数方法只放权重、不放数据。想复现训练几乎不可能，实用姿势是"用官方权重 + 自己的数据做推理/微调"。
  2. 输入假设必须对上：Tele360 假设"4~6 路无位姿 2K 环视"，HumanGS 假设"稀疏多视 + SMPL-X 参数"。把单目随手拍的图喂给这些模型，效果会断崖式下跌——先确认输入假设，再谈效果。
  3. 参数化模板的授权问题：SMPL-X / FLAME 需在官网申请并遵守许可，商业使用前必须确认，否则只能走 Tele360 那类"无模板"路线。
  4. 高斯数量爆炸：去像素耦合（CompactSplat/GrapeSplat/iLRM）的动机之一就是压高斯数；直接照搬"每像素一个高斯"在大分辨率下显存与光栅化都会崩。
  5. 光照烘焙死：绝大多数前馈高斯把光照烘进球谐（SH）里，换环境光就废。需要可重光照时，得选 F-RNG 这类显式解耦本征的路线。
  6. 位姿依赖：需要相机位姿的方法，位姿误差会直接传导成几何误差；无位姿方法（Tele360）则把这份不确定性换成了对基座模型（VGGT）的依赖。

11消融实验

前馈方法最值得看的消融，是"砍掉哪个组件会掉多少"——它直接说明该组件是不是真卖点。

ParticleSplat：位姿 / 深度 / 表示设计

  • 位姿条件化（表 8，RLBench NVS）：去掉后 2×RGB-D PSNR 28.77→27.62、1×RGB-D 25.35→23.91，两个设置都有效；
  • 深度监督（表 8）：单视图去掉后 25.35→19.63（崩），多视图去掉后 28.38（几乎不掉）—— 深度只在单视图下救命；
  • 表示设计（表 11，单视图成功率）：VAE-GS 42.0 < DLP 46.6 < Ours 73.0，说明增益来自「object-centric 结构 + 显式 3D 信息」的组合，而非仅重建目标。

iLRM：架构 / 规模 / mini-batch

  • 逐层跨注意力（Fig.10）：去掉迭代精修 29.24→28.58；去掉分辨率解耦 →28.47；去掉 token uplifting →28.90；
  • 自注意力（表 7）：去掉后 29.24→23.33（全局依赖不可省）；换 group-attention 无增益还带回二次复杂度；
  • 模型规模（Fig.9）：12 层 185 M 29.24 > 9 层 29.01 > 6 层 28.68 > 3 层 28.04，层数≈优化步数；
  • mini-batch cross-attn（表 6）：Quarter 版仅掉 30.39→30.08，迭代时间 1.51→0.94 s、显存 62.5→39.0 GB、算力 3.83→0.81 GFLOPs。

  • 完整模型 32.44 → 去掉 IDM 先验 31.21（降幅最大，外观无法合理分解光照 / 材质）；

  • HumanGS（表 S2）：1 高斯 vs 1 tight+4 free，LPIPS 30.66→30.81（TH2.1）、0.028→0.024，四个数据集一致提升，验证 free 高斯对宽松衣物 / 头发的价值；

12.1 对比结论

  • 输入假设是第一条分水岭：有无位姿（Tele360 无位姿 vs iLRM / ParticleSplat / F-RNG 需位姿）、有无模板（HumanGS / FFAvatar / SpatialAvatar-0 要 SMPL-X / FLAME vs Tele360 无模板）、图像数（单图 / 1~K / 1~N / 4~6 路同步 / 6 稀疏视图）——三条轴一交叉，适用场景几乎不重叠。
  • 实时性靠"去像素耦合"：想在高分辨率下维持实时，必须走 GrapeSplat / CompactSplat / iLRM 的紧凑表示，而不是"每像素一个高斯"。iLRM 在 24 视图下只用 2.01 GB，而 DepthSplat 同设置直接 OOM，是最干净的对照。
  • 可动画靠"参数化绑定"：要驱动、要动画，人物线基本只有"模板绑定高斯 + LBS"一条成熟路径（HumanGS / SpatialAvatar-0 / FFAvatar）。代价是显式收窄——VFAvatar 自己就承认 canonical SMPL-X 表示难以表达裙子等偏离人体拓扑的服装。
  • 可重光照靠"本征解耦"：只此一家（F-RNG），且它是架在别人 LRM 之上的插件，不自己训基座；代价是显存随视图数 / 分辨率增长，只能固定用 6 视图。
  • 训练成本的量级差：单卡可复现（HumanGS ~32 h / 单 RTX 6000、ParticleSplat ~30 h / 单 A6000）↔ 重资产（Tele360 8×A100、SpatialAvatar-0 单 H100 NVL 14 天、iLRM 8×H100）。选型时"能不能训得动"往往比"指标高多少"更决定性。
  • 开源率低：表内 13 项中明确开源仅 3 项（HumanGS / VFAvatar / GrapeSplat），另 3 项只有项目页（FFAvatar / SpatialAvatar-0 / iLRM），其余未放出代码——研究与落地之间存在明显的时间差。

13🎯 应用场景与落地适配性

选型建议按"输入假设能不能满足"倒推，而不是按指标高低排序。

✅ 适合前馈高斯重建

  • 批量三维资产生产：一次前向出高斯，适合规模化（电商商品、数字孪生）。
  • 实时环视 / VR 直播：Tele360 类无位姿实时方案。
  • 虚拟人 / 数字分身：HumanGS / VFAvatar 类，模板绑定 + LBS 动画。
  • 需要重光照的合成：F-RNG 类，把光照解耦出来。
  • 机器人感知 / 抓取：ParticleSplat 类物体中心语义分解。

⚠️ 暂不适合 / 需谨慎

  • 超大规模城市级场景：前馈模型训练分布外的尺度容易崩，仍宜逐场景优化。
  • 需要极高保真单场景：逐场景优化的 3DGS 至今在 PSNR 上限上仍有优势。
  • 无对应训练数据的长尾物体：泛化靠数据覆盖，长尾品类效果无保证。
  • 商业用途 + 需 SMPL-X/FLAME：先解决模板授权。
  • 要求可复现训练：数据未开源的方法几乎无法从零复现。

14可改进方向分析

三个维度：数据与泛化、表示与效率、能力边界。

14.1 数据与泛化

  • 训练集仍是瓶颈，且"数据即天花板"——合成数据（Objaverse/RLBench）到真实场景的域差没有系统性解法。
  • 可改进点：把几何基座（VGGT/DA3）当作可替换先验，让前馈头随基座升级而"免费"受益（F-RNG 已示范这种"不重训基座"的思路）。

14.2 表示与效率

  • 去像素耦合已有成效，但紧凑表示的表达上限尚未探明：锚点/查询数压到多低仍不掉质量？
  • 可改进点：动态分配锚点密度（前景密、背景疏），而非全局统一。

14.3 能力边界

  • 光照烘焙死 + 模板授权 + 无位姿依赖基座，是当前三条最硬的边界。
  • 可改进点：把"可重光照"做成前馈重建的默认能力（而非事后插件）；把"无位姿"与"可动画"结合（目前互斥：无位姿方案不做 LBS，可动画方案需模板位姿）。

15.2 领域演进定位

把三条主线与场景/人物/物体三个应用面交叉，可以看出：通用/场景线是"方法论创新主战场"（①③），人物线是"落地能力主战场"（模板绑定 + 前馈），物体线则更多表现为"专项能力插件"（语义/规模/材质）。前馈高斯重建不会取代逐场景 3DGS，而是与之分层共存——前馈管"快速拿到一个还不错的通用结果"，逐场景优化管"在单场景上榨到极限"。

给 vggt_human 的启示：人物线的两条成熟路径——(a) Tele360 式"无位姿 + 几何基座蒸馏"，(b) HumanGS 式"模板绑定 + LBS 动画"——恰好对应"采集端省事"与"驱动端可用"两个诉求。若目标是"随手拍即可驱动的数字分身"，当前最缺的正是把这两者合一的方案（见 §14.4 P0）。
