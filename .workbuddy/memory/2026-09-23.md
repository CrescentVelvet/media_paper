### 本轮值得留存的核心概念
- **蚂蚁几乎不直接啃食植物**。获取植物能量只有三条绕行路径:通过植食性昆虫的蜜露、通过栽培真菌、通过种子。切叶蚁"啃叶子"在因果链上错两环(不为自己吃、也不消化植物)。
- **"行军蚁综合征" ≠ 单系**。Dorylinae(Eciton/Dorylus)、Ponerinae 的细猛蚁属、Myrmicinae 的全异蚁各自独立凑齐"群体劫掠 + 游牧 + 特化蚁后",判据是"在系统树上不构成单系群却具备同一功能组合"。
- **"农业"在昆虫中被独立发明三次**:真菌栽培蚁 Attini / 培菌白蚁 + *Termitomyces*(国内可见的产物是**鸡枞菌**)/ 食菌小蠹。三者共用同一配方:垂直传播菌种 + 定向喂养 + 病害管理。
- **蚂蚁不捕食健康成年脊椎动物**,而反方向存在一整条"食蚁哺乳动物"支线(食蚁兽 / 土豚 / 穿山甲 / 袋食蚁兽),共享"无齿 + 长舌 + 强前爪 + 发达嗅觉"的趋同方案。蚁鸟吃的是被蚁群惊飞的昆虫,**不是蚂蚁本身**。
- **阿根廷蚁超级群体的正反馈机制**:入侵地遗传多样性低 → 巢间体表碳氢化合物识别信号同质化 → 不再互斗 → 资源可共享 → 连成巨大协作网络 → 进一步推动入侵。
