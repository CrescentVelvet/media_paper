## 同事 DA3+2DGS 实验情报(用户转述,未经一手验证)

- 现象:DA3 重建精细但有 floater/重影(归因跨视角位姿不一致);QuerySplat 无 floater/重影但模糊。
- 同事方案:冻结 DA3 几何骨干 + 低分辨率 2DGS 几何分支 + 高分辨率纹理分支(纹理清晰度↑);加带范围约束的像素中心 offset 与深度 offset(重影/floater↓)。
- 我的分析结论(2026-11-05):= 手工版 QuerySplat 解耦;2DGS 低通几何分支 + 高分辨纹理分支做属性解耦;**有界 offset = 信任域硬约束**,比 QuerySplat 软 CD loss(仅前 20K 步、全程施加失稳)更稳,把位姿错位吸收为局部亚像素位移;复现建议先 per-scene 优化版(组件全开源,DA3 Apache 2.0),前馈版需蒸馏;改进方向:显式 pose residual 联合优化(治根)、置信度自适应 offset 界、多视角 anchor 清洗、2DGS 原生 distortion/normal 损失、动态物体 visibility gating。
- 该方案若成,恰是笔记 §15"DA3 换 VGM"路线的实证——后续值得写进 QuerySplat 笔记或独立笔记。
