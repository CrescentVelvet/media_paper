## DensiTok(arXiv 2610.07958)深度调研笔记入库(commit 968965e)

- **论文**:DensiTok: 在 geometry token 空间补全未观测视角(延世大学 / NAVER AI Lab / KIST,共同一作 Minhyeok Lee + Jungho Lee,通讯 Sangyoun Lee)。abs 无 comments、仅 v1 → 不加会议徽章。GitHub `Hydragon516/DensiTok` 仅 README + assets → **无源码无权重**。deep 级笔记 `3D-20261006-DensiTok.html`,18 节,配图 9 张本地化 `images/2610.07958/`。
- **核心机制**:插在 geometry encoder 与重建头之间,encoder 全程冻结。① LAM-VAE 层级自适应调制把 L 层 × 2048(DA3 3072)通道压到 **$d_z=4$**,层级残差只注均值不注方差;② 相机条件 DiT 用 rectified flow matching 补 latent,每步把观测视角重置回 $\mathbf Z^{\mathrm{obs}}$,每 block 经 AdaLN 把 time + cam 嵌入**相加**;③ 相机双轨(训练 GT×单因子缩放 / 推理预测相机中心样条 + 旋转 slerp,**只插值不外推**);④ 外观 warp 支路仅 AnySplat 明确需要。三个 backbone 各训一套,共 420k 步(200k+200k+20k)。
- **核心论点**:「缺的不是像素而是 token」——$n{=}3$ 时 AnySplat 24.28 超过自己 $N{=}16$ 稠密参考 24.04,证明瓶颈在 token 不在头。
- **⚠️ 本次最大发现(已写入 §14.1 第 ⑥ 条 + §12 note):原文内部两套表数字不可混用**。同一 AnySplat $n{=}3$,Table 1 是 24.28、Table 7 是 26.919;WorldMirror $n{=}2$ 是 22.06 vs 25.079(差近 3 dB)。**根因是原文 C.4 自己写的**:Table 7 改 256 评测 → "we perform test-view sampling again. The resulting sampling indices differ from those used in Tables 1 and 6" —— 即**重抽了测试视角**。所以差值既非笔误也非单纯分辨率缩放。**教训:遇到同一方法同名 $n$ 两套数,先去附录找"是否重采样"的说明,别急着猜分辨率。**
- **分辨率三套并存(已补进 §11 C.4 段)**:主表 Table 1/6 用 **$294\times518$**(高宽恰好都是 14 的倍数,不需 resize,是**最干净的评测**);Table 7 在 $252\times252$ 推理 → resize 到 256;Table 8 在 $504\times504$ → resize 到 512。**反直觉:为了和别人可比,补全方法反而要在两张对比表里"降级"评测。**
- **溯源表修正**:Table 7 实为 10 个 baseline + 3 个 DensiTok 变体,不是 15 个方法(各方法只在自己官方实现支持的 $n$ 上出现,Splatt3R 仅 $n{=}2$、SelfSplat 仅 $n{=}3$)。papers.json summary 同步修正「n=3 超过各自稠密参考」的错误表述——WorldMirror 要到 $n{=}7$ 才超过。
