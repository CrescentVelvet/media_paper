- **论文**:arXiv 2507.05678 v1(2025-07-08,唯一版本),Zhejiang University · DAMO Academy Alibaba · Hupan Lab。项目页标注 ICCV 2025,但 **arXiv abs 页 comments 字段为空** → 按 AGENTS 规范**未在 papers.json 加会议 badge**,只在笔记正文标注来源。
- **代码状态**:项目页 publication-links 4 个链接里 `Code` 的 href 是 `https://fuchengsu.github.io`(作者个人主页),`Supplementary` 的 PDF 实测 404 → **代码/权重/补充材料三缺**。工程细节章节全部转引论文 §4.1,并显式声明可信度低于有源码笔记。
- **核心内容**:把 LoRA 融合当向量空间问题治理。两条真技术 = 逐层范数归一(式4,零参数一行除法)+ 缩放 token(式6–7,把运动幅度 S 经傅里叶编码拼进 token 序列);第三条"正交性"**只被测量(浅层余弦相似度 0.06±0.06)未被任何约束实现** —— 这是本笔记最重要的判断,写入摘要疑点卡与可改进方向首条。
- **发现的两处论文硬伤**:
  1. §4.3 称 FVD "较 CamI2V 降 37.8%",但表 1 CamI2V=294.6 → 实为降 53.8%;37.8% 与 CameraCtrl(218.9)吻合(且同句 "49 frames vs. 16-frame" 指的就是 AnimateDiff 骨干的 CameraCtrl)。标【待核实】。
  2. ATE 降幅 21.5% 按表 1 任何基线都推不出(CamI2V→20.3%,DimensionX-S*→17.8%),论文未指明基准。标【待核实】。
- **其他关键事实**:仅 3 类离散相机原语(平移/前后/环绕);复杂轨迹 RotErr 1.044 **输给 CamI2V 0.924**(论文自承 "except RotErr");DimensionX-S* 是作者自实现版本,对比对本文有利;表 3 显示 7k 样本 @4k 步(RotErr 1.227)反而劣于 100 样本 @4k 步(0.802),论文只讲有利的一半。
- **交叉链接**:SCoPE / UCPE(相机编码"加法 vs 乘法"对偶,与本篇构成"注意力空间 vs 参数空间"分工)、World-R1、两篇调研汇总、CogVideoX(骨干)。

## DMD2 (arXiv 2405.14867) deep 级调研笔记(新笔记 1 篇,累计 74)

**产出**:`ImageGen-20240523-DMD2.html`(deep,16 节;原名 `CV-AI-20240523-DMD2.html`,同日前缀体系重构改名)+ `images/2405.14867/`(13 张全部本地化)+ `papers.json` / `index.html`。commit af32e65(调研)+ 前缀重构 commit(见下节)。

- **论文**:Improved Distribution Matching Distillation for Fast Image Synthesis,MIT + Adobe(NeurIPS 2024 Oral,项目页/GitHub 标注;abs comments 为空 → 按规范 badge 不标会议,正文记录)。
- **仓库源码核验**(`tianweiy/DMD2`,克隆到临时目录):
  - **宣称 vs 实现差异(笔记已标【存疑】)**:"消除回归损失"是标题级卖点,但 SDXL **1-step** 路径仍需 10K 对 ODE 噪声-图像对的回归预训练初始化 + timestep shift(条件步 399)抗 block noise;只有 4-step 路径完全无回归。论文未对 1-step 该依赖做消融。
  - **TTUR 实现**:`train_sd.py:330` 的 `COMPUTE_GENERATOR_GRADIENT = step % dfake_gen_update_ratio == 0`(ratio=5;SD v1.5 是 10——TTUR 频率随 backbone 变,非全局常数)。
  - **GAN 权重补全**:论文附录只写 ImageNet 3e-3 / SD1.5 1e-3,SDXL 值论文未写 → 从 `experiments/sdxl/*.sh` 的 `gen_cls_loss_weight 5e-3` 拿到。
  - **判别器结构**:fake UNet bottleneck(1280ch)上接 3×(Conv k4 s2 + GN + SiLU) + Conv k4 s4 池化 + Conv k1 分类头(`sd_guidance.py:108-122`);`classify_forward` 返回 down/mid 特征列表取末项(`sd_unet_forward.py:249-251`)。
  - **Model Zoo 训练时长**(README):SDXL 4-step 19K iters/57h/FID 19.32;1-step 24K/57h/19.01;ImageNet 主线 200K/53h/1.51,加长 resume +140K/38h/1.28。
- **消融的关键解读**:SDXL 表 4 纯 GAN 变体 FID 13.77 看似最好但 CLIP 0.307 崩、patch FID 最差 → 论文自己点破"单看 FID 会被纯 GAN 蒸馏误导",已写入笔记 callout。
- **交叉链接**:Lyra2(DMD 4 步 194s→15s,但官方建议质量优先时关闭)、ArtiFixer(Phase II = Self-Forcing 式 DMD)——两篇都是 DMD 框架向 3D/视频域的迁移,构成库内脉络。
- **工具坑**:Write 工具单次写入约 15KB 会静默截断(报"参数缺 file_path"或 JSON 解析错,不提示真实原因)→ 大 HTML 写法:**先写小骨架(样式+Hero+目录+`<!-- APPEND -->` 占位),再用 Edit 把 `<!-- APPEND -->` 替换为各章节内容逐段追加**,最后删占位符。
