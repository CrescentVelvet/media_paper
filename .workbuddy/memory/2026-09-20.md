2. **孤儿图处理**:`action_model.png`(Figure I(b)) 与 `firstdepth.png`(Figure II) 下载了但未引用 → 选择**挂进已有对应段落**而非删除(§11.4 动作条件对比、§9.6 首帧深度),比删掉更有价值。
3. **图号重排**:中途插入新图会让 `图N` 与文档顺序脱节。做法:正则 `<b>图(\d+)(\(` 捕获图注、用映射表批量替换(避免链式碰撞),替换后校验位置序列严格递增 + 无重号 + 交叉引用同步。**注意:笔记内可能已有同题材图(本次 §15 的图10 就是同一张 invsible.png),插入前先查重**。
4. **stat 卡的孤立错误**:OctWorld stat 卡写"3.1–2.0× 重投影 PSNR 提升",但 23.47 vs 22.08 只差 +1.39 dB,论文全文无任何 3.1× 表述 → 已改。**教训:stat 卡这类"提炼数字"最容易脱原文,核对优先级应高于正文表格**(正文表格本次逐格对比全部命中)。
5. **papers.json summary 的隐形约束**:全库其余 67 条 summary 只用 `<strong>`,**无 `<a>`、无 LaTeX**。新写的两条原本带了链接与 `$...$`,已改为纯文本以保持一致(避免 index 卡片渲染异常)。
6. **宿主注入的 current_time 可能过时**:本次会话跨天(09-18 起),注入值是 09-18 而系统时钟已是 09-20;index.html 生成日期与笔记内"截至本笔记撰写"日期都用系统时钟,两者一致。**判断"今天是哪天"以系统时钟为准**。
