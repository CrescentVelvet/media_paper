## 峰哥咨询:bilateral grid 用于人像重建出现"人脸红润变灰白"
- 场景:另一台服务器的人像重建 pipeline(3DGS 系)加入 BiLaRF 式逐视角仿射网格后,面部色度丢失。
- 给出的根因判断:grid 容量过剩 + 收敛快于辐射场 → 把跨视角不一致的肤色色度当 ISP 残差吸收(color stealing,与 GLO 同源);人像场景 AE/AWB 以人脸为测光基准,肤色恰是跨视角变化最大区域,最易被偷。
- 调参方向:降空间分辨率(16×16→4×4/8×8)、TV 权重 10→30~100、加 identity L2 正则、grid 降 lr/延迟激活、渲染时用参考视角 grid 回烤色调;根治靠采集端锁 AE/AWB。

## 追问:服务器上的 reg_loss(identity L1 锚定,1e-2)官方有吗?
- **四仓库全量验证,均无 reg_loss**:yuehaowang/bilarf(全部 6 个 commit `git log -S` 无命中,网格相关损失只有 `bilateral_grid_tv_loss` @ train_utils.py:252 / `bilateral_grid4dcp_tv_loss` @ :262)、nerfstudio v1.1.4(同,只有 TV + `_init_identity_grid`)、zipnerf-pytorch(无 bilateral grid 代码)、bilateral-driving(论文提 circle 正则但开源代码 bilateral/ 目录未释放该 loss)。
- 结论:官方只靠**恒等初始化**,没有任何恒等锚定正则;峰哥服务器上的 reg_loss 是自定义死代码,恰好就是推荐的 identity 正则,值得接线启用。
- 给的建议:先核对锚定范围(12 通道全锚 vs 只锚对角)、sum/mean 口径(24576 系数)、L1+Adam 的 sign 行为;只在 3D 训练阶段用,finishing/编辑阶段禁用;λ 从 1e-4/1e-3/1e-2(mean 口径)扫。

## 峰哥补充实验现象,问 reg 是否会伤衣服均匀性
- 现象:不开 grid → 逆光衣服黑白斑驳且随视角变;开 grid → 衣服整体泛白但均匀,面部红润变灰白。
- 判断:两症状住在仿射参数不同子空间——衣服斑驳是**亮度/曝光方向**(grid 本职,证据强、幅值大),红润丢失是**色度方向**(机会主义偷色)。"衣服均匀但泛白"说明衣服色度也被偷了,只是面积大不明显。
- 建议:① 均匀 L1 存在可用 λ 窗口(L1 阈值先杀弱证据的色度偷取);② 更稳的是把 reg 改成**选择性锚定**——分解 A = s·I + C,亮度标量 s 与 offset 弱锚/不锚,色度部分 C(非均匀缩放部分)强锚;③ 最激进方案是纯曝光 grid(2 参数/cell),前提是采集锁 WB。扫描时双指标监控:人脸 (R−G) 均值 + 衣服跨视角一致性。
