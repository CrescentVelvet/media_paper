### 本轮的切分轴(可复用)

没有按"时间/会议/数据集"切,而是按**视频生成模型在重建链路中承担什么角色**切,得到六条路线:

| 路线 | 角色 | 代表 | 补的缺口 |
|---|---|---|---|
| A | 虚拟相机阵列(生成多视角视频→4DGS) | 4DAnyone / Flex4DHuman / Diffuman4D / MV-Performer / Human4DiT / CAT4D / SV4D / 4DVD | 视角缺失 |
| B | 潜空间接口(绕过 RGB) | Latent-to-4D (Beyond Pixels, 2608.10744) | 接口错配 |
| C | 补全器 / 伪监督源 | AHOY! (2603.17975) / StudioRecon (2607.09125) | 观测缺失 |
| D | SDS 训练信号 | PhyGenHOI (2605.30268) / Animate3D / AKD / DreamPhysics | 监督缺失 |
| E | 确定性几何编码器(非生成式) | DreamHand (2608.20308) | 几何/运动线索缺失 |
| F | 动态外观生成(texel 空间) | AvatarDynamizer (2608.19900) | 表面动力学缺失 |

配套的缺口框架(写进 §2):视角缺失 / 观测缺失 / 监督缺失 + 第四项**接口错配**。这个四缺口框架可复用到其它"生成辅助重建"类调研。

### 三条实质结论

1. **路线 A 是主战场,且 2026 年的竞争焦点已从"模型能生成什么"转到"上下文怎么管"。** DiT 单次前向能容纳的目标视角数有上限,超限必须分组 → 参考侧成本 O(N) 膨胀 + 目标侧组间结构漂移(4DAnyone 的 bounded-attention-context 诊断)。四种工程解:滑动迭代去噪(Diffuman4D)、RCP+TCR(4DAnyone)、级联解耦(4DVD)、历史 token rollout(Flex4DHuman)。
2. **路线 E/F 是 2026 年才出现的"非生成式复用",性价比可能更高。** DreamHand 把 VDM 从随机多步渲染器降级为确定性编码器(clean latent 单次前向 + 双向时空解码),ARCTIC MPJPE-p -30% / HOT3D -40%;AvatarDynamizer 把动力学挪到 2D texel 空间做条件图生图,绕开 3D 一致性难题。
3. **路线 C 的人机分工对自采数据最实用。** StudioRecon 原文明说"video diffusion 对人体会给出几何不一致的结果",于是只让扩散管背景(合成数百视角做稠密监督),人体走身份关联 + 关键点三角化初始化。比端到端生成更接近可交付工程。

### 核到的硬数据(均已写入笔记并标来源)

- 4DAnyone:DNA-Rendering PSNR **24.33**(对比最好 21.47)、DyMVHumans **21.03**;MVGameHuman 38k 视频 / 24 相机 / 318 actors;backbone Wan2.2-TI2V-5B;128×H20-3E;三阶段 curriculum 0.5/1/1.5 天。
- Diffuman4D:4 路 → **44 路**,150/225 帧;样本网格 (N+M)×T;开源重标注 DNA-Rendering **1000+ 序列 × 48 相机 × 225(150) 帧 ≈ 千万图**;LongVolcap 未开源,官方给 splatfacto 3DGS 替代。
- Flex4DHuman:Wan2.1 **1.3B** backbone;36 通道输入布局(16 噪声 latent + 16 条件 latent + 4 二值 mask);五轴位置编码(时空 RoPE + 视角索引 + 连续 SE(3) / PRoPE);三阶段课程。
- Latent-to-4D:约 1K 条重建 clip 训练;vs 同 latent Wan+4RC 级联,DINO-F1 **+2.88~3.45**(Text4D-200)/ **+5.81**(I4D-200)。
- AvatarDynamizer:自建 DynaHuman **58 actors × 100 台 4K 相机 × 约 27000 帧/序列**。
- StudioRecon:4 路低重叠(约 90° 分布)、未标定;SIGGRAPH Conference Papers 2026,DOI 10.1145/3799902.3811165。
