1论文摘要

前馈式 3D 高斯溅射(3DGS)方法在人体新视角合成的实时渲染中展现了卓越能力。然而,现有方法要么局限于稠密视角配置,要么受限于较低的图像分辨率,这阻碍了它们在大视角差下的自由视角渲染能力,也限制其在常用 GPU 上实时恢复精细人体细节的能力。

为解决上述问题,本文提出 EVA-Gaussian —— 一个面向多样化多视角相机设置的 3D 人体新视角合成新管线。其三大核心设计为:

  1. 高效跨视角注意力模块 (Efficient cross-View Attention, EVA):在高分辨率输入与稀疏视角设置下有效融合跨视角信息,同时最小化时间与计算开销;
  2. 特征精修机制:为每个 3D 高斯赋予特征向量,通过循环 U-Net 精修器纠正位置估计几何误差导致的伪影,增强整体视觉保真度;
  3. 锚点损失 (Anchor Loss):正则化高斯的不透明度、尺度,以及人脸关键点位置一致性。

在 THuman2.0 与 THumansit 数据集上的实验表明,EVA-Gaussian 在多样化相机设置下的渲染质量上具有显著优势。

2研究背景与动机

2.1 现有方法的局限

GPS-Gaussian

  • 基于立体匹配的 3D 高斯位置估计
  • 依赖 立体矫正 (stereo rectification),大视角时失败
  • Δ=90° 时完全无法工作
  • 多于 2 视角时性能下降(多视角不匹配)

Tele-Aloha

  • 图像融合 + 级联视差估计
  • 仅针对 4 视角固定系统
  • 无法泛化到更稀疏(<4)的相机设置

GHG

  • 前馈式实时人体高斯渲染
  • 需要 人体模板先验 (SMPL)
  • 继承模板方法的缺陷(姿态估计误差误导重建)

2.2 其他相关工作的问题

  • pixelSplat / Splatter Image:首次将前馈推理与 3DGS 结合,但高斯位置估计不准确;
  • MVSplat / MVGaussian:用交叉注意力/cost volume 改进位置估计,但仅限于 256×256 低分辨率;
  • 基于模板的 3DGS 人体方法:将高斯绑定到 SMPL/SMPL-X 网格,迭代绑定过程耗时,无法实时;
  • NeRF 类方法:训练与渲染均耗时,难以实时应用。

EVA-Gaussian 的目标

无需人体模板先验,在高分辨率 (1024×1024) 下,支持任意数量相机、大视角差(包括稀疏视角)的实时 3D 人体重建与新视角合成。

3算法总体框架

给定围绕人体的 $n$ 张稀疏视角 RGB 图像 $\{\bm{I}_i\}_{i=1}^n$, $\bm{I}_i \in \mathbb{R}^{H\times W\times 3}$,目标是在任意相机位置实时合成新视角图像。EVA-Gaussian 将每个源图像的前景像素对应到一个唯一的 3D 高斯,并将整个过程分为三个阶段:

STAGE 1

3D 高斯位置估计

基于 U-Net + EVA 模块,从多视角图像估计每个像素对应的 3D 高斯位置(深度图 $\bm{P}_i$)。

网络: $\mathcal{D}^P_{\theta_1}$ (AttenUNet)

STAGE 2

3D 高斯属性估计

以位置图 + 原始 RGB 为输入,预测剩余属性:不透明度 $\bm{O}$、尺度 $\bm{S}$、四元数 $\bm{Q}$、特征 $\bm{F}$。

网络: $\mathcal{D}^A_{\theta_2}$ (GSRegresser_feature)

STAGE 3

特征溅射与循环精修

将所有视角高斯聚合,通过 α-混合溅射渲染 RGB 与特征图,循环 U-Net 精修器纠正伪影。

网络: $\mathcal{D}^R_{\theta_3}$ (feature_refiner)

3.1 数学形式化

每个源图像 $i$ 对应 $U_i$ 个 3D 高斯,其完整属性图为:

$$\{\bm{M}_i\}_{i=1}^n = \{\bm{P}_i, \bm{O}_i, \bm{S}_i, \bm{Q}_i, \bm{F}_i\}_{i=1}^n = \mathcal{D}_{\bm{\theta}}(\{\bm{I}_i\}_{i=1}^n) \quad \text{(式 1)}$$

其中 $\bm{P}_i, \bm{O}_i, \bm{S}_i, \bm{Q}_i, \bm{F}_i$ 分别表示位置、不透明度、尺度、四元数(旋转)和特征图。特征向量 $\bm{f}_i^u \in \mathbb{R}^{32}$ 是每个高斯的新增属性,用于后续精修阶段消除位置估计误差引起的伪影。

核心观察:高斯位置与深度的等价性

当每个高斯的尺度足够小时,某像素的 3D 高斯位置精确对齐其深度图上的对应值(附录 D 证明)。因此,位置估计网络可以用深度图真值监督训练。

4阶段一:高斯位置估计 (EVA 模块)

人体表面深度变化虽小,但在面部、手部等语义丰富区域,微小的深度估计误差会导致显著的视觉质量退化。因此精确的 3D 高斯位置估计至关重要。

4.2 EVA 模块的核心设计

关键洞察

在人体采集系统中,人体通常位于每帧中心,因此对极线 (epipolar lines) 几乎平行于图像的 x 轴。这意味着来自参考视角的对应像素通常位于沿 x 轴的相邻位置。基于此,EVA 只需在沿 x 轴的局部 1D 窗口内计算交叉注意力,而无需全局注意力。

EVA 模块 (CVA) 工作流程:

  1. 位置编码:添加可学习位置嵌入 $\gamma$ 编码空间坐标;
  2. 窗口划分:将特征沿 x 轴划分为大小为 $w$ 的 1D 窗口;
  3. 双向交叉注意力:
    • attn_1:视角 1 的特征 Query 视角 2 的特征(View1 ← View2)
    • attn_2:视角 2 的特征 Query 视角 1 的特征(View2 ← View1)
  4. 移位窗口算法 (Shifted Window):每次迭代将窗口移动半个窗口大小,扩展感受野;
  5. MLP + 残差连接:经 LayerNorm 与 MLP 进一步融合。

4.4 训练损失

位置估计网络使用深度图真值的 MSE 损失(深度预训练):

$$\mathcal{L}_{\text{depth}} = \|\bm{P}_i - \bm{P}_i^{\text{gt}}\|_2 \quad \text{(式 3)}$$

5阶段二:高斯属性估计

为完成 3D 高斯属性图 $\{\bm{M}_i\}$ 的估计,采用一个浅层 U-Net $\mathcal{D}^A_{\theta_2}$ (GSRegresser_feature),输入为阶段一估计的位置图与原始 RGB 图像的拼接,输出剩余高斯属性:

$$\{\bm{O}_i, \bm{S}_i, \bm{Q}_i, \bm{F}_i\}_{i=1}^n = \mathcal{D}^A_{\theta_2}(\{\bm{I}_i\}_{i=1}^n \oplus \{\bm{P}_i\}_{i=1}^n) \quad \text{(式 4)}$$

5.2 渲染与新视角合成

所有源视角的 3D 高斯 $\{\bm{M}_i\}$ 聚合后,通过差分光栅化 (α-混合) 渲染目标视角。属性估计网络使用渲染图像与真值的 MSE + SSIM 组合损失训练:

$$\mathcal{L}_{\text{render}} = \|\hat{\bm{I}}^0 - \bm{I}^{\text{gt}}\|_2 + \lambda_{\text{render}}(1 - \text{SSIM}(\hat{\bm{I}}^0, \bm{I}^{\text{gt}})) \quad \text{(式 5)}$$

6阶段三:特征溅射与循环精修

阶段一估计的 3D 高斯位置图 $\bm{P}_i$ 不可避免地包含误差,可能导致渲染 RGB 图像出现畸变和伪影。为缓解这些问题,本文提出溅射后精修方法。

6.1 特征溅射 (Feature Splatting)

受研究表明特征向量表示比球谐函数更有效捕获场景信息的启发,本文为每个高斯赋予一个 32 维特征向量 $\bm{f}_i^u \in \mathbb{R}^{32}$。溅射时,颜色值通过标准 α-混合渲染,特征值通过修改的 α-混合函数溅射到图像平面:

$$\bm{f}_{\text{pixel}} = \sum_{j=1}^{N} \bm{f}_j \, \alpha_j \prod_{l=1}^{j-1}(1-\alpha_l) \quad \text{(式 6)}$$

其中 $N = \sum_{i=1}^n U_i$ 是所有源视角的 3D 高斯总数,$\bm{f}_j$ 是深度第 $j$ 大的高斯的特征向量。

6.2 循环 U-Net 精修器 (feature_refiner)

采用精心设计的循环 U-Net $\mathcal{D}^R_{\theta_3}$,同时接收 RGB 图像与特征图为输入,经 $L$ 次循环投影到 RGB 空间输出最终结果:

$$\hat{\bm{I}}^l = \mathcal{D}^R_{\theta_3}(\hat{\bm{I}}^{l-1} \oplus \bm{F}_{\text{novel}}), \quad l \in \{1 \cdots L\} \quad \text{(式 7)}$$

其中 $\hat{\bm{I}}^l \in \mathbb{R}^{H\times W\times 3}$,$\bm{F}_{\text{novel}} \in \mathbb{R}^{H\times W\times 32}$。

6.3 精修损失

$$\mathcal{L}_{\text{refine}} = \|\hat{\bm{I}}^L - \bm{I}^{\text{gt}}\|_2 + \lambda_{\text{refine}}(1 - \text{SSIM}(\hat{\bm{I}}^L, \bm{I}^{\text{gt}})) \quad \text{(式 8)}$$

7属性正则化 (锚点损失)

现有前馈式 3DGS 方法假设 3D 高斯位置直接对应各自视角的估计深度值。但这一假设并不总成立——高斯未被显式约束在物体表面上,且各视角独立反投影,缺乏跨视角一致性与全局场景优化。

7.1 锚点损失的三项组成

$$\mathcal{L}_{\text{anchor}} = \lambda_{\text{opacity}} \sum_{i=1}^{N} \|\bm{O}_i \log(\bm{O}_i)\|_1 + \lambda_{\text{scale}} \sum_{i=1}^{N} \|\bm{S}_i\|_2 + \sum_{i,j \in \mathbb{V}} \sum_{m_i \in \mathbb{M}_i, m_j \in \mathbb{M}_j} \max\{Dist, t\} \quad \text{(式 9)}$$
项 1

不透明度正则化

$O_i \log(O_i)$ 熵形式,推动不透明度趋向 0 或 1,减少半透明伪影。

代码: (opacity * log(opacity)).mean()

项 2

尺度正则化

L2 范数惩罚大尺度,保持高斯小且紧贴表面,支撑"小尺度高斯位置对齐深度"的证明。

代码: scale.mean()

项 3

关键点位置一致性

使用 MediaPipe 标注人脸关键点,约束同一关键点在不同视角反投影到 3D 后的距离。

容差 $t_2 = 0.05$

7.2 关键点距离计算

$$Dist = \|\Pi^{-1}(\bm{m}_i, \bm{P}_i(\bm{m}_i)) - \Pi^{-1}(\bm{m}_j, \bm{P}_j(\bm{m}_j))\|_2$$

其中 $\Pi^{-1}$ 为从 2D 图像到 3D 空间的反投影,$\bm{m}_i, \bm{m}_j$ 为两视角的 2D 人脸关键点位置,$\bm{P}_i(\bm{m}_i)$ 为该关键点处的深度值。

容差机制 (Hinge)

$\max\{Dist, t\}$ 形式意味着:当 $Dist \le t$ 时损失为常数 $t$(无梯度);仅当 $Dist > t$ 时提供梯度拉拢关键点。代码实现采用平滑铰链:$(|Dist - t_2| + |Dist + t_2|)/2$,容差 $t_2 = 0.05$。

$$\mathcal{L}_{\text{EVA}} = \mathcal{L}_{\text{depth}} + \lambda_1 \mathcal{L}_{\text{render}} + \lambda_2 \mathcal{L}_{\text{refine}} + \lambda_3 \mathcal{L}_{\text{anchor}} \quad \text{(式 10)}$$

12可改进方向分析

基于对论文方法与官方代码的深入研读,本节从方法、数据与评估、工程实用性三个维度分析 EVA-Gaussian 的可改进方向,并标注每项的优先级与代码佐证。

12.1 方法层面

① 多视角支持"名不副实"[高优先级]

论文宣称支持 $n$ 视角输入,但代码中 EVANet.forward 硬编码了 lmain/rmain 双视角(torch.stack([data['lmain']['img'], data['rmain']['img']], dim=1)),EVA 模块虽理论上可扩展到 $n$ 视角,但训练与推理流程被锁死在 stereo。

改进:真正实现可变 $n$ 视角输入,用 set-based 注意力(如 Perceiver / Transformer 编码器)替代固定双视角栈,使网络能自适应处理 2~6+ 视角。

② 1D 窗口假设的几何脆弱性[中优先级]

EVA 的核心先验是"人体居中 → 对极线近似平行 x 轴",这要求相机水平环绕排列。一旦相机有俯仰角、上下排列、或人体偏离中心,窗口沿 x 轴划分就失效。

改进:引入对极几何感知的窗口方向自适应——根据基础矩阵 $\bm{F}$ 动态决定窗口主轴方向;或用可变形窗口 (deformable window) 学习最优窗口形状,而非固定沿 x 轴。

③ 关键点仅约束面部[高优先级]

anchor_loss 只用了 MediaPipe 人脸关键点。但消融实验(11 节)显示伪影高发区恰是手部、脚部,这些区域没有关键点约束。

改进:引入全身关键点(COCO-17 / SMPL joints / MediaPipe Holistic 478 点),对关节、指尖、脚趾等高频区域施加跨视角一致性约束。手部关键点对消除手部伪影尤为关键。

④ 特征精修是单向后处理[中优先级]

循环 U-Net 只在末端精修,精修信息未回传到位置/属性估计阶段。这是一个"信息单向流"的设计,精修器无法指导前端改进。

改进:引入端到端的循环反馈——精修后的图像特征回传重估计位置 → 重属性;或用可微渲染的梯度直接回传到位置网络,形成闭环优化。

⑤ 无不确定性建模[中优先级]

位置网络只输出点估计(深度值),没有置信度/方差。多视角聚合时所有高斯被同等对待,无法区分可靠与不可靠区域。

改进:让网络输出高斯位置的概率分布(均值+方差),在精修与聚合阶段按不确定性加权(类似 Kendall 的 aleatoric uncertainty),而非简单 α-混合。

⑥ 无遮挡/可见性显式处理[中优先级]

多视角聚合时未做可见性判断,被遮挡视角的高斯仍会贡献到渲染,可能导致"穿模"伪影。

改进:加 visibility mask 或学习各视角贡献权重(soft visibility),让被遮挡视角的高斯自动降权。

12.2 数据与评估层面

⑦ 仅在合成/受限数据集验证[高优先级]

THuman2.0 是 SMPL 渲染的合成数据(无真实纹理噪声),THumansit 仅坐姿单一姿态。缺乏真实捕获、多样服装、复杂姿态、跨种族验证。

改进:在 DNA-Rendering、RealHuman、CustomHuman 等真实捕获数据上验证;增加宽松服装、配饰、手持物体等困难场景测试。

⑧ 缺乏时序一致性评估[中优先级]

前馈单帧方法在视频上会闪烁(flickering),但论文未评估时序一致性。

改进:增加时序指标(tLP、光流一致性);或加时序平滑正则、跨帧特征对齐。

⑨ 未与最新 SOTA 对比[中优先级]

Tele-Aloha 仅在 related work 提及未实验对比;GHG、latentSplat、Splatter Image 也未纳入实验。消融中也未对比不同 EVA 窗口大小对最终质量的影响(仅 Table 1 给了计算开销)。

改进:补全基线对比;补充窗口大小 $w \in \{16,32,64\}$ 对 PSNR 的消融。

12.3 工程与实用性层面

⑩ 深度预训练依赖 GT depth[高优先级]

depthnet_pretrain.py 需要合成深度真值,真实部署中难以获得(需 SMPL 渲染)。

改进:用自监督立体匹配、或 teacher-student 蒸馏(用预训练大模型做 pseudo-GT),减少对 GT depth 的依赖,使方法能在无标注真实数据上训练。

⑪ anchor loss 权重 1000 偏大且固定[中优先级]

代码中 (10**3)*L_anchor 与其他损失项量级悬殊(L_depth ~ 0.01, L_anchor × 1000),易致梯度失衡。容差 $t_2=0.05$ 也是固定值,未随训练阶段调整。

改进:用课程学习(初期小权重,后期增大)或自适应权重(GradNorm / Uncertainty Weighting / Homoscedastic loss)替代固定 10³。

⑫ 特征维度 32 与循环次数 L 未充分讨论[低优先级]

论文未消融这两个超参。特征维度是否最优?循环次数 L 增多是否持续收益?

改进:补充维度 $\in \{16,32,64,128\}$、循环次数 $L \in \{1,2,3,4\}$ 的 Pareto 曲线(质量-速度权衡)。

⑬ 无 4D/动态扩展[中优先级]

方法本身是静态单帧重建,未支持动态运动序列的端到端时序建模。

改进:结合 4DGS / deformation field,扩展到动态人体运动序列;或用时空 attention 融合相邻帧信息。

个人认为最关键的三点

  1. 真正实现可变 $n$ 视角(而非代码中的双视角锁死)——直接决定方法能否泛化到不同采集系统;
  2. 用全身关键点替换仅面部约束——直接针对消融暴露的手部/脚部伪影问题;
  3. 在真实捕获数据上验证泛化性——决定方法从"实验室 demo"走向"实际部署"的可行性。

13总结

EVA-Gaussian 的四大贡献

  1. 三阶段管线:位置估计 → 属性估计 → 特征精修,实现快速前馈式 3D 人体重建;
  2. EVA 模块:基于 1D 移位窗口的跨视角注意力,在稀疏视角与高分辨率下增强多视角对应检索,计算与显存开销极低;
  3. 特征溅射 + 循环精修:为每个高斯嵌入 32 维特征,循环 U-Net 融合溅射图像与特征图,纠正位置估计误差伪影;
  4. 锚点损失:正则化不透明度、尺度与人脸关键点跨视角一致性,增强稳定性。

核心优势

  • 无需人体模板先验
  • 支持 2~4+ 视角,大视角差 (Δ=90°)
  • 1024×1024 高分辨率
  • 实时渲染 (~55ms)
  • 跨域泛化能力强

技术要点

  • 对极线近似平行 x 轴的人体中心先验
  • 1D 移位窗口注意力(类 Swin Transformer)
  • 特征向量优于球谐函数
  • 铰链式关键点容差损失
  • 深度预训练 + 端到端微调
