1论文摘要与核心贡献

PERSIST(ICML 2026,Mila × UdeM × McGill)提出用持久 3D 状态(persistent 3D state)替代「像素历史 / 关键帧检索」作为交互式世界模型的世界表示。核心论点:视频世界模型(Oasis 类滑窗、WorldMem 类关键帧检索)把世界状态隐式存在 attention 里的帧序列中,一旦观测脱离画面或窗口滑走,状态即丢失;而 PERSIST 把状态显式存在一个以 agent 为中心的体素 world-frame latent $w$ 中——agent 走多远,世界记住多远。

核心贡献四个:

  1. 持久环境表示:agent 状态 $\tilde{s}=\langle w, c\rangle$,w 为以 agent 为中心的 48³ 体素 world-frame latent(12³×48),c 为 10 维相机状态;环境演化在 3D 中预测而非像素中。
  2. 三组件耦合架构:world-frame 模型 $W_\theta$(rectified-flow DiT)、相机模型 $C_\theta$(1D causal transformer)、world-to-pixel 渲染 $P_\theta$(learned deferred shader),训练时独立、推理时组装,无需联合微调。
  3. 可微投影算子 R:可微光栅化(三角网格 + depth-peeling)把 world-frame 投影到任意视角,得到逐像素深度有序的体素特征栈 $\tilde{w}_{2D}$,桥接 3D 预测与 2D 渲染。
  4. 长程交互与结构化控制:600 帧不掉 FVD 饱和线、单图生成多样 3D 世界、中途编辑世界、屏外动态持续演化(agent 撞树、洞穴注水等涌现效果)。
一句话定位:Oasis/WorldMem 用「记忆过去的像素」对抗遗忘,PERSIST 用「维护一个 3D 世界」从根上消灭遗忘——状态不在帧里,在体素里。

2研究动机:像素历史的失败模式

2.1 像素空间世界模型的三个结构性缺陷

现有交互式世界模型(以 Oasis、WorldMem 为代表)把「世界」存在像素历史中,要么是滑窗内的最近 K 帧,要么是检索出的关键帧集合。论文指出三个结构性问题:

  1. 遗忘不可避免:滑窗滑走、检索打分不高,状态就丢了。误差随帧数累积,FVD 从 200 帧到 600 帧单调恶化(Oasis 409→875)。
  2. 屏外即未知:像素观测的视场角有限,agent 转身或前进时,屏外区域没有任何信息载体。3D 空间中的实体(agent 走过撞过的树、注水的洞穴)一旦离开画面,再回来时模型只能「猜」。
  3. 像素空间的 3D 一致性是间接的:几何约束只能通过 attention 隐式学习,没有显式的空间载体,视角一致性(同一条河、同一棵树)依赖大量数据与容量。
关键假设:世界状态本质上属于 3D 空间而非 2D 观测——只要把状态放进显式 3D 载体(world-frame 体素),遗忘问题就被结构性消除,而非用更长窗口/更聪明检索去「缓解」。这个假设的失效条件见 §16。

2.2 与记忆增强路线的分野

本库此前调研的 WorldMem(关键帧检索)与 CovRAG(覆盖最大化检索)属于「更好的检索」路线:承认状态在像素里,改进「取哪几帧」。PERSIST 属于「换载体」路线:状态根本不在像素里。两条路线的对比哲学与 Lyra 2.0 的「显式几何只做信息路由」同源——但 Lyra 路由的是视频 token,PERSIST 路由的是整个世界状态本身。

图1 PERSIST 总体架构。交互循环中,world-frame 模型 W_θ 在体素 latent 空间预测环境演化,相机模型 C_θ 预测视角变化,投影算子 R 把 world-frame 投到当前视角,渲染器 P_θ 生成像素观测。三组件训练时独立,推理时组装。

3问题形式化与符号表

3.1 世界模型形式化

论文把交互式世界模型形式化为五元组 $E=\langle S, O, A, \Omega, p\rangle$:状态空间 S、观测空间 O、动作空间 A、初始状态分布 Ω、转移核 $p(s_{t+1}\mid s_t, a_t)$。智能体只观测 $o_t$,需从观测-动作历史推断状态。标准「世界模型」做法是学一个隐状态 $h_t$ 聚合历史;PERSIST 的关键改变是把隐状态结构化为 $\tilde{s}_t=\langle w_t, c_t\rangle$——环境部分 w(体素 latent)与相机部分 c(视角)显式解耦。

3.3 目标函数

World-frame 模型采用 rectified flow / conditional flow matching 目标(Eq. 1):

$$\mathcal{L}(\theta)=\mathbb{E}_{t,x^0,x^1,\tau}\left[\left\|V_\theta(x^\tau,\tau)-\left(x^0-x^1\right)\right\|^2\right]$$ Eq. 1

其中 $x^1\sim\mathcal{N}(0,I)$ 为噪声,$x^\tau=\tau x^0+(1-\tau)x^1$ 为线性插值。推理时按 Euler 步(Eq. 2)$x^{\tau+\Delta}\leftarrow x^\tau+\Delta\,V_\theta(x^\tau,\tau)$ 迭代去噪,默认 20 步。世界模型演化即 Eq. 4:$\hat{w}_{t+1}=\text{denoise}_{W_\theta}(w_t,a_t)$。

4持久环境表示:World-Frame 架构

4.1 状态设计的三个决策

以 agent 为中心

体素窗口随 agent 移动,agent 永远在中心。好处:支持无限漫步,状态容量固定(48³);代价:窗口外的世界不维护——但已比像素滑窗大得多。

latent 而非原始体素

48³ 体素经 3D-VAE(ResNet3d 主干,cross-entropy + KL 1e-6)压到 12³×48 latent,4³ 体素一个 patch。W_θ 在 latent 空间做 flow,计算量与像素空间解耦。

环境/相机解耦

w 只装「世界」,相机状态 c 独立(⟨pos, rot, fov⟩ 10 维)。视角变化不污染环境状态,回头/俯仰时 w 不动、只动 c——这是「持久」的第二重含义:视角无关性。

4.2 观测编码双塔

2D-VAE(pixel 域)

ViT 主干,MSE + KL 1e-6。360×640 像素 → 36×64×16 latent(10px patch)。服务于 P_θ 的像素重建与 DFoT 式 pixel-level 训练。

3D-VAE(voxel 域)

ResNet3d 主干,重建用 cross-entropy(体素类别)+ KL 1e-6。48³ 体素 → 12³×48。服务于 W_θ 的 world-frame 训练。

双塔的意义:两个域各自有最合适的压缩失真权衡(像素 MSE 保连续外观,体素 CE 保离散类别),不必强行用一套 VAE 兼顾。

图2 以 agent 为中心的体素 world-frame 观测示例。环境状态显式存为 48³ 体素(图中为可视化解码),agent 始终处于窗口中心。

5三组件方法论:W/C/P 耦合

5.1 组件划分与训练独立性

组件结构输入 → 输出训练目标
W_θ world-frame 模型rectified flow DiT(patch 2,12³ 输入,ape+raymap)$w_t, a_t, c_t \to w_{t+1}$CFM(Eq. 1)
C_θ 相机模型1D causal transformer + RoPE$c_{1:t}, a_t, z_{1:t} \to c_{t+1}$残差回归(Δpitch/Δyaw/Δfov)
P_θ world-to-pixellearned deferred shader(DiT)$\tilde{w}_{2D}, c_{t+1} \to o_{t+1}$VAE latent 重建 + flow
设计核心:训练独立、推理组装。三个组件各自用自监督目标在大规模轨迹数据上独立训练,推理时按 $\hat{w}_{t+1}=W(w_t,a_t,c_t)$ → $\hat{c}_{t+1}=C(c_{1:t},a_t)$ → $R(\hat{c}_{t+1},\hat{w}_{t+1})$ → $\hat{o}_{t+1}=P(\tilde{w}_{2D})$ 串联,无需任何联合微调。这大幅简化了训练工程:每个组件可以独立迭代、独立缩放。

5.2 world-frame 模型 W_θ 细节

DiT 在 12³ latent 上做 rectified flow。条件注入方式:动作 $a_t$(23 维 multi-hot)与相机 $c_t$ 经 MLP 后作为 cross-attention 条件;latent 位置用 3D APE(voxel_use_ape=True);投影特征栈输入时开启 pixel_use_raymap(每像素射线方向可学嵌入)。去噪默认 20 步,σ_min=1e-5。

源码印证(pipelines/persist_S_pipeline/pipeline.json):voxel_sampler 配置 {"noise_cond":0.1,"sigma_min":1e-5,"steps":20,"rescale_t_inference":3.0,"min_noise_level_inference":0.02} 与论文 Table 9 完全吻合——η=3(rescale_t_inference)、τ_ctx=0.02(min_noise_level_inference)、10% flat 噪声增强(noise_cond 0.1)逐项对上。pixel_sampler 同构,唯 min_noise_level_inference=0.1。

5.3 相机模型 C_θ 细节

10 维相机状态 ⟨pos(3), rot(6d), fov(1)⟩ 经重参数化后,只预测残差 ⟨Δpitch, Δyaw, Δfov⟩(不预测位置与 roll)。1D causal transformer 沿时间轴 RoPE,吃相机历史 + 动作 + 像素 latent 历史。源码 models/camera_transformer.py 的 predict_next_camera 中 GAIN_PITCH=3.6、GAIN_YAW=6.4,delta 输出为分类式(乘增益),pitch clamp 到 [1e-8, 180-1e-8] 防极点退化。

5.4 world-to-pixel 渲染 P_θ 细节

learned deferred shader:先由投影算子 R 得到逐像素深度有序的体素特征栈 $\tilde{w}_{2D}$(每个像素位置的可见体素特征序列),P_θ 在此 2D 特征栈上用 DiT 直接生成像素 latent 再解码。相比体素→mesh→神经渲染的物理管线,learned shader 允许模型自学「如何从体素特征画像素」,避免显式纹理/材质建模。

图3 world-to-pixel 渲染器。投影算子 R 输出深度有序特征栈,P_θ(learned deferred shader)从特征栈生成像素。

6投影算子 R:可微光栅化桥接

6.1 为什么需要投影算子

W_θ 在体素 latent 空间演化,P_θ 在像素空间渲染——两者之间需要一个可微、视角条件化、深度有序的桥接。R(c,w) 把 world-frame 投影到相机 c 的视角:

$$R(c, w) = (\tilde{w}_{2D}, d), \quad \tilde{w}_{2D} = \text{Rasterize}(w; c)$$ Eq. 5

输出 $\tilde{w}_{2D}$ 是逐像素的体素特征栈(沿视线方向按深度排序),d 是对应深度。深度有序很关键:遮挡关系显式编码在特征栈的排序里,渲染器不需要隐式学遮挡。

6.2 实现:三角网格 + depth-peeling

体素块转三角网格后用可微光栅化渲染,depth-peeling 逐层剥离得到多图层特征栈(max_layers=32)。源码 utils/voxel_rasterizer.py 的 VoxelMeshRasterizer(dim=16, width=256, height=256, max_layers=32),rasterize_voxel_peeling 调 nvdiffrast 的 dr.DepthPeeler;screen_depth_to_view_space_depth 实现视图空间深度换算 $z_{view}=-p_{23}/(z_{ndc}+p_{22})$。

可微性收益

光栅化可微 → 梯度可以从像素损失回传到体素 latent,端到端训练 P_θ 时 world-frame 表征被反向塑形。

持久性收益

R 是纯函数、无参数、不依赖历史帧——同一 w 在任意视角 c 下可重复投影,「记忆」由 w 单点持有,与视角解耦。

图4 同一 world-frame latent 在不同相机视角下的重投影。视角变化时 w 不变,只变 c 与 R(c,·)——状态持久性的直观展示。

7暴露偏置缓解:Diffusion Forcing + 噪声增强

7.1 问题:自回归暴露偏置

推理时 W_θ 吃自己生成的 $w_t$(带误差),训练时吃真值 $w_t$(无误差)——经典暴露偏置(exposure bias),误差逐帧复合。PERSIST 用两层机制缓解:

  1. Diffusion Forcing(DFoT):训练时给条件帧的 latent 注入随机强度噪声 $\sigma\sim[0,1]$(而非全噪声或全干净),模型学会在任意噪声水平下去噪。推理时用 noise floor τ_ctx 保持条件帧带少量噪声:W_θ 的 τ_ctx=0.02,P_θ 的 τ_ctx=0.1,匹配「生成帧 vs 条件帧」的分布差。
  2. 10% flat 噪声增强:条件 latent 与 10% 高斯噪声线性混合,cond = (1-0.1)·latent + 0.1·noise(源码 train_scripts/train_diffuser_voxel.py 中 cond["pixel_latents"] = (1-noise_cond)*batch["pixel"] + noise_cond*noise_pix 的 voxel 侧对应实现)。这比 DFoT 更粗但极廉价,进一步抹平自回归分布偏移。
参数对照(论文 Table 9 ↔ 发布配置,已交叉验证):σ_min=1e-5;去噪步数 20;η(rescale_t_inference)=3.0;τ_ctx:W=0.02 / P=0.1;噪声增强系数 noise_cond=0.1。注意 trainers/flow_euler.py 中 DiffusionForcingArgs 默认 noise_cond=0.015 是 DFoT 内部的噪声表参数,与推理增强的 0.1 是两回事——读源码时不要混淆。

7.2 与 KV cache 的关系

W_θ 与 P_θ 推理时维护 causal KV cache(reset_and_warmstart_kv_caches),单帧循环不重算历史注意力;DFoT 噪声只作用于当前帧的条件拼接,不影响 cache 的复用。这是 PERSIST-S 能做到 2/4-step 886ms/帧的工程前提之一。

13新能力:生成 / 编辑 / 屏外演化

13.1 单图生成多样 3D 世界

从单张图 o_0 出发,W_θ 的 flow 采样可生成多个不同的 w_0(3D 世界的「幻想补全」),再进入交互循环。这是像素自回归模型做不到的:像素模型从单图只能走一条轨迹,而 PERSIST 把「世界的不确定性」从时序维度搬到了 3D 结构维度——一次采样定型一个世界,之后该世界内交互是确定的。

初始化有两种模式(论文 Figure 3):仅单 RGB 帧(,第一行,模型自行采样补全 w_0),或 RGB + 世界帧联合初始化( + ,第二行,GT/显式给定 w_0)。

图9 两种初始化模式的定性对比。行 1:单 RGB 初始化,w_0 由模型采样(多样但可能偏离 GT);行 2:RGB + w_0 联合初始化,世界帧直接对齐真值。
图10 同一初始观测 o_0 采样出的多个 w_0 及其对应渲染。多样性体现在 3D 结构(地形/建筑布局)而非仅纹理。

13.2 中途世界编辑

w 是结构化张量(体素 latent),可以在任意时刻显式改写(增删建筑、改地形),后续帧立即生效且持续保持。编辑接口天然存在,无需为编辑设计专门机制——这是「状态在显式载体里」的直接红利。对照:像素模型的编辑需要专门训练 inversion/editing 模块。

图11 中途编辑示例。对 w 直接修改后,后续生成持续保持编辑结果(视角变化、时间推进后仍一致)。

13.3 屏外动态持续演化

最有说服力的能力:agent 在 A 处撞倒树/注水洞穴,走远再回来,变化仍在——因为演化发生在 3D 状态里而非观测里。论文展示了洞穴注水、树被撞倒等案例;这类「屏外因果」是滑窗与检索模型原理上无法保证的(除非恰好检索到相关帧)。

14.1 定位与演进逻辑

四篇构成一条清晰的演进线:Oasis(什么也不记)→ WorldMem(记关键帧)→ CovRAG(聪明地选帧)→ PERSIST(把状态搬进 3D,不再需要记)。前三篇共享「状态在像素里」前提,在检索轴上内卷;PERSIST 换掉了前提本身。CovRAG 用 VGGT 深度做检索路由,已经引入显式几何,但几何只服务于「选哪帧」;PERSIST 让几何成为状态本身——与 Lyra 2.0「显式几何做信息路由」vs「几何即状态」的分野完全同构。

库内交叉链接:R2M-Bench(重访记忆评测——PERSIST 的屏外演化正对 R2M-Bench 的 re-visit 协议,未来工作可用它量化「持久性」)、CovRAG(检索路线极致)、Lyra 2.0(几何路由哲学对照)、OctWorld(同样用八叉/体素离散化世界的生成范式)。另有直接代码亲缘:PERSIST 仓库 utils/camera_util.py 内置 worldmem_cam_to_minetest_cam 与 WorldMem 相机坐标对齐——两团队评测协议互通。

14.2 各自的适用边界

  • 有 GT 3D 的模拟环境(游戏/机器人仿真):PERSIST 范式完胜——状态转移直接监督,屏外演化、编辑、O(1) 状态全兑现。
  • 真实世界视频(无 GT 3D):PERSIST 目前不可行(GT 体素无从获得),检索路线(WorldMem/CovRAG)仍是唯一选项;除非未来用重建模型造伪 GT。
  • 评测端:R2M-Bench 的 re-visit 协议恰好能量化 PERSIST 声称的屏外持久性,是天然搭配。

15应用启发与改进方向

15.1 对本库相关方向的启发

vggt_human pipeline

「状态持久化 vs 检索」的取舍对多目持久重建有直接启发:head_gs/body_gs/scene_gs 的拆分本质上也是「把状态放进显式 3D 载体」,PERSIST 验证了 latent 体素 + 可微光栅化投影的组合可以端到端维护——多-session 人体重建的「跨 session 状态持久」可借鉴此架构(W 为持久人体/场景 gaussians,R 为可微渲染)。

世界模型评测

PERSIST 的 FVD 三时长协议(200/400/600)+ 人评四维是可复用的评测骨架;R2M-Bench 的 re-visit 协议补上「屏外持久性」维度,两者合用可构成交互式世界模型的完整评测矩阵。

15.2 论文自身的改进方向

  1. 摆脱 GT 3D 依赖:用大规模重建(VGGT/3DGS 类)从真实视频造伪体素监督,是走向真实世界的关键一步;风险是伪 GT 的噪声会直接污染 W_θ 的转移学习。
  2. 突破 48³ 有限区域:分层体素(近处细、远处粗)或无限平铺 world-frame;48³ 对 Minecraft 类游戏够用,对开放世界不够。
  3. 实时化:886ms/帧距实时还差一个量级;蒸馏单步 flow、量化、P_θ 与 W_θ 的双扩散串联改单级,是明确路径。
  4. 非体素场景:体素离散化天然适配 Minecraft 类世界;连续场景(室内/城市)需换 NeRF/Gaussian 类连续载体——P_θ 的 learned deferred shader 倒是载体无关的。

16局限与展望

16.1 论文自认局限

  • 需 GT 3D 监督:W_θ 的转移学习依赖引擎提供的真值体素;真实世界视频无法直接使用。
  • 有限 3D 区域:48³ 窗口外的世界不维护(比像素滑窗好,但非无限)。
  • 未达实时:最快 886ms/帧(1.13 FPS),交互体验受限。

16.2 关键假设的失效条件

假设失效边界:「状态属于 3D 空间」这一前提在以下情形失效——① 世界状态不可完全体素化(流体细节、非刚性形变、光照);② 观测与体素窗口错位(agent 快速移动时 48³ 跟不上);③ 需要无限记忆(走出窗口的世界仍需召回)。此外 600 帧 FVD 仍有 +15% 恶化,说明 latent 舍入误差也在缓慢累积——持久 ≠ 无损。
