为什么是这个组合

  • 2DGS 几何质量 SOTA：2D 盘状高斯沿表面对齐，几何精度远超原版 3DGS，漂浮点天生更少——这正是微动场景的痛点
  • PDF-GS 专为不一致输入设计：2026-04 CVPR Findings 最新工作，把破坏多视角一致性的像素/帧当 distractor 渐进剔除——肢体微动 + Wan 生成帧的不一致正好是它的目标场景
  • SAM2 mask 直接可用：你已有的 mask 可作为前景监督，与 2DGS/HUGS 范式天然契合
  • SMPL prior 可选叠加：若 2DGS+PDF-GS 仍不够，可上 HUGS 范式（SMPL 初始化 + 偏移场）
关键洞察：PDF-GS（arXiv:2604.12580）几乎是为你的场景量身定做的——微动 + 生成帧不一致正是它要处理的 distractor。即插即用、零额外推理成本、可直接挂到 2DGS 上。

1. Top 3 推荐方案详解

1.1 🥇 2D Gaussian Splatting (2DGS)

2D Gaussian Splatting for Geometrically Accurate Radiance Fields
SIGGRAPH 2024 · hbb1/2d-gaussian-splatting · 3.3k stars · ~20-40min/场景
将 3D 高斯塌缩为沿表面对齐的 2D 盘状高斯，直接沿法线方向"投影"厚度。几何精度大幅提升、漂浮点明显减少。在 DTU/Spaces/Mip-NeRF360 上取得 SOTA。nerfstudio 已集成为 splatfacto，gsplat 亦支持。
GitHub arXiv

选它作 baseline 的理由：

  • 12-16 视角已不算极端稀疏，2DGS 的表面几何质量远好于原版 3DGS
  • mask 可直接作为前景监督（已有 SAM2）
  • nerfstudio/gsplat 生态成熟，开箱即用
  • 工程成熟度 ★★★★★

1.2 🥈 PDF-GS（鲁棒性首选）

PDF-GS: Progressive Distractor Filtering for Robust 3D Gaussian Splatting
CVPR Findings 2026 · arXiv:2604.12580 · kangrnin/PDF-GS · 即插即用
利用 3DGS 内在的"自过滤"能力，多阶段渐进式剔除破坏多视角一致性的"干扰点"（distractor，含微动肢体、动态物体、生成帧不一致像素），再用纯化后的高斯重建细节。轻量、无架构改动、无额外推理开销，可直接挂到 2DGS/3DGS baseline 上。
GitHub arXiv
为什么契合你的场景：你的"肢体微动 + Wan 2.2 生成帧的不一致"正是 PDF-GS 设计目标的 distractor。它不会硬压微动，而是识别并降权这些不一致区域，让主体重建保持高保真。

1.3 🥉 HUGS / GaussianAvatars（人体专用）

HUGS: Human Gaussian Splats
CVPR 2024 · apple24f/HUGS · 4-8 视角 · ~30min 训练 · 60 FPS
利用 SMPL 人体模型初始化高斯，同时优化线性混合蒙皮权重（LBS），使高斯能跟随骨骼运动。只需少量单目视频帧即可训练，自动分离静态场景和可动画人体。
GitHub arXiv
GaussianAvatars: Semantic Control & Animator-Ready
CVPR 2024 · QianyiWu/GaussianAvatars · 8-16 视角 · ~60min 训练
语义可控动画 avatar，FLAME/SMPL 绑定高斯，三角网格局部帧作为参考。与 HUGS 思路类似但更偏重可驱动。
GitHub

选它们作人体专用的理由：对"静态多视角人体"特别契合，配合已有的 SMPL/SAM2 mask 天然适配。若需要可驱动数字人是 HUGS/GaussianAvatars 的强项；若只需静态资产，2DGS+PDF-GS 已足够，HUGS 可作为升级路线。

2. 密度控制改进类（抗漂浮点 / 伪影）

原版 3DGS 的自适应密度控制（split/clone/prune）是启发式的，容易产生漂浮点和过度增长。这类方法改进密度控制机制。

3DGS-MCMC
3DV 2024 · 把自适应密度控制替换为马尔可夫链蒙特卡洛采样
杜绝启发式 split/clone 的漂移，更稳定的密度控制。是后续很多方法的 density backend。
AbsGS
2024 · 抽象高斯 · 改进 densification 退化问题
StopThePop
SIGGRAPH 2024 · 解决高斯"弹出"（popping）伪影 · 视点依赖调节
Scaffold-GS
CVPR 2024 · anchor + MLP 生成高斯 · 结构化抑制漂浮
用 anchor 点作为高斯生成的种子，MLP 学习局部偏移和外观，结构化表示有效抑制漂浮点。
3DGBGS
2026-07 (arXiv:2607.26578) · 粒球自适应分区 anchor · 更紧凑表示
GaussianPro
CVPR 2024 · 渐进式传播高斯 · 抑制冗余增长

3. 稀疏视角类（< 20 视角）

针对稀疏视角（2-12 视角）的重建方法，通常引入几何先验（深度/法线）或大规模预训练先验。你的 12-16 视角处于中度稀疏，可选但非必需。

DNGaussian
CVPR 2024 · 2-4 视角 · ~15min · 几何先验蒸馏
从预训练模型蒸馏深度/法线先验，对极稀疏视角（2-4）效果好。你的 12-16 视角用不上这么激进的方案。
FSGS
ECCV 2024 · 频率正则稀疏重建
MAC-Splat
ECCV 2026 · MASt3R + DINOv3 对应点 · 2-12 视角 · <1min
用 MASt3R 和 DINOv3 提取对应点直接监督 3D 一致性，ScanNet++ 上 PSNR 比 Splatt3R 高 4.5dB。但属于 feedforward 范式，对非常规输入泛化差。
PairDropGS
2026-05 (arXiv:2605.12072) · dropout 一致性正则 · 稀疏稳定
GeoQuery
SIGGRAPH 2026 · 几何引导扩散修复稀疏伪影
CLEAR
2026-08 (arXiv:2608.02206) · 单阶段稀疏超分重建

4. 几何先验注入类（depth / normal / SMPL prior）

这类方法显式注入几何先验（深度图、法线图、参数化模型）以约束重建，特别适合稀疏视角或需要高质量表面的场景。

SuGaR
CVPR 2024 · 3.5k stars · 高斯贴合表面 → 高质量 mesh
让高斯贴合到表面上，便于提取高质量 mesh。如果你的下游需要 mesh 而非高斯，这是首选。
GOF (Gaussian Opacity Fields)
CVPR 2024 · 几何感知高斯场 + SDF 一致性 · 15+ 视角
引入 SDF 一致性约束，提升表面质量。视角需求 15+，正好契合你的 12-16。
2DGS
SIGGRAPH 2024 · 2D 盘状高斯 + 法线对齐（已在 Top 3 介绍）
Confidence-matters (Lähner et al.)
2026-08 (arXiv:2608.06117) · VGGT 多视角置信度图加权深度/法线先验
用 VGGT 提取的置信度图加权深度/法线先验，显著改善镜面物体等难区域。可借鉴思路加入你的 pipeline。
D²-4DGS
2026-08 (arXiv:2608.01588) · 单目+多视角双源深度对齐 · 稀疏动态
P2GS
CVPR 2026 · 物理光度一致 · 分离 HDR 辐照/曝光
Gaussian Sculpting
2026-08 (arXiv:2608.10602) · SDF + 高斯双层优化 · 端到端表面重建

5. 鲁棒性 / 不一致输入类（针对你的微动场景）

最关键的一类：你的场景核心是"输入帧有微动 + 生成帧有不一致"，需要鲁棒性方法处理。这一类是为你场景量身定做的。
PDF-GS
CVPR Findings 2026 · 渐进干扰点过滤 · 已在 Top 3 介绍
本类首选。把破坏多视角一致性的像素/帧当 distractor 渐进剔除。
Gaussian in the Wild (GITG)
CVPR 2024 · 分离静态/动态/瞬态场 · 处理野外不一致
将场景分解为静态场、动态场、瞬态场，分别建模。野外场景下处理不一致输入的经典工作。
RAWG
2024 · 鲁棒自适应加权高斯
Deformable-3DGS
3DV 2024 · 变形场建模动态 · 对微动友好 · 官方实现
用规范空间 + 变形场建模动态，对微动友好。工程更重，建议作为 PDF-GS 不够时的升级路线。
AniGS
2024-12 (arXiv:2412.02684) · 把"不一致图像重建"当作 4D 任务处理
4DGS 范式适配生成图不一致性，思路新颖。若 PDF-GS 不够，可考虑此方向。
ArtifactWorld
2026-04 · 视频扩散 backbone 修复 3DGS 伪影 · 107.5K 训练对
NRGS
2026-04 · 神经正则化多视角不一致语义场

8. 针对本场景的推荐组合

场景定义：12-16 真拍视角（含肢体微动） + SAM2 mask + Wan 2.2 生成旋转帧（含生成不一致） + 不需可驱动 + 暂缓长发/宽松衣物

8.1 推荐主组合

2DGS（baseline 几何质量） + PDF-GS（处理微动 + 生成帧不一致） + SAM2 mask（前景监督，已有） + 真拍 N 视角 λ=1.0（几何锚点） + 生成 M 帧 λ=0.3（视角补全，置信度加权）

8.2 升级路径

若主组合仍残留问题，按以下顺序升级：

  1. 主组合不足时 → 加 HUGS 范式：SMPL-X 初始化高斯 + LBS 偏移场学习（处理衣物超出模板）
  2. 仍有残差 → 上 Deformable-3DGS：变形场建模微动（更重但更鲁棒）
  3. 极端情况 → 上 AniGS：4D 范式把不一致图像当 4D 任务处理

8.3 不同子场景的最优解

子场景 最优解 理由
仅真拍 N 视角，不上生成帧 2DGS + PDF-GS + SAM2 PDF-GS 直接处理微动 distractor
真拍 + Wan 生成帧联合 2DGS + PDF-GS + 置信度加权 真拍 λ=1.0 锚几何，生成 λ=0.3 补稀疏
需可驱动数字人 HUGS 或 GaussianAvatars SMPL 绑定直接产出可动画资产
微动严重到 PDF-GS 失效 Deformable-3DGS 显式变形场建模
需要 mesh 输出 SuGaR 或 GOF 专为 mesh 提取设计
标定误差与微动误差难分离 JOintGS 联合优化相机/姿态/高斯

10. 不推荐方案

以下方案不适合你的场景，避免踩坑：

10.1 原版 3DGS

漂浮点多、几何质量差、对微动极敏感。已有 2DGS 这个全面升级版，没必要再走老路。

10.2 Feedforward LRM 类（GS-LRM / Splatt3R / MAC-Splat）

这些是单图/少图前馈式重建，速度快但对"含微动真实多视角 + 生成帧混合"这种非常规输入泛化差。你的输入不是它们的训练分布。

10.3 极稀疏方法（DNGaussian）

专为 2-4 视角设计，需要强先验蒸馏。你 12-16 视角用不上这么激进的方案，反而引入不必要的先验偏差。

10.4 一上来就上 Deformable-3DGS / AniGS

虽然对微动友好，但工程量大、训练慢。应该先用 PDF-GS 这种轻量方案试，不够再升级。

10.5 纯生成式 3D 重建（SDS / DreamGaussian）

质量不稳定，Janus 问题、漂浮物、纹理模糊。你已有真拍数据，没必要走纯生成路线。
