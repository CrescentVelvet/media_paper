VGGT-Ω: Visual Geometry Grounded Transformer — Omega

📄 arXiv: 2605.15195 📅 2026-05-14 🏢 Oxford VGG + Meta AI 🏆 CVPR 2026 Oral / Best Paper Finalist ✅ 开源

📋 论文概要

Feed-Forward 3D Scaling Law Register Attention Dynamic Scenes Self-Supervised Foundation Model

VGGT-Ω（Omega）是 VGGT (Visual Geometry Grounded Transformer) 的升级版，来自同一核心团队（Oxford VGG + Meta AI）。VGGT 是 CVPR 2025 最佳论文，而 Ω 版本进一步在架构效率、训练规模和场景覆盖上大幅提升，被评为 CVPR 2026 Best Paper Finalist（Oral）。

核心目标：证明 前馈式 3D 重建模型的质量可以随模型和数据规模可预测地扩展（Scaling Law），并在此过程中建立新的 SOTA。名称中的"Ω"（Omega）来自一作 Jianyuan Wang 的最后一篇 PhD 论文——象征完整与终结。

核心贡献：通过架构简化（单一 dense prediction head + register attention）将训练显存降至原版的 ~30%，从而能够用 15× 更多的监督数据训练，并利用海量无标注视频数据进行自监督学习。同时支持静态和动态场景重建，在 Sintel 上相机估计精度提升 77%。

🔧 核心架构改进

相比 VGGT 原版，Ω 版本引入了三大架构改进：

1. 单一 Dense Prediction Head + 多任务监督

  • 用多任务监督替代 VGGT 的多个专用 head（Camera Head + DPT Head）
  • 去掉了昂贵的高分辨率卷积层（DPT 架构），大幅减少显存占用
  • Dense prediction head 可以只用 MLP，不需要复杂卷积，进一步简化架构
  • 相机参数和深度图作为充分且紧凑的重建目标

2. Register Attention

  • 引入 register 令牌聚合场景全局信息
  • 帧间信息交换通过 register 进行，部分替代 global attention
  • Register 是全局信息的自然载体，使跨帧信息交换更高效
  • 显著降低注意力矩阵的规模，从而降低显存

原版 VGGT 的帧间全局注意力复杂度为 O((F×P)²)（F=帧数，P=每帧 patch 数）；VGGT-Ω 将帧间信息交换限制在 register tokens 之间，复杂度降至 O(F×P² + F²×R²)，其中 R = register 数量，远小于 P。

方案复杂度信息交换路径
VGGT 原版O((F×P)²)所有帧所有 patch 间全局注意力
VGGT-ΩO(F×P² + F²×R²)帧内 patch→register + 帧间 register↔register

单张 A100 GPU 即可处理 200 帧输入序列（原版远达不到）。

3. 动态场景支持

  • 新增高质量数据标注流水线，支持动态场景重建
  • 自监督学习协议利用大量无标注视频数据
  • 使前馈 3D 重建从仅支持静态场景扩展到动态场景
显存效率：训练时 GPU 显存仅约原版的 30%，这使得用 15× 更多的监督数据训练成为可能，并允许利用海量无标注视频数据进行自监督学习。

📈 Scaling Law — 可预测的扩展性

VGGT-Ω 的核心发现之一是：前馈式 3D 重建模型的质量随模型和数据规模可预测地提升。这类似于 LLM 领域的 Scaling Law，为后续更大规模训练提供了理论依据。

关键意义：这意味着 3D 重建可以像语言模型一样通过扩大规模持续受益，而不是停滞在当前精度。天花板远未触顶，未来更大的模型和数据将带来更好的重建质量。

💡 额外发现 — 重建作为空间理解的代理任务

VLA 模型增强

学到的 register 特征可以直接增强 Vision-Language-Action (VLA) 模型的空间理解能力。3D 重建不仅是一个独立任务，其学到的表征还能迁移到机器人等下游领域。

语言对齐 / CLIP CLS Token 类比

重建 latents 可以与语言表示对齐，暗示重建是空间理解的可扩展代理任务（proxy task）。类比：如果说 CLIP 的 CLS token 是图像的语义摘要，那么 VGGT-Ω 的 register 就是 3D 场景的几何摘要 —— 都是经过大规模预训练学到的紧凑表示，可作为场景几何的 latent code 迁移到下游任务。

MLP-only 解码

Dense prediction head 可以只用 MLP，不需要复杂卷积。这一发现来自与合作者的深入讨论（论文致谢中提到 Tianhong Li 和 JiT 的工作），进一步简化架构。

紧凑重建目标

相机参数和深度图是充分且紧凑的重建目标。不需要预测过多冗余量（如点图、高斯参数等），简化了输出空间。

🏋️ 训练策略

架构效率提升

  • 单一预测头：多任务监督替代多个专用 head，去掉高分辨率卷积层
  • Register Attention：限制帧间信息交换通过 register 进行，降低注意力矩阵规模
  • 显存降至 ~30%：使大规模训练成为可能

数据策略

  • 监督数据：15× 于原版的标注数据量
  • 无标注视频：自监督学习协议利用海量无标注视频数据
  • 动态场景标注：高质量数据标注流水线支持动态场景

自监督学习

  • 利用视频序列的自然约束（时间一致性、多视角一致性）进行自监督
  • 无需人工标注即可从互联网视频中学习 3D 几何
  • 与 LLM 预训练类似：从海量无标注数据中学习通用表征

Teacher-Student 自监督协议

  • 教师模型训练：在少量高质量深度/相机真值标注上训练教师模型
  • 伪标签生成：教师模型为海量无标注视频打伪标签
  • 置信度加权：教师模型输出置信度，低置信度伪标签权重降低，避免噪声标签干扰训练
  • 几何一致性约束：利用多视图几何的内在约束（重投影一致性、深度尺度一致性）过滤不合理伪标签
  • 学生模型训练：在大规模标注 + 伪标签数据上联合训练

这种策略让模型从互联网级别视频中学习，而不仅仅依赖有限的标注数据 —— 是 22% 精度提升的来源。

⭐ 核心创新点

创新 1：Register Attention — 用 register 令牌聚合全局信息，限制帧间注意力通过 register 进行，大幅降低显存，使规模化训练可行。
创新 2：Scaling Law 验证 — 首次证明前馈 3D 重建质量随模型和数据规模可预测提升，为后续扩展提供理论依据。
创新 3：动态场景支持 — 从仅支持静态场景扩展到动态场景，大幅拓宽应用范围。
创新 4：自监督学习协议 — 利用海量无标注视频数据，摆脱对标注数据的过度依赖。
创新 5：重建作为空间理解代理任务 — Register 特征可增强 VLA 模型，重建 latents 可与语言对齐，暗示 3D 重建是通向空间智能的基石。

🧠 个人分析

  • 前馈 3D 重建的规模化里程碑：VGGT-Ω 证明了 3D 重建也存在 Scaling Law，这意味着 3D 视觉可以像 LLM 一样通过扩大规模持续受益。这是从专用模型到通用基础模型的关键一步。
  • VGGT → Ω 的传承：从 CVPR 2025 最佳论文到 CVPR 2026 Best Paper Finalist，同一团队证明了持续改进的能力。Ω 版本不仅改进了架构，更重要的是验证了规模化路线的可行性。
  • Register Attention 的意义：这是对 VGGT 全局注意力瓶颈的优雅解决方案。Register 作为全局信息的紧凑表示，既降低了计算成本，又提供了可迁移的特征表示（增强 VLA、语言对齐）。
  • 动态场景是关键突破：VGGT 原版仅支持静态场景，限制了实际应用。Ω 版本支持动态场景后，应用范围大幅拓宽——从静态重建到视频理解到机器人感知。
  • "Omega"的象征意义：作为一作 Jianyuan Wang 的最后一篇 PhD 论文，"Ω"象征完整与终结。但论文开辟的 Scaling Law 方向意味着前馈 3D 重建的规模化之路才刚刚开始。

🎯 结论：是不是最好的方法？

  • 在前馈式 3D 重建赛道，VGGT-Ω 目前是最强的方法之一
    • CVPR 2026 Best Paper Finalist（Oral），顶级学术认可
    • 同时覆盖相机估计、深度图、点云、动态场景，综合能力最强
    • 与 Depth Anything 3 等专门方法的定性对比也占优
    • Scaling 特性好，天花板高，未来更大规模训练将持续受益
    • Register 特征可增强 VLA 模型，具有跨领域迁移价值
    • 开源代码、模型、在线 Demo 齐全，可复现性强
  • ⚠️ 需要注意：
    • 与传统优化方法（COLMAP+BA）不是同一赛道，后者在精度极限上可能仍有优势
    • 实际落地效果取决于具体场景和输入质量
    • 论文发布于 2026-05，还很新，社区实践反馈需要时间
    • 大规模训练需要显著的计算资源
