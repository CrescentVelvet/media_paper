VGGT-Ω:前馈 3D 重建的 Scaling Law 与几何 SOTA

VGGT(CVPR 2025 Best Paper)的官方升级版。三大架构改进(单一 dense head + Register Attention + 动态场景)把训练显存压至原版 ~30%,从而用 15× 监督数据 + 18M 无标注视频自监督 训练 1B/10B 模型,首次验证前馈 3D 重建的 Scaling Law,并在 6 个基准(7Scenes/NRGBD/ETH3D/DyCheck/Sintel/TUM)上断层领先——Sintel 位姿 AUC@3°=40.0(vs 次优 MegaSaM 22.5,+77%)。本笔记为重写版,基于 arXiv HTML 全文纠正了旧版多处错误并补全准确数字。

1论文摘要与定位(重写说明)

VGGT-Ω(Omega) 是 VGGT(CVPR 2025 Best Paper)的官方升级版,发表于 CVPR 2026(Oral / Best Paper Finalist)。核心主张:通过架构简化把训练显存压至原版 ~30%,从而用 15× 监督数据 + 海量无标注视频自监督训练超大模型,首次验证前馈 3D 重建的 Scaling Law——质量随模型与数据规模可预测提升(幂律)。

2研究背景:VGGT 原版的三大瓶颈

VGGT 原版虽统一了相机/深度/点云/追踪四任务,但有三处效率与能力瓶颈(§1, §3.1),Ω 直击之:

① DPT 高分辨率卷积头显存爆炸

Camera Head + DPT Head 存大量前向激活,占 disproportionate 显存;FSDP/gradient checkpointing 都消不掉,限制了可训练规模与数据量。

② Global attention 二次成本

帧间 global self-attention 成本随总 token 数 二次增长 $O((N P)^2)$,是规模化主瓶颈。

③ 仅静态 + 监督数据小

只支持静态场景,监督序列仅 ~270K,无法支撑 Scaling Law 所需的数据规模,也无动态能力。

3核心架构改进(逐条核实)

3.1 单一 Dense Prediction Head(非纯 MLP-only)

论文探索过 fully convolution-free(纯 MLP)解码器:定量指标更好、更快更省显存、梯度更稳,但定性产生块状伪影(尤其户外远景/天空/山脉,因 depth 无界)。mipmap 监督、概率混合建模均未可靠消除(§5)。

最终设计(§3.1.3, §5):保留 DPT 的早期低分辨率卷积层(16×16/32×32,开销小),将 1/4 分辨率以上的高分辨率卷积块替换为"单层 MLP + pixel-shuffle"。MLP 输出 $2u^2$ 通道($u{=}4$,即 32 通道),pixel-shuffle 重排为 $(uH')\times(uW')\times2$(深度+置信度)。多任务损失(point/matching)保留但仅作训练时监督,无独立 head——通过 $\mathcal{L}_{point}$(对 unprojection 误差)、$\mathcal{L}_{match}$(最后一层 token)监督,接近多 head 性能且大幅省显存(§3.2)。相机头:对 camera token + register 跑轻量 transformer + MLP,单次预测(无 VGGT 的迭代细化)。

3.2 Register Attention(§3.1.2, Fig.2/3)

每帧附 1 个 camera token + 16 个 register(scene token),token 化来自 DINOv3(patch 16)。机制:在 25% 的 global attention 层中,自注意力仅限各帧 register 之间,更新后的 register 在后续 frame-wise attention 中把聚合的 scene 信息 redistribute 回 image token,形成 bottleneck。

$$\text{global: }O\big((N(P{+}17))^2\big)\approx O((NP)^2)\;\Longrightarrow\;\text{register: }O\big((16N)^2\big)=O(256N^2)\;\text{(与 }P\text{ 无关)}$$

经验数字(§1 脚注 + §5):替换 25% → 无可测精度损失、省 ~23% FLOPs、省 16% backbone 显存;替换全部 → FLOPs 降至原 6%,但精度降到原版 VGGT 水平(register 无法完全替代 global)。

3.3 动态场景支持(表示选择 + 标注流水线,非自监督)

机制澄清(纠正旧版误读):动态能力不来自自监督,而来自:① 表示选择——只预测 depth + camera,不输出 motion mask/dynamic point map/ray map(论证:point map 需分割运动像素如 MonST3R;ray map 耗资源且把相机信息与像素外观变化纠缠);数据驱动模型从数据学运动先验,取代手工低秩/局部刚性假设;② 新标注流水线(§3.5.2)产出 ~200K 动态 + ~600K 静态高质量标注(共 0.8M,约占 40M 互联网视频的 2%)。自监督(§3.4)是独立的一般化增强手段,与动态能力无直接因果。

4Scaling Law:可预测的规模扩展

VGGT-Ω 的核心发现(§1, Fig.1):前馈 3D 重建模型的质量随模型与数据规模可预测地提升(幂律)。Fig.1 给出模型 0.2B→10B、数据 2K→2M sequences,3D point error 单调下降,曲线呈 power-law 形态。

5.1 自监督协议(§3.4,纠正旧版)

Teacher-Student + EMA(真实机制):$\theta^T\leftarrow m\theta^T+(1-m)\theta^S$($m{=}0.999$);学生匹配教师:跨层 ℓ2 feature-matching loss + camera/depth 回归损失;camera/depth head 冻结防 collapse;增强含 color/blur/90°-rot/patch-mask/frame-reorder。§5 明确:自监督"had little impact on most benchmarks"但改善 OOD,且仍需预训练初始化(尝试 RayZer/E-RayZer/NeRF/GS/掩码/时序从 scratch 均失败)。

旧版虚构纠正:"置信度加权"论文未提及;"几何一致性过滤"是数据标注流水线(§3.5.2 的 multi-view consistency + XGBoost/RandomForest/CatBoost 分类器,基于 camera-up 一致性/parallax/trajectory smoothness,500+500 人工标注训练)的环节,不是自监督协议内容。自监督纯为 DINO 式 EMA 师生蒸馏,无伪标签生成(教师即学生 EMA 自身)。

7消融实验(纠正旧版错误)

旧版消融数字全部错误,现据论文(§4.3, §5,1B/2M/64GPU/150k 监督步,point error↓越低越好)纠正:

旧版错误 ①:Register Attention 消融

旧版称"去掉 ↓15% 精度、↑2.3× 显存"——证伪。论文:register 是纯效率工具(25% 替换无精度损失,省 23% FLOPs/16% backbone 显存;全 register 退化到 VGGT 级)。15% 与 2.3× 数字论文不存在。

旧版错误 ②:自监督消融

旧版称"去掉 ↓22%"——证伪/方向反了。论文:加入自监督使 point error 0.073→0.070(提升);§5 明说自监督"had little impact on most benchmarks"但改善 OOD。无 22% 此数。

8额外发现:VLA 迁移 + 语言对齐

register 增强 VLA(§4.4,Table 3)

提取 register(scene token)拼到 OpenVLA-OFT 输入,VGGT-Ω 冻结。LIBERO 平均成功率 98.5% vs OpenVLA-OFT 97.1%(+1.4);Object 99.3/Goal 99.2/Long 99.0。对比 π0 94.2、UniVLA 95.2、CoT-VLA 83.9。3D 重建的几何表征可迁移到机器人空间理解。

语言对齐(§4.4,Fig.8)

VLM 描述场景→文本 token mean-pool+ℓ2;Ω 侧小 self-attention stack 跨 register + 可学 language token→project+ℓ2;symmetric InfoNCE。VLM 冻结、Ω 端到端微调(LR 1e-5)。10K 步后检索:top-1 76.8% / top-3 97.0%;零样本迁移 Qwen3 纯文本 LLM embedding:top-1 47.5%。对齐后几何任务无退化。register 即 3D 场景的"CLS token"。

类比:CLIP 的 CLS token 是图像语义摘要,VGGT-Ω 的 register 是 3D 场景几何摘要——都经大规模预训练学到的紧凑表示,可迁移下游。3D 重建不仅是独立任务,更是通向空间智能的代理任务(proxy task)。

11可改进方向分析(代码佐证)

[方法·高优先级] 改进 1

自监督协议增益有限且依赖预训练初始化

问题:§5 原文自监督"had little impact on most benchmarks",且"expected self-supervised reconstruction to work from scratch, whereas our successful approach still requires a pretrained model";尝试 RayZer/E-RayZer/NeRF/GS/掩码/时序从 scratch 均失败。佐证:§4.3 自监督使 point error 0.073→0.070(仅 −0.003)。建议:探索无需预训练 init 的自监督目标,或并入 omni-model 多模态统一训练(§6 已暗示方向)。

[方法·中优先级] 改进 2

MLP-only 解码器块状伪影(深度无界)

问题:§5 Dense Prediction Heads:MLP-only 定量更好但户外产生块状伪影,mipmap/概率混合未可靠消除。建议:在对数深度空间或带界数值空间预测,或引入局部深度方差监督的改进版。

[数据评估·高优先级] 改进 3

动态监督保守,运动物体 depth 实质无监督

问题:§3.5.2 流水线丢弃动态区域 depth(仅静态像素过 multi-view consistency);§3.3 不输出显式动态量。动态能力是隐式先验而非显式 4D 监督。建议:引入 4D 点轨迹/光流显式监督,或放宽动态接受准则并辅以运动掩码验证。

[工程·中优先级] 改进 4

10B 未开源 + 文本对齐仅 1B/256

问题:HuggingFace 仅 VGGT-Omega-1B-512 与 1B-256-Text-Alignment,10B 仅论文数字不可复现;text-alignment 无 10B 版。佐证:GitHub README + HF 模型库。建议:蒸馏 10B→1B,或以 FP8/INT8 发布 10B,补 10B-Text 变体。

[方法·中优先级] 改进 5

Register attention 25% 无精度增益,纯效率工具

问题:§4.3(25% 替换 0.073 vs 全 global 0.071,几乎相同)、§5(全 register FLOPs 6% 但降到 VGGT 级)。建议:设计自适应 register 数量或层级稀疏 global+register 混合(早期层全 global、后期层全 register),在效率/精度间更优帕累托。

个人最关键三点:改进 1(自监督依赖预训练,决定能否真正利用互联网规模无标注数据)、改进 3(动态监督保守,决定 4D 能力上限)、改进 4(10B 未开源,决定社区能否复现/跟进)。这三点也指向 VGGT-Ω §6 自预判的下一代方向:unified/omni-model(把 reconstruction 作为 omni 模型的一个任务,深度作图像生成、相机作文本自回归)。

12SOTA 地位与总结

截至论文发表(2026-05):VGGT-Ω 在 3 个静态(7Scenes/NRGBD/ETH3D)+ 3 个动态(DyCheck/Sintel/TUM)基准上以显著优势达到前馈 3D 重建 SOTA,全面超越 DA3(1B Giant)、π³、MegaSaM、MonST3R、MapAnything、原版 VGGT。几何质量 SOTA 成立,且验证 Scaling Law、开源 1B + 模型/Demo 齐全。

2026 下半年挑战者:仅凭此论文与项目主页无法确认 6–8 月有新方法超越。论文 §6 自预判下一代可能走向 unified/omni-model,并提到并发工作 [67] 在自监督上有类似观察——这些是潜在挑战方向。在 Pareto 全谱调研 中,VGGT-Ω 仍被定位为几何轨道质量 SOTA(Sintel AUC@3°=40.0 断层领先),亚秒级,2026 H2 无已确认挑战者。

VGGT-Ω 的历史地位

① 首次验证前馈 3D 重建 Scaling Law(0.2B→10B 幂律);② Register Attention 把显存压至 30% 使规模化可行;③ 动态场景支持拓宽应用域;④ register 作 3D"CLS token"可迁移 VLA/语言,3D 重建成为空间智能代理任务;⑤ CVPR 2025 Best Paper → CVPR 2026 Best Paper Finalist 的传承。

局限

① 10B 未开源,数字不可复现;② 自监督增益有限且依赖预训练 init;③ 动态监督保守(运动物体 depth 实质无监督);④ MLP-only 户外块状伪影;⑤ Register 25% 无精度增益(纯效率);⑥ 强运动模糊/FOV 突变退化;⑦ 迭代细化可再 +4–6% AUC@3° 但为简洁牺牲。

一句话:VGGT-Ω 是前馈 3D 重建的规模化里程碑——以 Register Attention 把显存压至 30% 从而验证 Scaling Law,在 6 基准断层领先(Sintel AUC@3°=40.0,+77% vs 次优),并展示 register 向 VLA/语言的迁移能力;但 10B 未开源、自监督依赖预训练、动态监督保守是其留待下一代(omni-model)的三个缺口。
