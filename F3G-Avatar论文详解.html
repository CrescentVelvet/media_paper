1.1 核心问题

现有全身高斯化身（Gaussian Avatar）方法主要优化全局重建质量，但常常无法保留细粒度的面部几何和表情细节。原因：

问题说明
面部表示容量不足面部在全身面积中占比很小，全局优化倾向于将容量分配给身体，面部被"淹没"
高频位姿依赖形变困难面部表情变化（微笑、眨眼等）是高频形变，现有方法难以建模
过度平滑面部关键特征丢失或扭曲 → 显著的感知质量下降，引发"恐怖谷"效应

二、核心创新概述

创新一：双分支架构 — 身体 + 面部分离建模

从穿着衣服的 MHR（Momentum Human Rig）模板出发，渲染前后位置图，通过双分支架构解码为 3D 高斯：身体分支处理全身位姿依赖非刚性形变；面部聚焦形变分支精细化头部几何和外观。

创新二：面部聚焦形变分支

独立的面部子网络（三个轻量 StyleGAN 网络）从高分辨率面部位置图预测位置偏移、颜色和辅助高斯属性。面部高斯经三线性插值上采样提高分辨率。

创新三：区域感知重建 + 面部对抗损失

身体和面部高斯融合后经 LBS 变换并渲染。训练结合重建损失 + 感知损失 + 面部专属对抗损失（预训练 StyleGAN2 判别器），增强特写视角的真实感。

创新四：MHR 穿衣模板

使用 Momentum Human Rig (MHR) 替代 SMPL-X 作为身体模板，支持穿衣服的化身表示，从 SMPL-X 参数转换得到。

3.1 3D 高斯泼溅基础

场景表示为各向异性 3D 高斯集合 𝒢 = {Gᵢ}，每个高斯 Gᵢ = (xᵢ, Σᵢ, αᵢ, fᵢ)：

  • xᵢ ∈ ℝ³：3D 中心位置（均值）
  • Σᵢ ∈ ℝ³ˣ³：协方差矩阵（由缩放 s 和旋转 q 参数化）
  • αᵢ ∈ [0,1]：不透明度
  • fᵢ：球谐系数（视角相关颜色）

渲染：前后深度排序 → α 混合合成。协方差投影到屏幕空间后取 2×2 子矩阵定义图像平面椭圆。

3.3 MHR 身体模板

采用 Momentum Human Rig (MHR) 作为表示基础。MHR 是一种穿衣人体模板，支持比 SMPL-X 更丰富的衣服几何。

SMPL-X → MHR 转换：通过优化 MHR 的形状/位姿参数，最小化与 SMPL-X 模板顶点和关节位置的差异：

min ‖V_mhr − V_smplx‖ + λ‖J_mhr − J_smplx‖

重建从 A-pose（近星形位姿）的子集帧开始，提取穿衣模板。

3.4 全身规范形变（Global Canonical Deformation）

  • BodyUNet（基于 StyleUNet 的生成器）处理 512×512 规范位置图
  • 预测 1024×1024 的颜色、位置偏移和辅助高斯属性图
  • 捕捉位姿依赖的非刚性形变（衣物摆动、肌肉形变等）
  • 包含约 320K 个身体高斯

3.5 面部聚焦形变（核心创新）

3.5.1 规范面部模型

  • 从预训练 BodyUNet 模板中提取头部区域
  • 将每帧头部位置图变换到规范坐标系，跨数据集平均得到规范面部高斯
  • 通过三线性插值上采样规范面部高斯网格，提高空间分辨率
  • 包含约 60K 个面部高斯

3.5.2 位置面部图

  • 从全身图中裁剪 512×512 面部区域
  • 相应更新相机内参（缩放因子 s，裁剪偏移）
  • 用更新后的内参渲染正交前后面部位置图
K_new = [s·fx, 0, s(cx−xc); 0, s·fy, s(cy−yc); 0, 0, 1]

3.5.3 面部聚焦高斯图

使用三个轻量 StyleUNet从头部位置图预测高斯属性：

网络输入输出
位置 StyleUNet 𝒫头部位置图位置偏移（高斯形变）
颜色 StyleUNet 𝒞形变后位置 + 相机参数球谐颜色系数
辅助 StyleUNet 𝒜形变后位置不透明度 + 缩放 + 旋转

三路输出拼接为残差高斯属性图：

ΔG_v^h = 𝒞(P̂_v^h, K_new, R, t) ∥ 𝒜(P̂_v^h) ∥ P_v^h
为什么面部需要独立分支？面部在全身面积中占比极小，全局优化会将其"淹没"在身体重建中。独立分支为面部分配专属表示容量，通过高分辨率裁剪和上采样捕捉面部高频细节（表情、皱纹、眼睛运动等）。

3.6 区域感知重建

  • 面部预测高斯与规范面部高斯融合，再与身体高斯合并
  • 合并后通过线性混合蒙皮（LBS）变换到位姿空间
  • 使用 3DGS 可微渲染器渲染到图像域
  • 预训练 StyleGAN2 判别器应用于渲染的面部裁剪 → 提供非饱和对抗损失 ℒ_adv

六、消融实验

6.1 组件消融（AvatarReX 面部指标）

变体PSNR↑SSIM↑LPIPS↓
无面部聚焦形变25.7210.9510.107
无 MHR 模板26.0150.9630.090
无对抗损失 ℒ_adv27.0100.9590.091
完整模型26.2430.9640.084
  • 移除面部聚焦形变 → LPIPS 大幅恶化（0.107 vs 0.084），SSIM 下降 → 确认面部分支的核心价值
  • 移除 MHR 模板 → PSNR/SSIM 下降 → MHR 穿衣模板提供更好的初始几何
  • 移除对抗损失 → PSNR 反而最高但 LPIPS 更差 → 对抗损失提升感知质量而非像素级指标

6.2 输入分辨率与网络容量

配置PSNR↑SSIM↑LPIPS↓时间(ms)

  • 通道倍数 cm 从 1→2：PSNR +0.5 dB，但运行时间增加
