1论文概要与核心贡献

一句话:MoGe-3 在 MoGe-2 基础模型之上外挂一个自引导稀疏 3D 精炼器(SSR)——把初始点图抬到以 log-depth 量化的稀疏体素壳上,用稀疏 3D 卷积按「真实 3D 邻域」而非「图像面邻近」聚合特征,迭代预测 log-depth 残差,把栅栏、灯杆这类细长结构的扭曲失真修回来,同时保持 metric-scale 输出与接近实时的速度。

问题-方法-结果:现有单目几何模型(2D 卷积解码器 / VAE 解码 / 2D UV query 的 MLP 头)都在 2D 参数化里解码 3D 几何,特征交互由图像面距离主导,深度不连续处的前背景特征被错误混合,细长结构被过度平滑(§1)。MoGe-3 保留强 2D 基础模型做外观理解,把几何建模搬到 3D 空间:每像素恰占一个体素(共 $HW$ 个占用体素,计算量随占用线性),稀疏卷积只在 $|Δζ|≤1/D$ 的 3D 邻域内聚合。结果:9 个 zero-shot benchmark 上全局/局部/边界指标全面 SOTA(Table 1),ViT-L 默认模型局部点图阈值精度 $\delta_{0.01}^{p}$ 从 MoGe-2 的 46.6 提到 55.9,延迟 121 ms@700²(A100 FP16,Table 2)。

2研究背景与动机

2.1 观察到的失败模式(§1)

作者对现有 SOTA 单目几何模型的失效描述非常具体,不是泛泛的"效果不好":

  • 扭曲的栅栏、涂抹的灯杆:"while current models produce plausible global layouts, they often struggle to faithfully reconstruct fine-scale geometry, particularly for thin or elongated structures, resulting in severe distortions such as twisted fences or smeared poles"(§1)。
  • 2D 可视化下隐形、换视角才暴露:"such artifacts are often inconspicuous in 2D depth visualizations but become evident under viewpoint changes, exposing underlying 3D geometric distortions"(§1)。这意味着只看深度图指标的评测会系统性低估该问题——作者因此专门构造了 local/boundary 指标(§4.2,本笔记 §11)。

2.2 归因:2D 参数化的架构错配(§1,作者假设)

核心洞察(作者原文假设):"We hypothesize that this issue is due to a fundamental architectural mismatch: most current monocular reconstruction models decode 3D geometry within a 2D parameterization. ... In all cases, feature interactions are governed by image-plane proximity rather than true 3D geometric relationships. This introduces a local smoothness prior that inadvertently mixes features from geometrically distant surfaces across depth discontinuities and over-smooths geometry."

2D 卷积解码器

前馈模型的主流解码方式(Depth Pro、MoGe-2、UniK3D 等;§1 引 [18,30,4,44,45,13,54,58])。卷积核在图像网格上滑动,一根前景细杆与背后远墙在 2D 上相邻,特征被同一卷积核混合 → 杆被"抹"进墙里。

VAE 解码(扩散类)

扩散式深度模型在 latent 空间生成、VAE 解码回深度图(§1 引 [16,9],如 Pixel-Perfect Depth 路线)。解码器同样是 2D 卷积, latent 中的深度不连续在解码时被平滑先验抹平。

MLP over 2D UV queries

近期方法在 patch latents 或 2D UV 查询上接 MLP 头(§1 引 [51,58],如 InfiniDepth)。逐像素独立回归虽无显式卷积混合,但 query 本身按图像网格组织,缺乏跨像素的 3D 感知交互。

2.3 关键假设的失效条件(本笔记分析)

假设何时失效:作者的判断"local structural integrity breaks down when 2D proximity diverges from true 3D relationships"(§1)有两种发散方向:① 图像相邻但 3D 远离(遮挡边界、深度不连续)→ 特征被错误混合,这是本文主攻的;② 图像远离但同属一个 3D 表面(细长结构的两个远端)→ 2D 参数化下无法关联,本文靠 3D 邻域卷积部分缓解。SSR 自身的隐含假设:体素壳的邻接判据 $|ζ_{ij}-ζ_{i'j'}|≤1/D$ 依赖前一步的 log-depth 估计——若初始误差大于 $1/D$,错误的壳会把不同表面连成邻居,误导 3D 卷积感受野(自引导的级联风险,见 §5 与 §15)。

此外,作者承认回归范式的固有局限(§5 Limitations):"regression-based paradigm inherently struggles to resolve pixel ambiguity along object boundaries... introduces 'fly-points'",即边界像素的深度在原理上二义,完全锐利的深度边无法由回归得到——这是本文没有解决、留待生成式方法(如 Pixel-Perfect Depth [51])融合的方向。

2.4 与 MoGe 系列的关系

MoGe(CVPR 2025 oral 级别影响力,affine-invariant 点图 + 最优监督)→ MoGe-2(2025-07,metric scale + 数据精炼锐化细节)→ MoGe-3(本文,2026-07,3D 稀疏精炼修细节)。MoGe-3 的 base 直接初始化自 MoGe-2(§1:"initialize the base geometry estimator from MoGe-2"),SSR 是外挂模块,可视为"第三代 = 第二代 + 3D 精炼器 + 联合训练"。库内此前未收录 MoGe 系列笔记,本篇为系列首篇。

4.2 数学形式化

点图以分解坐标表示(式(2))——这是 SSR 的前提:把 $(X,Y,Z)$ 分解为射线方向 $(u,v)$ 与 log 深度 $ζ$,精炼只动 $ζ$:

$$\boldsymbol{q}_{ij}=(u_{ij},v_{ij},\zeta_{ij})=\left(\frac{X_{ij}}{Z_{ij}},\frac{Y_{ij}}{Z_{ij}},\log Z_{ij}\right) \text{(式 2)}$$

base 的监督是光轴仿射不变的(式(1)),因此 base 输出本身不带绝对尺度;metric 尺度由 scale_head 单独预测并在最后相乘(§3.1;v3.py:321-323)。

4.3 前向流程(v3.py:113-217)

  1. 按 num_tokens 与宽高比解出 base 网格 $(b_h,b_w)$(v3.py:127-132);
  2. DINOv2 编码得 4 层中间特征 + cls_token(v3.py:135);每层特征拼接归一化 UV 坐标(aspect-ratio 条件,v3.py:139-145)——最细层拼接后通道数 $1024+2=1026$,即 refiner 的 encoder_channels;
  3. 共享 neck 融合,points/normal/mask 三个 2D 头解码,scale_head 从 cls_token 出 metric scale(v3.py:148-156);
  4. points_head 原始输出 raw_coord 形状 $[B,3,H,W]$,通道序 $(x/z,\ y/z,\ \log z)$(v3.py:163-164),经 remap_output='exp'(v3.py:38)映射回点图;
  5. 推理后处理(infer,v3.py:219-381):逐步恢复 (focal, shift)(v3.py:304-312)、force_projection 用内参重投影点图(v3.py:318-319)、乘 metric scale(v3.py:321-323)、mask 过滤无效点(置 inf,v3.py:350-356)。

5模块二:Self-Guided Voxelization(自引导体素化)

体素化是 SSR 的"地基":它决定了 3D 卷积把哪些点当邻居。设计要点是让壳同时满足投影对齐、尺度不变、几何相干三条性质(§3.2.1)。

5.1 数学形式化

$$\mathcal{V}^{(k)}=\left\{\boldsymbol{c}_{ij}^{(k)}\right\},\qquad \boldsymbol{c}_{ij}^{(k)}=\left(i,\,j,\,\left\lfloor D\cdot\zeta_{ij}^{(k)}\right\rceil\right) \text{(式 3)}$$

图像轴 $(i,j)$ 天然离散;深度轴把 log-depth $ζ$ 乘以分辨率 $D$ 后四舍五入量化。每个像素恰好映射到一个体素 → $l{=}0$ 层形成"恰有 $HW$ 个占用体素的薄流形壳"(§3.2.1),计算量对占用体素数线性。

5.2 三条设计性质与机制解释

① Projection-aligned

体素网格的 $(i,j)$ 两轴与图像像素网格完全对齐 → 无需学习的投影/反投影,2D 特征可按 $(i,j)$ 直接 gather(见 §6.3),且壳分辨率随输入分辨率自适应。

② Scale-invariant

量化作用在 $\log Z$ 上:乘性深度误差(全局尺度 $s$)在 log 域变成加性常数,被 per-batch 的 z-offset 吸收(源码 v3.py:88-89)→ "shell density and connectivity remain invariant to metric scale transformations"(§3.2.1)。这正好匹配 base 的仿射不变监督。

③ Geometry-coherent 感受野

3×3×3 稀疏卷积的邻居 ⟺ 图像相邻且 $|ζ_{ij}-ζ_{i'j'}|≤1/D$——深度差超过一个量化格的两个表面在 3D 网格上不相邻,特征自然解耦,"preventing the 'bleeding' and 'twisted' artifacts inherent in 2D-based feature mixing"(§3.2.1)。

⚠️ D 的取值:论文 200 vs 代码 256。论文 §3.2.1 与 §4.5 消融均以 $D{=}200$ 为默认(Table 3 的 ⋆ 行);而官方仓库 configs/train/v3.json:194 为 "refiner_depth_resolution": 256。两者方向一致(论文消融显示 D=200 与 D=300 之间是平台期),但数值不等,【待核实】发布配置可能在论文投稿后重新调过。复现时以代码为准。

6.2 稀疏卷积与动态稀疏性

  • 子流形稀疏卷积(SubmanifoldConv3d):来自 flex_gemm(JeffreyXiang/FlexGEMM,钉在 commit b2fadb29,pyproject.toml:28)——即"输出体素集 = 输入体素集"的稀疏卷积,不在空处生发新体素,保证壳拓扑不被卷积撑爆。通道数 ≥128 时用 masked_implicit_gemm,否则 implicit_gemm(flex_sparse_blocks.py:15-23)。
  • 动态稀疏下采样(§3.2.2):第 $l$ 层体素集 $\mathcal{V}^{(k),l}=\{\lfloor\tfrac{1}{2^{l}}\boldsymbol{c}_{ij}\rfloor\}$——图像轴被池化压缩,但"structures that collapse to the same image-space location can still remain separated along the depth dimension, leading to multiple occupied voxels around depth discontinuities":不同深度的体素在 2×2×2 池化后仍是不同体素,前背景在多尺度处理中保持分离。这正是 2D U-Net 做不到的(§12 消融对照)。
  • NeighborCache 复用(sparse_unet.py:184-204 注释):同层下采样与对称上采样坐标一致,邻居索引缓存(level_conv_caches / level_down_caches)在 down/bottleneck/up 三段复用,省掉重复建图——这是 K 次迭代下延迟仍可控的关键工程手段之一。

6.3 2D 特征注入(源码细节:只在 bottleneck,按 (i,j) gather,z 轴共享)

论文说"at the lowest resolution level, the encoded voxels are concatenated with 2D features F"(§3.2.2)。源码给出精确机制:

  1. 下采样路径结束后,对 bottleneck 层每个体素取其坐标 $(b,i,j,z)$ 的前三个分量,直接在稠密 2D 特征图 encoder_feature(形状 $[B,1026,H/16,W/16]$,即 DINO 最粗层 + UV)上按 $(b,:,i,j)$ 索引取值(sparse_unet.py:154-168 _sample_encoder_feature)——注意 $z$ 轴被忽略:同一射线上不同深度的体素拿到同一份 2D 特征(论文:"Voxels sharing an image location but differing in depth duplicate the same 2D feature",§3.2.2);
  2. Linear 1026→512(encoder_fuse,sparse_unet.py:75),与体素特征 concat 后经 fuse_proj(Linear→SiLU→Linear,sparse_unet.py:77-81)融合回 512 维;
  3. 注入只发生在 bottleneck 一处,不是多级注入。
机制解释(为什么瓶颈注入就够):bottleneck 层的体素感受野已通过 4 次 3×3×3 卷积 + 3 次池化覆盖大 3D 邻域,此处注入语义特征可以让" appearance 证据"沿 decoder 路径回流到每个输出体素;若在高层注入,2D 特征没有 3D 上下文支撑,反而容易把图像面邻近平滑回去。RGB 替代注入的消融(Table 3)证明语义特征不可替代——RGB Input 变体 $\delta_{0.01}^{p}$ 只有 49.7,远低于 DINO 注入的 55.1。

6.4 前向流程(sparse_unet.py:170-242)

  1. input_proj 把 $(M,3)$ 映射到 32 维;
  2. 5 级 down:每级残差块 → 缓存 skip → PoolDown 建邻居缓存;
  3. 最深层 gather 2D 特征、融合、过 bottleneck 块;
  4. 4 级 up:NearestUp(用上采样转置缓存 .T)→ 加性 skip → 残差块;
  5. out_proj 输出 $(M,1)$ log-depth 残差。

7模块四:log-depth 残差迭代更新

7.1 数学形式化

$$\boldsymbol{q}^{(k+1)}_{ij}=\left(u_{ij},\,v_{ij},\,\zeta_{ij}^{(k)}+\Delta\zeta_{ij}^{(k)}\right) \text{(式 4)}$$
$$\boldsymbol{p}^{(K)}_{ij}=e^{\zeta^{(K)}_{ij}}\cdot\left(u_{ij},\,v_{ij},\,1\right) \text{(式 5)}$$

三个要点:

  • 只更新 $ζ$:$(u,v)$ 全程固定(§3.2:"the refiner only predicts log-depth residuals")——refiner 只能沿射线推拉点,不能横向移动。这是刻意的设计收缩:横向误差由 base 负责,refiner 专注于深度维的细节修复(设计边界见 §15)。
  • 每步重新体素化(自引导):更新后的 $\zeta^{(k+1)}$ 重新离散化为下一步的壳(§3.2.3),壳结构随估计改进而自我修正——故名 Self-Guided。源码:v3.py:171-176 循环内每次调用 _refine_logz → _voxelize 重建 coords。
  • 残差恒等初始化:out_proj 零初始化(sparse_unet.py:120-122)→ 训练起步时 $\Deltaζ=0$,$ζ^{(1)}=ζ^{(0)}$,精炼器从"什么都不做"开始学修正(§3.2.2:"allowing identity mapping"),配合两阶段训练稳定早期优化(§8.3)。

7.2 K 的设置与泛化(§4.1, §4.5, Fig. 4)

  • 训练 K=3,推理默认 K=3(§4.1);消融实验统一训练 K=3、评估 K=5(§4.5,Table 3 表注);
  • Fig. 4 测试 $K\in\{0,1,\dots,5,7\}$:"local metrics improve substantially after the first step and continue to improve gradually before saturating around K=5, while global metrics remain nearly unchanged";"Running up to K=7 yields slightly improved or stable metrics"——每步学的是收敛性修正而非过拟合固定步数(§4.5);
  • K=0 时模型与 MoGe-2 延迟完全相同(共享 base 架构,§4.3)。

8.3 训练策略:两阶段 + 双数据流(§3.3 + 源码验证)

  • Stage 1(warm-up,前 5000 步):"detaches gradients from the base model features to the refiner"(§3.3);源码 refiner_detach_backbone_until=5001 + out_proj 零初始化 → refiner 从恒等映射起步,"learn residual corrections starting from a known-good initialization"。
  • Stage 2(联合微调):5000 步后全梯度导通端到端联合训练,"prevents large early-stage gradients of refiner from corrupting the representation of well-pretrained base model"(§3.3)。K=0(联合训练的 base)已优于 MoGe-2(§4.5)——联合训练本身就有收益。
  • 双数据流(refine_ratio=0.5):源码 get_refine_accumulation_schedule(train_moge3.py:72-84)在梯度累积微批内按配额调度——50% 微批走合成数据(refine_steps=3),50% 走真实数据(refine_steps=0)。"the refiner receives gradients only from synthetic samples, whose pixel-accurate ground truth is essential for learning sharp and geometrically correct residual corrections, while the base model is supervised on the full mixture"(§3.3)。

10.4 落地坑(源码级)

  • 体素化必须 fp32(v3.py:75-77):量化步长 1/256 细于 fp16 分辨率,半精度下体素会塌缩/抖动——混合精度部署时这段不能 autocast。
  • z_extent 动态变化(v3.py:88-90):深度轴格数 = 当前 batch 的 logz 动态范围 ×256,无固定上限;极端深度范围(近景 0.1m + 远景 1km,$\log$ 域跨度 ~9.2 → 约 2360 格)会显著增加邻居建图开销。
  • eval 分辨率按数据集固定(configs/eval/moge3.json):NYUv2 640×480、KITTI 750×375、ETH3D 2048×1365、iBims-1 640×480、Sintel 872×436、DIODE 1024×768、Spring 1920×1080、Synth4K 3840×2160、HAMMER 1664×832——Table C.4 的 700² 是统一报告档,实际评测按原生分辨率。
  • CLI 必须显式给权重(README:241-242):moge infer --version v3 --pretrained PATH --refine_steps 3,v3 不像 v1/v2 有默认权重路径。
  • 梯度检查点:enable_gradient_checkpointing 会包装全部残差块(sparse_unet.py:144-147),训练大分辨率时省显存。

12.2 消融结论(§4.5 原文要点 + 本笔记解读)

  1. D 的甜区在 200–300:"Increasing the voxel resolution from D=100 to moderate resolutions (D=200–300) substantially improves local metrics while preserving global accuracy";D=400 时"increasingly sparse occupancy... limits the effectiveness of the 3D sparse convolutions",全局局部双降。作者选 D=200 作精度-占用-效率折中(代码最终取 256,见 §10.2)。从表格看 D=300 在全局三格反而略优于 D=200,作者的选择明显偏向局部指标($\delta_{0.01}^p$ 55.1 vs 52.0)。
  2. 2D 卷积变体失败:参数对齐的 2D U-Net"simply increasing model capacity in 2D does not provide the gains achieved by 3D refinement"——局部 $\delta_{0.01}^d$ 45.0 甚至比 base 的 47.1 更差。这是全文最关键的消融:提升来自 3D 参数化本身,不是来自"加了个更大的网络"。
  3. DINO 语义特征不可替代:RGB Input 变体 $\delta_{0.01}^p$ 49.7,高于 base(46.6)但远低于 DINO 注入(55.1)——"semantic and contextual information provided by visual features is crucial for resolving fine structures and disambiguating local 3D geometry"(§4.5)。
  4. K 的泛化(Fig. 4):训练 K=3,测试 K 增至 7 不退化:"each refinement step learns a stable, convergent correction rather than overfitting to a fixed number of iterations"(§4.5)。局部指标约 K=5 饱和,边界 F1 第 1 步即获大部分收益。
  5. 联合训练的独立收益:K=0(联合训练 base)已超过 MoGe-2 baseline(§4.5)——SSR 训练信号反哺了 base。

13.2 对比结论(机制层面,逐条"为什么")

  1. 对 Depth Pro:Depth Pro 用 1536² 原生分辨率堆细节,F1(16.3)与 MoGe-3(16.0)相当,但局部 $\delta_{0.01}^p$ 差 10.7 个点(45.2 vs 55.9)——分辨率堆不出 3D 邻接关系,且延迟反而更高(142 vs 121 ms @ 3.4× 像素)。
  2. 对 MoGe-2(自家前代):同一 base 冻结后仅加 SSR(Table 3)局部 $\delta_{0.01}^p$ +8.5(46.6→55.1);全局指标基本不动甚至微降(metric Rel 15.6→16.4)——SSR 是局部细节专用工具,全局布局仍由 base 决定。这解释了为什么作者坚持"精炼"而非"重训全局"。
  3. 对 DA3 / UniK3D:二者全局 δ₁ 与 MoGe-2 相当(91.4/92.8 vs 94.1),但局部与边界大幅落后(DA3 F1 仅 6.61)——大规模数据提升了泛化,但 2D 解码的平滑先验在细结构上无能为力。
  4. 对 PPD / InfiniDepth(细节特化方法):这两个恰是"2D 深度图好看"的代表——PPD 的像素空间扩散、InfiniDepth 的连续 UV 查询都在 2D 参数化内;它们的边界 F1 不差(12.7/19.3,InfiniDepth 甚至是第一),但点图指标(局部 δ₀.₀₁ᵖ 39.1/43.7、全局 69.8/87.6)明显弱,印证了"2D 锐 ≠ 3D 准"——换视角才暴露的失真正是本文的靶子。
  5. 对生成式路线的定位:作者自己指出(§5)回归范式在边界像素上的二义性是固有的,fly-points 要靠 PPD 式生成式表述解决——MoGe-3 与 PPD 在路线图上不是替代关系而是潜在的互补(base 换扩散或 refiner 输出换概率建模)。

① [高优先级] 自引导壳的级联失效风险(method)

问题:体素壳的邻接关系由前一步 $ζ^{(k)}$ 决定(式(3)),若 base 在某区域误差 $>1/D$(log 域约 0.005,即深度差 0.5%),错误壳会把异表面连成邻居,3D 卷积在错误邻域上聚合,误差被逐步固化——论文未分析该失效模式,Fig. 4 只展示了 K 增加"不退化"的良好情形。证据:v3.py:171-176 每步用 current_coord.detach() 重新体素化,无置信度门控。建议:给每个体素附带不确定度通道(base 可用多步采样方差估计),或在体素化时对 $|Δζ|$ 超阈值的邻接做显式断开。

② [高优先级] 只修 log-depth,横向几何误差不可修(method)

问题:更新式(4)固定 $(u,v)$,refiner 只能沿射线推拉点;若 base 的误差在横向(边缘错位、FOV 不准),SSR 原理上无法纠正。论文边界 F1 第三(16.0,输给 InfiniDepth 19.3)与此一致——边界错位是横向误差。证据:式(4);v3.py:174 torch.cat([current_coord[..., :2], refined_logz.unsqueeze(-1)], dim=-1) 只替换第三通道。建议:让 U-Net 输出 3 维残差(Δu, Δv, Δζ),小范围横向修正;消融成本可控。

③ [中优先级] 论文与代码两处数值不一致(文档质量)

问题:$D$ 论文 200 vs 代码 256;2D heads 峰值 LR 论文 $10^{-4}$ vs 代码 $10^{-5}$(§10.2)。虽然方向不影响结论(消融显示 D∈[200,300] 是平台),但说明发布配置与论文配置不是同一份,复现者无法从论文得到真实训练配方。建议:引用超参时以 configs/train/v3.json 为准;已向论文 v3 版反馈的价值——这也是本库坚持源码验证的典型案例。

④ [中优先级] refiner 只见合成数据的域差(data)

问题:refiner 梯度只来自 17 个合成数据集(§3.3),真实传感器噪声下的残差分布从未见过;论文 zero-shot 数字漂亮,但真实数据(如手机拍摄的运动模糊/噪声)上 refiner 是否会"修错方向"缺乏分析。建议:引入真实数据的自监督变体(如多帧一致性),或在真实数据上以更小 LR 微调 refiner 并监控局部指标。

⑤ [中优先级] 回归范式的边界二义性未解(作者自认)

问题:§5 Limitations:"regression-based paradigm inherently struggles to resolve pixel ambiguity along object boundaries... introduces 'fly-points'"。fly-points(漂浮点)在下游 3DGS 初始化里是脏数据。建议:作者建议融合 PPD 式生成式表述;工程上可用 mask 边界的深度梯度检测 + 形态学清理先滤掉 fly-points 再进重建管线。

⑥ [低优先级] 评测协议依赖 SAM2 且局部 mask 只覆盖两个合成集(evaluation)

问题:局部指标仅在 Spring + Synth4K 上计算(§4.3,因需要 dense fine-detail GT),真实数据集上的细结构收益靠定性图支撑;mask 构建引入 SAM2(B.1),评测链路的复现门槛提高。建议:后续工作可在 HAMMER(已有锐利边界标注)上补局部指标;复现评测时注意 SAM2 版本。

优先级总览与"最关键三点"

优先级条目
[高]① 自引导级联失效;② 横向误差不可修
[中]③ 论文/代码不一致;④ 合成域差;⑤ fly-points
[低]⑥ 局部评测覆盖面

个人认为最关键的三点:①(决定方法在恶劣初值下的可信度,也是工程落地的最大不确定性)→ ⑤(fly-points 直接污染下游重建)→ ③(影响复现与引用可信度)。

16总结与演进定位

16.1 总结

MoGe-3 的价值不在"又一个单目深度 SOTA",而在它给出一个有说服力的诊断-处方对:

  • 诊断:2D 参数化解码是细结构失真的架构级根因——特征交互被图像面邻近性主导,深度不连续处前背景互相污染(§1)。参数对齐的 2D U-Net 对照(Table 3)证明这不是容量问题。
  • 处方:自引导稀疏体素壳 + 子流形稀疏 3D 卷积,把特征聚合的邻域定义权交还给 3D 几何;$HW$ 占用体素使开销可控(121 ms@700²),log-depth 量化使壳尺度不变,K 步残差可测试时外推(K=7 不退化)。

从工程视角,MoGe-3 是少见的"论文-代码同日对齐"的微软系工作:训练/推理/评测全量开源、配置可读、权重可下;两处论文-代码数值差异(D、heads LR)属于文档同步问题而非方法问题。

16.2 演进定位

在 MoGe 系列内部:v1 确立"仿射不变点图 + 最优监督"的表示层创新;v2 补 metric scale 与数据侧锐化;v3 把解码侧从 2D 抬到 3D——三代分别对应"监督→数据→架构"三个改进维度。放到领域脉络里(§13.3),MoGe-3 是"点图回归"范式第一次系统引入 3D 空间归纳偏置的工作,其 SSR 模块原则上可插到任何点图回归器(VGGT 系、DUSt3R 系)之后——只依赖分解坐标 $(u,v,ζ)$ 的接口设计(v3.py 的 _voxelize 输入契约)使这种迁移没有架构障碍,这是比单一模型更有生命力的遗产。
