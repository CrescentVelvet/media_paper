MHR: Momentum Human Rig — Meta 新一代参数化人体模型

📄 arXiv: 2511.15586 📅 2025-11-19 (v3: 2025-11-24) 🏢 Meta Reality Labs (47 位作者) ✅ 开源 (industry-friendly license)

📋 论文概要

Parametric Body Model Decoupled Skeleton/Shape Non-linear Pose Correctives ATLAS 基础 Momentum Library FACs Expressions Multi-LoD AR/VR

SMPL 自 2015 年提出后一直是参数化人体模型的事实标准，但存在骨架/形状耦合、表情不兼容艺术家流程、pose corrective 稠密耦合等根本局限。MHR 由 Meta Reality Labs 47 位作者联合打造，基于 ATLAS 的解耦骨架/形状范式 + Momentum 蒙皮库的现代 rig，专为 AR/VR 与图形管线设计，是 SMPL 的正式升级版。

核心贡献：
  1. 解耦骨架与表面：骨架独立参数化，不从 mesh 回归 → 形状/骨架可独立控制
  2. 稀疏非线性 pose corrective：局部 MLP + geodesic 初始化的稀疏 mask，兼顾表达力与稀疏性
  3. FACs 语义表情：72 个艺术家雕塑的 FACS 表情，兼容艺术家工作流（非数据驱动的稠密表情空间）
  4. 多 LoD + 工业友好许可：6 级细节（971~73639 顶点），FBX/GLTF 导出，免费实验许可

🎯 核心问题与动机

SMPL 系列的根本局限

  • 骨架从表面回归：SMPL 的关节位置是从 mesh 顶点加权求和得到的 → 形状和骨架耦合，改身体形状会动关节，给 keypoint fitting 带来错误相关
  • 稠密 pose corrective：SMPL 的 pose corrective 是所有关节→所有顶点的稠密映射 → 远距离的身体部分产生不想要的相关
  • FLAME 表情不兼容艺术家：ATLAS 用 FLAME 的数据驱动稠密表情空间，但艺术家工作流偏好稀疏语义表情（FACs），且数据驱动表情空间含残余 pose 变化（如眨眼不应与 pose 相关）
  • 骨架未优化 pose corrective：ATLAS 骨架不是为叠加 pose corrective 设计的

ATLAS 的进步与不足

ATLAS（Meta 2025）已解决部分问题：解耦骨架/形状、77 关节、稀疏非线性 pose corrective、60 万高分辨率扫描训练。但表情用 FLAME（不兼容艺术家）+ 骨架未为 corrective 优化。MHR 在 ATLAS 基础上补齐这两块。

MHR 定位：不是替代 ATLAS，而是ATLAS + 艺术家友好 + pose corrective 优化的工业级实现。MHR = ATLAS 的解耦范式 + Momentum 库的现代 rig + FACs 表情 + 工业许可。

🏗️ 模型架构

MHR 的形式化定义：

X(β, θ) = M(X̃(βˢ, βᶠ, θ), Bᵏ(βᵏ), θ, ω)

X̃(βˢ, βᶠ, θ) = X̄ + Bˢ(βˢ, S)  + Bᶠ(βᶠ, F)  + Bᵖ(θ, P)

其中:
  X    = 输出顶点 (3V 维)
  M    = LBS 蒙皮函数 (权重 ω)
  X̄    = 中性模板
  Bˢ   = 身份 blendshape (系数 βˢ, 基 S)
  Bᶠ   = 表情 blendshape (系数 βᶠ, 基 F)
  Bᵖ   = pose corrective (pose θ, 参数 P)
  βᵏ   = 骨架变换参数 (68 维: 肢体长度等)
  θ    = pose 参数 (204 维: 136 pose + 68 skel)

1. Pose Parametrization（姿态参数化）

骨架（127 关节）

  • 每个关节：3 平移 + 3 旋转 (XYZ Euler) + 1 均匀缩放 + 常量父偏移 + 常量预旋转
  • 预旋转让 x 轴指向骨头方向（twist 轴），其他轴对称（如 z 轴正向后弯膝盖）
  • 关节变换：T_w = T_p × T_off × T_t × T_prerot × T_rot × T_s

参数映射（204 → 889 关节参数）

204 个模型参数通过线性变换 T_p 映射到 127×7=889 个关节参数。这层映射带来三大能力：

  • 激活自由度子集：只给想控制的关节自由度赋非零值（如肘部只允许单轴旋转）
  • 单参数→多关节：如补充 twist 关节按主关节的分数激活，缓解 LBS candy wrapper 效应
  • 多参数→单关节：如脊柱弯曲用两个重叠参数（上/下脊柱）控制

204 参数拆分：136 pose 参数（每帧变）+ 68 骨架变换参数（每人固定，定义肢体长度等）。

蒙皮

  • LoD 1-4：每顶点 4 关节影响
  • LoD 0：每顶点 8 关节影响
  • 使用艺术家定义的蒙皮权重，不进一步优化（优化权重缺乏结构和局部性，对艺术家不友好）

2. Facial Expressions（面部表情）

关键设计选择：FACs 而非数据驱动
  • 72 个艺术家雕塑的 FACs (Facial Action Coding System) 表情
  • 稀疏、语义化，兼容艺术家工作流
  • 消除数据驱动表情空间的残余 pose 变化（如眨眼不应依赖 pose）
  • 简化与合成数据生成管线的连接

数据驱动表情（FLAME）优势：来自千张扫描，理论上能建模细微表情；正交空间紧凑；自动建模面部相关性。但残余 pose 变化 + 不兼容艺术家是致命问题。MHR 选 FACs 是工程务实选择。

3. Identity Space（身份空间）

身份空间控制固定骨架下的身体形状（不像 SMPL 会改肢体长度/身高）。分三个不相交的子空间：

子空间训练数据成分数说明
Body7110 scans (从 13664 过滤)20体型/年龄/种族多样性
Head (skull)2138 subjects (扩展自 Codec Avatar)20用 Pixel Codec Avatar 拟合中性几何
Hands3000 subjects5手部专用扫描
  • 软掩码分区：三个子空间用软 mask 加权后分别做 PCA，避免 body/head/hand 交界处断裂
  • 镜像数据：扫描镜像后训练 → 把伪不对称压到两个特定成分并移除
  • 总身份空间 = 45 成分（20 body + 20 head + 5 hand）

4. Pose Correctives（姿态校正）

这是 MHR 相比 SMPL 的核心改进之一。pose corrective Bᵖ(θ, P) 接收 6D 关节角，输出顶点偏移。设计哲学：稀疏 + 非线性。

两阶段分解

  • 局部非线性：每个关节 j + 邻居 n(j) 输入轻量 MLP → c 维 embedding
  • 稀疏线性：embedding 乘权重矩阵 P_j → 顶点偏移，再用 ReLU 激活的 mask A_j 限制影响范围

稀疏 mask 初始化

  • 顶点 i 对关节 j 的 mask 初始化为 (1 - d(i,j)) · 𝟙[i ∈ seg(j)]
  • d(i,j) = 顶点 i 到关节 j 环的归一化 geodesic 距离
  • 加 L1 正则 → 训练后 corrective 集中在关节附近
对比 SMPL-X：SMPL-X 用稠密 pose corrective（所有关节→所有顶点），导致远距离相关。MHR 用局部 MLP + geodesic 稀疏 mask，既保留非线性表达力，又限制影响范围。这是 STAR（稀疏线性）+ GHUM（稠密非线性）的融合。

数字人模型的“前世今生”

在 计算机图形学 领域，参数化人体模型扮演着核心角色。像我们熟知的 SMPL 、SMPL-X等模型，它们能用一组紧凑的参数（比如体型和姿态）来生成一个完整的三维人体网格。这项技术是虚拟试衣、 动作捕捉 和虚拟形象创建等应用的基石。

然而，经典的模型也存在一些固有的局限性。例如，在SMPL这类模型中，人体的骨骼关节位置是通过表面网格顶点加权计算得出的。这种设计导致了骨骼和身体外形（ 软组织 ）的“纠缠”，使得我们很难独立地去调整骨骼长度（比如让一个角色变高，但不变胖）或精确地塑造体型。这对于追求细节的 艺术家 和开发者来说，无疑是一个痛点。

为了解决这个问题， ATLAS 模型率先提出了解耦骨骼与外形的思想，允许对骨骼和表面进行 独立控制 。MHR正是在这一思想的基础上，进一步融合了 Momentum库 的灵活性和现代化的绑定系统，旨在打造一个表现力更强、更符合解剖学原理的全新模型。

MHR模型的核心创新

MHR模型的 设计哲学 是“解耦”与“精控”。它将人体分为几个可以独立控制的部分，并对姿态引起的变化进行了更精细的建模。其核心可以概括为以下几点：

骨骼、体型和姿态的完全解耦

MHR的第一个亮点，就是它彻底分离了 骨骼结构 （Skeletal Structure）、身份体型（Identity Shape）和姿态（Pose）。

  • 独立的 骨骼系统 ：MHR的骨骼系统基于Momentum库构建，拥有127个关节。与以往模型不同，骨骼的长度、位置等属性可以被直接、独立地调整，而不会意外地影响到身体的胖瘦。这为创建不同身高、臂展和腿长的角色提供了极大的便利。论文中的图示非常直观地展示了改变单一骨骼参数的效果，例如拉长手臂或大腿，而身体其他部分保持不变。
图3 骨骼、体型和姿态的完全解耦
  • 分区的身份空间 (Partitioned Identity Space) ：为了更精细地控制体型，MHR将身份体型 空间划分 为了三个独立的部分： 身体、头部和手部 。这意味着你可以使用不同的参数集分别调整这三个区域的形状，比如单独改变一个人的脸型，而身体和手保持不变。这种设计不仅让艺术家的创作更自由，也使得模型可以利用来自不同大型扫描数据集的优势，分别针对身体、头部和手部进行学习，从而提升各部分的细节和保真度。
图4 骨骼、体型和姿态的完全解耦
  • 丰富的表情系统 ：MHR还包含一个由艺术家雕刻的、基于面部动作编码系统（ FACS ）的表情空间。这个系统包含了72个 语义化 的表情，比如抬眉、微笑等，它们是稀疏且明确的，使得表情控制更加直观和精准。
图5 骨骼、体型和姿态的完全解耦

创新的稀疏非线性姿态校正

当人体做出大幅度动作时（比如弯曲手肘或膝盖），皮肤和肌肉会产生复杂的变形，这被称为“软组织变形”。传统的线性混合蒙皮（LBS）技术很难完美模拟这种效果，经常会导致“糖纸包裹”等不自然现象。因此，需要额外的“姿态校正”来修正。

SMPL-X等模型虽然有姿态校正，但其校正量是全局性的，一个关节的运动可能会影响到全身的顶点，这在物理上是不准确的。

MHR在这里提出了一个非常巧妙的方案： 稀疏非线性姿态校正 (Sparse, Non-Linear Pose Correctives) 。它将校正过程分解为两步：

  • 局部非线性编码 ：首先，一个轻量级的多层感知机（MLP）网络会处理每个关节及其相邻关节的姿态信息，生成一个编码了局部姿态变化的特征。这个过程是 非线性 的，能够捕捉到更复杂的变形关系。
  • 稀疏线性应用 ：然后，该特征会通过一个线性层，将变形应用到 网格顶点 上。关键在于，这个应用过程是 稀疏 的。通过一种基于 测地线 距离的初始化和L1正则化，模型能学习到每个关节的运动只影响其周围的一小片区域。

如下图所示，SMPL-X的姿态校正（第一行）影响范围很广，而MHR的校正（第三行）在训练后变得非常稀疏和局部化，更符合真实的肌肉运动原理。

图7 创新的稀疏非线性姿态校正

这种设计结合了 非线性模型 的表现力和 稀疏模型 的局部性与效率，是MHR在技术上的一个重大突破。

实验效果如何？

说了这么多技术细节，MHR的实际表现究竟怎么样呢？论文在3DBodyTex这个公开数据集上，将MHR与SMPL和SMPL-X进行了详细的比较。

定量分析

在模型拟合3D扫描数据的任务上，研究人员评估了模型表面与真实扫描数据点之间的平均距离（即顶点到表面的误差）。结果显示，MHR在不同数量的拟合参数下，其 拟合误差 均显著低于SMPL和SMPL-X 。这意味着MHR能够用更少的参数更准确地表达真实的人体形状。

图8 定量分析

定性分析

定性结果更加直观。从下图的比较中我们可以看到，无论是从模型与扫描的重叠度，还是从误差热力图来看，MHR（最右列）的拟合效果都远超前两者。特别是在关节处，如肩膀、肘部和膝盖，SMPL和SMPL-X的拟合偏差较大，而MHR则能非常贴合地重建出身体轮廓，尤其是在一些极端姿态下，优势更为明显。

图9 定性分析

总结与展望

总的来说，MHR通过将骨骼与体型解耦、引入分区的身份空间以及设计巧妙的稀疏非线性姿态校正系统，成功地创建了一个在表现力、准确性和艺术家友好性方面都超越以往工作的参数化 人体模型 。

这项工作不仅为AR/VR中的虚拟化身、电影和游戏中的角色动画提供了更强大的工具，也为 计算机视觉 领域中基于模型的3D人体姿态和形状估计等研究铺平了道路。虽然模型还有一些待完善之处，比如集成眼球和 口腔系统 ，但MHR无疑为 数字人技术 的未来指明了一个清晰而令人兴奋的方向。

⭐ 核心创新点

创新 1：解耦骨架/形状 + 127 关节 — 骨架独立参数化，不从 mesh 回归，形状/骨架可独立控制。68 个骨架变换参数定义肢体长度等固定属性。
创新 2：稀疏非线性 pose corrective — 局部 MLP + geodesic 稀疏 mask，融合 STAR（稀疏线性）与 GHUM（稠密非线性）的优势，避免远距离相关。
创新 3：FACs 语义表情 — 72 个艺术家雕塑表情，兼容艺术家工作流，消除数据驱动表情的残余 pose 变化。
创新 4：分区身份空间 — body/head/hand 三个子空间分别 PCA，用软 mask 平滑过渡，各部位可用专用高质量数据集。
创新 5：工业级工程化 — 6 级 LoD、Momentum 库 (C++/Python)、FBX/GLTF 导出、工业友好许可，专为 AR/VR 与图形管线设计。

🧠 个人分析

  • SMPL 的正式继承者：SMPL 自 2015 年统治了 10 年，但骨架/形状耦合是设计债。MHR 用 ATLAS 的解耦范式 + 工业级工程化，是 Meta 给行业的正式升级方案。47 位作者体现了这是组织级投入，不是小团队研究。
  • FACs vs FLAME 的取舍是关键：数据驱动表情（FLAME）理论上更细，但残余 pose 变化 + 不兼容艺术家是工程硬伤。MHR 选 FACs 是务实 —— 牺牲理论极致换工程落地。这也意味着 MHR 更适合生产管线而非学术 SOTA 刷榜。
  • 稀疏非线性 pose corrective 是技术亮点：STAR 太稀疏（线性），GHUM 太稠密（非线性耦合）。MHR 用"局部 MLP + geodesic mask"走中间路线，既有表达力又限制相关，是正确的工程折中。
  • 分区身份空间是好设计：body/head/hand 各自用专用高质量数据集，软 mask 平滑过渡。这比 SMPL 的统一 PCA 更灵活，也解决了全身扫描中手/脸质量不足的问题。
  • 工业友好许可是杀手锏：SMPL 的"研究用"许可限制了工业应用。MHR 明确"免费实验"许可 + FBX/GLTF + Momentum 库，降低工业采用门槛。这可能比技术优势本身更重要。
  • 局限与风险：(1) 还很新（2025.11），社区工具链/预训练不如 SMPL 成熟；(2) 无显式眼球/口腔（SMPL-X 有）；(3) 47 作者说明这是组织工程产物，学术可复现性可能受限；(4) 3DBodyTex 评估范围有限，野外泛化未充分验证。

🎯 结论

  • SMPL 的正式升级版，工业级参数化人体模型
    • 解耦骨架/形状 + 127 关节 + 稀疏非线性 pose corrective + FACs 表情
    • 3DBodyTex 拟合误差低于 SMPL/SMPL-X
    • 6 级 LoD + Momentum 库 + FBX/GLTF + 工业友好许可
    • 开源，已在 F3G-Avatar 等 3DGS 数字人工作中被采用
  • ⚠️ 局限：尚新、无显式眼球/口腔、社区生态待成熟
