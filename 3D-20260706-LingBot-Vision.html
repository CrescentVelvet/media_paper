1论文概要与核心贡献

一句话概括:主流自监督视觉基座(DINOv2/DINOv3)的 patch 特征擅长「语义分组」(把同一物体的 patch 聚到一起),但在两个区域的交界处——也就是物体的边缘——表达最弱,因为语义码本根本不编码几何。LingBot-Vision 的答案是把「边界」从「需要预测的输出」提升为「组织特征学习的信号」:先用一套纯几何的 boundary field 参数化把线段编码成稠密场 $a(p)=(d_p,\theta_p,\phi^1_p,\phi^2_p)$,再把「边界 token」强制塞进掩码集 $\mathcal{M}^+=\mathcal{M}\cup\mathcal{B}$,逼模型必须重建这些结构。结果是 patch 特征在不牺牲语义的前提下带上了显式的几何结构。

核心贡献一句话:把「边界」从分割/边缘检测这类下游任务的预测目标,改写成预训练阶段的自监督组织信号。论文引言的原话点破了这一点:"boundaries and shape discontinuities are not merely outputs to be predicted, but fundamental organizing signals..."。这是对「自监督学不到几何」这个长期判断的直接反驳——学不到不是 SSL 目标本身不行,是没人把边界放进目标里。

三个宣称的贡献(论文 §1)

  1. boundary field 的几何重参数化:把图像边界建模为线段,再把稀疏线段「升维」成稠密场——每个靠近线段的像素存它到线段的距离与三个定位角度 $(d,\theta,\phi^1,\phi^2)$,且刻意冗余到「支撑区域内任一像素都足以重建整条线段」(§3.3,Figure 4)。
  2. boundary token 的在线发现管线:教师自身在线预测稠密 boundary field → 与一个冻结的单块 ViT 定位的稀疏角点配对 → 投票聚合解码出线段候选 → a-contrario 校验丢弃无支撑候选 → 幸存者重渲染成干净的 target field(§3.4,Figure 5)。全程无人工标注、无外部检测器。
  3. masked boundary modeling:把边界 token 强制并入随机掩码集 $\mathcal{M}^+=\mathcal{M}\cup\mathcal{B}$,让这些「结构上最关键」的 token 成为 student 必须重建的对象(§3.5,Figure 2)。
为什么这篇值得与 DINOv3 笔记 对照着读:两篇笔记是同一场「自监督如何学几何」对话的两种答案。DINOv3 承认 patch 级一致性会随训练退化,用 Gram anchoring 在训练后期事后修复;LingBot-Vision 则选择在事前改造 patch 级目标本身。两者的结论也互补:DINOv3 在 ADE20k 语义分割上更强(55.9 vs 53.5),LingBot-Vision 在 NYUv2 相对深度上反超(0.296 vs 0.309)且参数少 7 倍。这个互补关系正是「按任务选基座」的直接依据,详见 §14。

2研究背景与动机:语义码本里的几何盲区

论文对「视觉智能」的重新定义

论文 §1 开篇给出一段纲领性表述:"Visual intelligence is not only about recognizing what is in an image, but also about recovering the dense spatial structure that makes the physical world measurable, navigable, and actionable."——这句话把「可测量、可导航、可操作」作为视觉智能的落地标准,而这三个词恰好都是机器人学的语言。这解释了这篇技术报告为什么出自一家机器人公司(蚂蚁灵波 Robbyant):它的目标不是刷 ImageNet,而是给下游的操作(manipulation)与深度补全提供一个带几何感知的视觉基座。

失败模式:语义边界处的表示最弱

论文 §3.2 给出关键论证,这也是整套方法的事実基础:

"A semantic codeword encodes no explicit geometry and is weakest where two or more regions meet, so standard reconstruction under-supervises exactly the boundary tokens we force into the mask; the categorical geometric target supplies the missing signal."

失败模式:边界处的「欠监督」

以 iBOT 这类 latent 重建目标为例:它把 patch 特征投进一个语义码本(codebook),让 student 重建被掩码 token 的码本索引。问题在于码本索引是语义的——同一只狗的背部 patch 和边缘 patch,码本都可能归到同一类。于是恰好是两个物体交界处的 patch 最难学,而随机掩码又很少命中这些位置。

作者的归因:边界信息被码本「抹平」

码本的条目是有限的(Table 2 里 DINOv3 的 iBOT prototype 也只有 96k),它不可能为「从猫过渡到背景」这种局部几何过渡留一个码字。结果就是边界 token 的信号被平均掉,模型学到的是「整块区域的语义」而非「区域的形状」。

与 DINOv3「稠密特征退化」的关系

这是两篇论文同一个病灶的两种诊断。
  • DINOv3 的诊断:patch 与 CLS 的余弦相似度随训练升高 → 特征局部性丧失 → 稠密任务掉点(DINOv3 §2)。药方是 Gram anchoring——用早期 checkpoint 的相关性结构当锚。
  • LingBot-Vision 的诊断:随机掩码系统性避开边界 token,且语义码本不含几何 → 边界处的表示先天薄弱。药方是 masked boundary modeling——把边界 token 强制塞进掩码,并配上显式几何目标。
两者的区别在于「事后修」还是「事前改」。DINOv3 的做法不改变预训练目标,只在后期加一个约束项;LingBot-Vision 的做法直接改预训练目标的内容(掩码分布 + 监督信号)。Gram 的净收益约 +5.4 mIoU(ADE20k),masked boundary modeling 的净收益约 +3.0 δ₁(NYUv2)——数量级相当,但作用点不同。

为什么是「线段」而不是「边缘图」

论文 §3.3 专门论证了这个问题:"An edge map... marks photometric discontinuity pixel by pixel, may seem the more general choice. The trouble is that edge pixels can hardly be validated"——边缘图逐像素标注光度不连续,但无法做校验(每个边缘像素都是一个孤立事件,没有整体结构可以检验)。线段则不同:它有一个整体的、可被 a-contrario 判据检验的几何假设。这个「可校验性」是整条边界发现管线的支点。

边界是自然涌现的(Finding 1)

图2(对应论文 Figure 3 的两行样例)给定角点,随机 boundary field 也能解码出线段;若方向通道再被 level-line 引导,线段变得连贯。论文对 Finding 1 的表述:"Boundaries emerge from corner points. For two images, we draw five random boundary fields per image, fix the corner points, and decode line segments from each draw. In the bottom two rows, every field channel is sampled uniformly at random: the decoded segments still anchor on the corner points, but stay short and fragmented. In the top two rows, only the direction channel is guided by a parameter-free estimate of the image's level-line orientation, rendered into a boundary field, and every draw yields coherent, near-identical segments. In either case the fields carry no learned information."——这张图是「边界目标可以从零启动」的原理证明:只要角点可靠,即使是完全随机的场也能解出锚定在角点上的线段。
核心洞察(insight):boundary field 之所以能让「从零启动」成为可能,靠的是它的冗余性——支撑区域内任一像素都足以重建整条线段(§3.3),所以即使 field 早期是噪声,投票聚合也能从大量弱信号里「聚」出相干候选。这个「冗余 → 投票 → 校验」的三件套,本质上是把线段检测从「学习问题」退化成「统计检验问题」,从而摆脱了对预训练权重的依赖。这也是它与「直接预测边缘图」最根本的区别。

4模块一:boundary field 的重参数化

一句话定位

把「稀疏的线段集合」升维成「稠密的像素级场」,而且故意做得高度冗余:支撑区域内任何一个像素,都携带足以重建整条线段的全部信息。这个冗余是后面「投票聚合」「在线启动」两个步骤能成立的前提。

网络结构 / 参数化

论文 §3.3 的核心设计。把图像边界建模为直线段(曲线边界 = 短线段链),然后对每个靠近线段的像素 $p$,存它到线段的距离和三个定位角:

$$a(p)\;=\;\big(d_p,\;\theta_p,\;\phi^{1}_p,\;\phi^{2}_p\big)$$ (式 5)boundary field 四元组,论文式 (7)
  • $d_p$:像素 $p$ 到其所属线段 $\ell$ 的距离;
  • $\theta_p$:线段 $\ell$ 的方向角(共享同一朝向颜色的平行线段见图 3b 左二);
  • $\phi^1_p,\phi^2_p$:从 $p$ 看向线段两个端点的方位角——用两个端点角把「这条线段在哪、多长」确定下来。
图3(对应论文 Figure 4 的 (b)(c)(d) 三子图)boundary field 一览。左一($d$):距离通道;左二($\theta$):方向通道,平行线段共享同一朝向颜色;右一(支撑区域):编码刻意冗余,任一支撑像素足以重建整条线段;右二(投票聚合):橙色细线是单个像素的噪声投票,黑色粗线是聚合后的线段。论文图注原文:"The boundary field lifts the sparse segments into a dense map: every pixel near a segment stores its distance d to the segment and three angles... The encoding is deliberately redundant: any single pixel p in a segment's support region carries enough information to reconstruct the entire segment. Conversely, segments are decoded by letting all support pixels vote and aggregating the votes..."

数学形式化:类别化 + 软标签

四个通道各自被离散化成 $K=32$ 个 bin,把回归问题变成分类问题(论文称 "categorical reparameterization")。第 $c$ 个通道的软标签是围绕真值 bin 的高斯:

$$\bar{y}^{c}_{k}(p)\;\propto\;\exp\!\Big(-\frac{\delta^{c}\big(k,\,a^{c}(p)\big)^{2}}{\tau_{\ell}}\Big)$$ (式 6)第 c 通道的软标签,论文式 (8);$\delta^c$ 为环形距离,$\tau_\ell$ 为窄温度

监督信号是对四个通道分别求交叉熵再相加:

$$\mathcal{L}_{\mathrm{bnd}}\;=\;-\frac{1}{|\mathcal{B}|}\sum_{p\in\mathcal{B}}\sum_{c}\;\bar{y}^{c}(p)^{\top}\log \hat{y}^{c}(p)$$ (式 7)boundary 损失,论文式 (9);只在 boundary token 上求和
为什么「类别化 + 软标签」是这个模块的关键(而不是可选项):
  1. 环形距离 $\delta^c$:方向角是周期性的($\theta$ 与 $\theta+\pi$ 是同一条线),用普通欧氏距离会在 $0$ 与 $\pi$ 边界处出错;环形距离把这个周期结构编码进损失。
  2. 窄温度 $\tau_\ell$:让梯度集中在真值 bin 附近的几个 bin 上,而不是均匀摊到全部 32 个。论文 §4.3 称这相当于「把软标签做得很窄」。
  3. 离散化让「多解」合法:同一条线段的两个方向($\theta$ 与 $\theta+\pi$)在 32-bin 的周期码本里是两个都合法的类别,不像回归那样被迫二选一。

前向流程

  1. 教师 backbone 输出 dense patch 特征 → 一个三层 per-token MLP(head dim 512,输出步长 $s=2$)→ 每 token 预测 $4\times K=128$ 个 logit。
  2. 预测被重排成 boundary field 的四个通道图。
  3. 只在 $\mathcal{B}$ 内的 token 上算 $\mathcal{L}_{\mathrm{bnd}}$(非边界位置填均匀随机标签,避免「全背景」平凡解)。
「支撑区域」的设计有一个值得注意的物理含义:论文把支撑区域的宽度固定为 33 像素(附录 A,原文 "fixed-width rectangles of 33 px"),这是一个比 patch 尺寸(16 px)更大的邻域。也就是说,一条线段的影响范围会跨越约 2 个 patch——这使得「边界 token」天然是一个跨 patch 的协同概念,而不是单 patch 的属性。这是它能修正「patch 级一致性」的深层原因:它强迫相邻 patch 在边界处达成一致。

5模块二:边界目标的在线发现管线

一句话定位

这是整套方法里工程上最精巧的部分:监督信号不是从外部检测器来的,而是从教师自身的噪声预测里「长」出来的。整条管线分四步,其中第三步(投票聚合)和第四步(a-contrario 校验)是把「噪声场」变成「干净目标」的关键。

四步流程(§3.4)

  1. 教师预测:教师对当前 batch 预测稠密 boundary field(早期是噪声,见 §2 Finding 1 的证明)。
  2. 角点配对:用一个冻结的单块 ViT定位稀疏角点,与 field 配对,得到「角点锚定的线段碎片」。冻结是关键词——它提供不随训练漂移的种子。
  3. 投票聚合:支撑区域内的所有像素对「线段在哪」投票,聚合出候选线段(图 3d 的橙色细线 → 黑色粗线)。
  4. a-contrario 校验:对每个候选线段做「无意义的偶然对齐概率」检验,丢弃未通过者,幸存者重渲染成干净的 target field。
图4(对应论文 Figure 5 的 (b)(c) 两子图)在线生成边界目标的中间步骤。左:教师早期的噪声 boundary field 加上角点种子(绿色点);右:投票聚合后解码出的线段候选——既有真边界,也有伪候选(如脸部对角线、背景弦)。论文图注原文:"Even when the teacher's boundary field is noisy, as it is early in training, the holistic parameterization lets the many weak per-pixel votes in a segment's support region aggregate into coherent candidate segments anchored at corner points, together with spurious candidates such as face diagonals and background chords."注意:此时还没有做任何过滤——伪候选是投票聚合的必然副产物,过滤交给下一步的 a-contrario 校验。

a-contrario 校验的数学形式化

校验的思想是「假设检验」:如果一个线段候选只是「噪声的偶然对齐」,它应该能通过一个极低阈值的检验被淘汰。具体实现用 NFA(Number of False Alarms):

$$\mathrm{NFA}(\ell)\;=\;N_t\cdot\Pr\big[\text{在 }H_0\text{ 下,随机场里出现一条与 }\ell\text{ 一样好的对齐}\big]$$ (式 8)NFA 定义;$\epsilon=1$ 时拒绝所有 NFA>1 的候选(附录 A)
  • 检验统计量:线段上「方向对齐」的像素数,对齐容差 $\pi/16$(比经典 LSD 的 $\pi/8$ 更严)。
  • 零假设 $H_0$:像素方向独立同分布,因此一条线段上对齐像素数服从二项分布,概率 $p=1/16$。
  • 试验数 $N_t=(HW)^{5/2}$(附录 A)。
  • 预过滤:「对齐像素密度 < 0.5」的候选直接拒绝,不进 NFA 计算。

6模块三:masked boundary modeling

一句话定位

这是把「boundary field」接到「自监督预训练」上的接口:把边界 token 强制并入随机掩码集,让这些结构上最关键的位置成为 student 必须重建的对象。整个模块只有一个新符号 $\mathcal{B}$,但它的效果是把预训练的「注意力」从「整块区域」重新分配到「区域交界处」。

数学形式化

先定义边界 token——被任何一条预测边界穿过的 patch:

$$\mathcal{B}\;=\;\Big\{\,i\in\{1,\dots,N\}\;:\;\text{a predicted boundary intersects patch}(i)\,\Big\}$$ (式 9)boundary token 集合,论文式 (5)

再把它并入随机掩码集:

$$\mathcal{M}^{+}\;=\;\mathcal{M}\;\cup\;\mathcal{B}$$ (式 10)掩码集取并集,论文式 (6)

最终的总目标是在 DINOv2 的基座上加上边界项:

$$\mathcal{L}\;=\;\mathcal{L}_{\mathrm{DINO}}+\lambda_i\,\mathcal{L}_{\mathrm{iBOT}}+\lambda_b\,\mathcal{L}_{\mathrm{bnd}}+\lambda_k\,\mathcal{L}_{\mathrm{KoLeo}},\qquad \lambda_i=\lambda_b=1,\ \lambda_k=0.1$$ (式 11)总损失,论文式 (10)
图6(对应论文 Figure 2 全部四子图)玩具场景上的边界中心掩码建模。(a) 输入图像与 patch 网格;(b) 随机掩码——大量被掩的是平坦区域,可从上下文恢复,而承载边界的 patch 大多逃过掩码;(c) 边界强制掩码(本文)——把每个承载边界的 patch 都加入随机掩码,让「场景的结构」成为 student 必须重建的对象;(d) 监督边界 token 的 boundary field,编码为逐像素的离散距离/方向分布。论文图注原文:"Boundary-centric masked modeling on a toy scene... Random masking is content-agnostic: most hidden patches are flat and recoverable from context, while the boundary-bearing patches largely escape the mask. Boundary-forcing masking adds every boundary-bearing patch to the random mask, so the structure of the scene is exactly what the student must reconstruct."——这四张子图就是 $\mathcal{M}^+=\mathcal{M}\cup\mathcal{B}$ 的直观化。

为什么「强制掩码边界」有效(论文的机制解释)

论文 §3.2 给出因果链:

  1. 随机掩码是内容无关的,所以它系统性地避开稀疏的边界位置;
  2. 语义码本又不编码几何,所以边界位置的重建误差一直很高;
  3. 这两个因素叠加,导致边界 token 在预训练里被双重欠监督;
  4. 把它们强制塞进掩码,等于把监督预算重新分配到最需要的位置。

这与 DINOv3 的 Gram anchoring 形成有趣的镜像:Gram 修的是「patch 间相关性的相对结构」,masked boundary modeling 修的是「哪些 patch 该被监督的空间分布」。两者都是在给 patch 级目标「补课」,只是一个补在损失项上,一个补在掩码分布上。

两个关键的稳定化设计(§4.3)

  • 非边界位置填均匀随机标签:而不是一个固定的「背景」值。论文原文:"teacher targets at non-boundary positions are filled with uniform random labels rather than a constant background value, which removes the trivial all-background solution"——这是防止网络坍缩到「全预测背景」的平凡解的关键一步。
  • teacher 侧 centering 全程开:保持与 DINO/iBOT 相同的中心化处理。

对比结论(4 条)

  1. 「几何目标」是一个独立的增益轴。同样的 DINO+iBOT 基座,加 Gram(DINOv3)或加 masked boundary modeling(LingBot-Vision)都能涨;但两者作用点不同——Gram 主要救「长训练后的语义分割」(ADE20k +5.4),boundary modeling 主要救「深度与空间对应」(NYUv2 −8.5% 到 −20%)。两者在 ADE20k 与 NYUv2 上的胜负是互补的,不存在一个「全面更好」的方法。
  2. LingBot-Vision 的效率优势非常硬。在 NYUv2 上以 1.1B 参数赢过 6.7B 的 DINOv3(0.296 vs 0.309);以 0.3B 蒸馏档打平 7B 教师(0.310 vs 0.309)。如果把「达到同等深度指标所需的参数量」作为横轴,LingBot-Vision 是表里最省的。
  3. 「蒸馏自监督」这条中间路线(AM-RADIO)在两个几何指标上都输给原生方法。AM-RADIO 的 NYUv2 是 0.340,既不如 LingBot-Vision(0.296)也不如 DINOv3(0.309);其 ADE20k 53.0 也只是居中。这印证了「从监督模型蒸出来的几何」不如「自监督原生学到的几何」。
  4. 「视频时序」能提供部分几何,但不彻底。V-JEPA 2.1(视频预训练)在 NYUv2 上做到 0.307,优于 DINOv2(0.372)——说明时序一致性本身就是一种几何信号;但仍不如显式的 boundary 目标(0.296)。这是一个值得注意的光谱:无几何(DINOv2 0.372)→ 隐式几何(V-JEPA 0.307)→ 事后几何约束(DINOv3 0.309)→ 显式几何目标(LingBot-Vision 0.296)。
与 DINOv3 笔记对照时的一个公平性提醒:两篇论文的 NYUv2 数字虽然都是「冻结线性探测」,但并不来自同一份评测代码——LingBot-Vision 自行实现了一套「token 对齐」协议(§5 的 "Evaluation protocol"),DINOv3 用的是它自己的 Table 3 协议。两者都把输入对齐到 1024 个 patch token,方向一致,但跨论文的 0.296 vs 0.309 这个 0.013 的差距,处在「评测协议差异」的噪声量级之内。【待核实】要下「LingBot-Vision 在深度上稳赢 DINOv3」的结论,需要在同一份代码、同一份数据上复跑——这也是本库把它列为「值得在本地 vggt_human pipeline 上做的对照实验」的原因(见 §16)。

前馈式高斯重建的衔接

15.1 结论先行:这两个基座怎么选

一句话选型原则:要语义分割 → 选 DINOv3;要几何 / 深度 / 边界敏感 → 选 LingBot-Vision。两者不是「谁取代谁」,而是增益轴正交——DINOv3 的 Gram anchoring 主要救「长训练后的语义分割与全局稳定性」,LingBot-Vision 的 masked boundary modeling 主要救「深度估计与空间对应的边界锐度」。对本库最关心的前馈式高斯重建而言,瓶颈恰恰落在后者:位姿回归、深度初始化、distractor 抑制都依赖空间对应与边界几何,而非语义标签。

15.2 一个对前馈重建特别重要的证据:镜面与玻璃

前馈式重建(3DGS / VGGT 系)有一个公认的经典失败区:镜面、玻璃、反光地板——这些表面对多视图几何是灾难(深度传感器在这里直接缺测,MVS 匹配在这里产生错误对应),而恰是室内场景的高频元素。LingBot-Vision 的下游联动 LingBot-Depth 2.0 给出的证据,直接命中这个失败区:

15.4 给 vggt_human 的三条可执行建议

  1. 做一个 2×2 对照实验( backbone × 下游头)。在当前 COLMAP→3DGS 链路上,把「前馈编码器」这个变量单独抽出来:{DINOv3 ViT-L, LingBot-Vision ViT-L} × {当前深度 / 位姿头}。重点看边界密集场景(发丝、手指、衣褶、镜面)的重建失败率,而不是只看全局 PSNR——全局指标会掩盖边界增益。
  2. 把「边界敏感子任务」作为独立的评测切片。vggt_human 的人脸重建里,发际线、眉形、唇线、下颌轮廓都是「边界决定观感」的区域。建议单独评这些区域的深度 / 法线误差,LingBot-Vision 的 boundary token 机制理论上应在此处体现优势。
  3. 关注「boundary token 是否被前馈头正确消费」这条副线。LingBot-Vision 把边界 token 显式并进掩码集 $\mathcal{M}^+$,意味着它的 patch 特征在边界处承载了更多结构信息。接入前馈重建头时,值得验证这些 boundary token 是否被注意力正确加权——这决定了增益能不能传导到最终的高斯参数。

15.5 两个必须说明的落差

  1. 语义分割上 LingBot-Vision 确实落后。在 ADE20k 上它比 DINOv3 差约 2 个 mIoU(见 §13 消融)。如果你的前馈重建管线同时需要强语义先验(例如依赖语义分割做场景分解),那 DINOv3 仍是更稳的选择——不要用 LBV 替代 DINOv3 去做语义主导的任务。
  2. 跨视图对应(NAVI 类)未被验证。LingBot-Vision 论文的全部几何评测都是单视图深度 / 分割 / 跟踪,【待核实】没有在 NAVI / 多视图对应这类「前馈重建真正依赖」的任务上跑过。也就是说,「boundary-aware → 跨视图匹配更准」这一步因果链在论文里是缺失的,需要在本地 pipeline 上自己补验证。

16.2 四个具体短板

① 无显式跨视图机制

整条 pipeline 是单视图自监督,没有任何跨视图一致性约束(对比 VGGT 的多视图 token 交互)。这解释了 15.5 的落差②——它学的是「单图里边界长什么样」,不是「同一边界在另一张图里长什么样」。对前馈重建,这是最需要补的一块。

② 高分辨率适配不如 DINOv3 激进

DINOv3 专门做了 10k 迭代的高分辨率微调 + RoPE-box jittering($s\in[0.5,2]$)来稳住大图外推;LingBot-Vision 论文未给出同等力度的方案。高分辨率重建(2K+)是它的潜在弱项。

③ 蒸馏家族档位少

DINOv3 提供 S21M/S+29M/B86M/L300M/H+840M + ConvNeXt 四档的完整蒸馏谱系;LingBot-Vision 只蒸了 L/B/S 三档,且跳过了 Gram 阶段。要部署到边缘端,可选档位明显更少。

④ 「7× vs 6.1×」的数字表述需复核

论文摘要说 LingBot-Vision「7× fewer parameters than DINOv3」,但按精确参数量(1.1B vs 6.716B)算是 6.1×。这与本库 LiON-LoRA 笔记发现的「相对改进百分比错位」是同类问题——论文把表格数字二次加工成结论句时最易出错。引用时一律用复算值 6.1×。

对本库最有价值的一个改进方向(可作为本地研究点):把 LingBot-Vision 的 boundary field 监督移植到多视图设置——用同一场景的两个视图,强制「同一条物理边界在两个视图里被同一组 boundary token 编码」。这直接补上短板①,且与本库 vggt_human 的「跨视图人脸对应」需求完全对齐。论文本身的单视图框架 + 附录 A 的 a-contrario 管线为这件事提供了全部零件,缺的只是跨视图配对的监督信号。

17.2 三条演进线索

线索一:从「语义不变性」到「几何保持」

早期 SSL(DINO / iBOT)追求对增强不变的语义表示;DINOv3 用 Gram 在长训练后约束语义不要漂移;LingBot-Vision 更进一步,直接把几何(边界)当作学习目标本身。演进的方向是:几何从「被牺牲」→「被约束」→「被主动学」。

线索二:监督信号的「自衍生」

LingBot-Vision 最精巧的一步是监督信号不来自外部标注或检测器,而是从教师自身的噪声预测里「长」出来(§5 四步管线)。这与 DINOv3 的 EMA teacher 一脉相承,但把「自蒸馏」推到了「自发现几何结构」的程度——用未训练好的模型自己造监督,再用它训练自己。

线索三:基座 → 垂直下游的直通

DINOv3 → 卫星高度图(WRI 合作);LingBot-Vision → LingBot-Depth 2.0。两篇都证明了「一个好的基座 + 一个垂直下游头」能直接产出 SOTA。对前馈重建的启示:与其从零训一个重建网络,不如选对基座 + 冻结特征 + 小头。

17.3 一句话定位

LingBot-Vision 是「把边界从预测目标改写为预训练组织信号」这条新路线的第一个完整验证。它与 DINOv3 不是替代关系,而是同一个问题(SSL 学不到几何)的两种解法——一个用事后约束救语义,一个用事前设计救几何。对前馈式高斯重建这类「几何敏感」的下游,LingBot-Vision 提供了一个参数效率极高(1.1B 打平 7B)、许可友好(Apache-2.0)的新基座选项;真正的差距在于它尚未在跨视图对应这个前馈重建的核心环节被验证——这正是本库 vggt_human pipeline 可以去补的实验空白。
