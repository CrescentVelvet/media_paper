PDF-GS:面向鲁棒 3D 高斯溅射的渐进式干扰过滤

1论文摘要

⚠️ 定位澄清:它做什么、不做什么

PDF-GS 并非实现"动态物体/动态场景的运动重建",而是针对包含动态干扰物(行人、移动物体、瞬态遮挡等)的静态场景,实现鲁棒的无干扰 3DGS 重建——它把画面中的动态内容视为破坏多视图一致性的"干扰物(distractor)",通过渐进式过滤机制逐步剔除,最终输出干净的静态场景 3D 高斯表示。

一句话:输入有干扰的图像,输出干净静态场景的 3DGS。

3D 高斯溅射(3DGS)已实现实时逼真渲染,但常规训练 pipeline 内禀假设输入图像间完全多视角一致——一旦出现破坏该假设的 distractor(行人、车辆、阴影、视角相关反光等 transient/view-dependent 内容),就会产生视觉伪影。

本文重新审视了 3DGS 一个被忽视的内禀属性:它对不一致信号有天然的抑制能力。基于这一观察,作者提出 PDF-GS(Progressive Distractor Filtering for Robust 3D Gaussian Splatting),通过多阶段渐进优化放大这种自过滤特性:

  1. 渐进过滤阶段(Progressive Filtering Phases):利用 discrepancy 线索逐步剔除 distractor;
  2. 重建阶段(Reconstruction Phase):从净化后的高斯表征恢复细粒度、视角一致的细节。

通过这种迭代精炼,PDF-GS 在多种数据集和真实挑战条件下稳定超越基线。方法轻量、无架构改动、无额外推理开销,可直接挂到任意 3DGS 框架上,达到新的 SOTA。

核心洞察

3DGS 训练本身就是个不一致信号过滤器——只需把它迭代放大,而非另起炉灶显式建模 distractor。

关键机制

DINOv3 patch 特征差异 → 渐进 mask → masked 监督 + 稀疏颜色更新 + 阶段间重 SfM 初始化。

工程价值

不引入新模块、不增加推理成本,4 个 phase 共 40K 迭代,wall-clock 时间与 30K 迭代的 RobustSplat 相当。

2研究背景与动机:3DGS 的自过滤特性

2.1 问题定义:distractor 为何伤害 3DGS

3DGS 用一组可学习 3D 高斯 $\mathcal{G}=\{(\mu_i,\Sigma_i,\alpha_i,c_i)\}$ 表示场景,通过可微光栅化最小化所有训练视角的渲染误差。其优化目标隐含一个强假设:所有输入图像观测的是同一静态场景。当输入含 distractor 时,它们只在少数视角出现、无法提供跨视角一致支持,优化器无法为其学到稳定高斯,反而以伪影(color bleeding、floater、ghosting)形式泄漏到新视角。

2.2 核心底层依据:3DGS 的自过滤特性

作者发现一个被忽视的现象:标准 3DGS 训练天然具备"自过滤"倾向。原因很直观——瞬态/动态物体只在少数视角出现,无法提供跨视角一致的监督信号,在优化过程中会逐渐被一致性压力"抹平":不透明度逐步降低、颜色向背景漂移,最终从渲染结果中模糊或消失。

直觉上,多视角监督会把所有视角"拉"向同一个一致解,distractor 缺乏跨视角支持,自然被挤出去。这意味着 3DGS 训练本身就是一个隐式的 distractor 过滤器。

图 1(动机):通过聚合多视角监督,3DGS 常使视角不一致的 distractor 消失或模糊。这一经验观察是 PDF-GS 整个方法论的出发点。
图 2(动机):由此可把 3DGS 训练本身重新解释为一个 distractor 过滤器,而非为 distractor 另建显式模型。

但单轮自过滤并不彻底

单次标准训练的自过滤无法完全消除 distractor 残余——残留的干扰信号会持续污染几何与外观,导致鬼影(ghosting)、颜色渗透(color bleeding)、floater 等伪影。Fig.1 显示 vanilla 3DGS 训练后仍留有痕迹。

★ PDF-GS 的核心思路

既然 3DGS 天然会过滤 distractor,只是单轮不够彻底——那就把"单次不彻底的自过滤"转化为"多轮可控制的渐进式精炼流程",通过 4 阶段迭代放大 3DGS 的天然抗干扰能力。每轮用上一轮更纯净的渲染重新定位 distractor,mask 越来越准,过滤越来越干净。

这是"化繁为简"的范式选择:不另起炉灶显式建模 distractor,而是把训练本身当 filter 并迭代放大。

3算法总体框架:4 阶段渐进 pipeline

一句话总览

PDF-GS 把一次 3DGS 训练拆成 3 轮渐进过滤阶段 + 1 轮重建阶段,共 4 个 phase。每 phase 跑 10K 迭代,合计 40K 步——与标准 3DGS 训练预算相当。无需修改 3DGS 核心架构,推理时零额外开销。

两个阶段分工明确:过滤阶段提纯场景结构(剔除干扰),重建阶段恢复精细画质(还原纹理)。

图 3(方法总览):Phase 1 无 mask 用结构损失得到粗糙一致的 Θ⁽¹⁾;Phase 2/3 基于 Θ⁽ᵏ⁻¹⁾ 渲染与 GT 的 DINOv3 差异生成 mask,masked 监督下重 SfM 初始化训练;distractor 逐 phase 消失;Phase 4 继承 Θ⁽³⁾,用最终 mask 恢复细粒度外观。

3.2 两大阶段分工的设计动机

渐进过滤阶段(Phase 1-3):逐层剥离干扰,提纯结构

核心目标:提纯场景结构,而非精细还原外观。每一轮都遵循「差异检测 → 生成掩码 → 重新初始化 → 带掩码训练」的闭环,逐步剔除不一致的动态干扰。每个 phase:(a) 用上一 phase 的 Θ⁽ᵏ⁻¹⁾ 渲染图与 GT 比较,生成 discrepancy map → mask;(b) 从 SfM 点重新初始化高斯 Θ⁽ᵏ⁾,在 masked 图像监督下训练。

为何重新 SfM 而非继承?防止色彩漂移和几何偏差跨 phase 累积(消融 Fig.7:无重初始化会出现持续伪影)。

重建阶段(Phase 4):恢复精细画质

核心目标:恢复高保真外观细节。经过 3 轮过滤,已得到几何稳定、基本无干扰的高斯,但为优先抗干扰牺牲了纹理/颜色的精细度。Phase 4 专门用于恢复纹理、阴影、颜色渐变等精细外观。

关键设计:(1) 不重新 SfM,直接继承 Θ⁽ᴷ⁻¹⁾——它已过 K-1 轮过滤,作初始化比 SfM 更可靠;(2) 把所有 1 阶以上球谐(SH)系数重置为零、active_sh_degree 归零,让外观从头学;(3) 用最终 mask M★防止 distractor 复活。

4Distractor 检测:语义级差异检测与 mask 生成

核心思路:用语义特征而非像素差值定位干扰

每一轮过滤开始时,用上一轮训练完成的高斯模型渲染所有训练视角,把渲染结果与真实输入图像对比,生成差异图。关键在于不直接使用像素 RGB 差值——而是通过 DINOv3 特征提取器计算特征空间的 L2 距离,得到语义级差异图。这种方式对光照、低层级颜色变化更鲁棒,能更精准识别"语义层面的动态干扰物体"。

差异值越高的区域,越大概率是跨视角不一致的 distractor(动态行人、移动车辆等)。

4.1 差异线索计算(式 1)

对训练视角 $v$、phase $k$,比较 GT 与上一 phase 的渲染:

$$ D_v^{(k-1)}(p) \;=\; \big\|\, F\!\left(I_v^{gt}\right)(p) \;-\; F\!\left(I_v^{r}(\Theta^{(k-1)})\right)(p) \,\big\|_2 $$ (式 1)

其中 $F(\cdot)$ 是语义特征提取器。论文默认用 DINOv3 ViT-B/16 的 patch token。选用语义特征而非低级指标(PSNR/SSIM)的理由:patch 级语义差异对光照、颜色等低级变化鲁棒,能抓住"语义级不一致"——静态区域即使光照变化也不会被判为 distractor。

递推逻辑:越往后越准

Θ⁽ᵏ⁻¹⁾ 在 phase 推进中越来越纯净,所以 $D_v^{(k-1)}$ 对真 distractor 的定位也越来越准——这是"渐进"能放大于"单次"的核心。

4.2 二值 mask 生成与膨胀(式 2-3)

根据差异图生成二值掩码,差异大于阈值的像素会被屏蔽、不参与损失计算:

$$ M_v^{(k-1)}(p) \;=\; \mathds{1}\!\left[\, D_v^{(k-1)}(p) \;\leq\; \tau_k \,\right] $$ (式 2)

注意符号方向:$D(p) \leq \tau_k$ 的像素保留(视为视角一致),$D(p) > \tau_k$ 的像素mask 掉(视为 distractor)。随后对 mask 膨胀 7 像素再应用,确保干扰物的边缘轮廓被完整覆盖,避免边缘残留信号污染训练。masked 图像:

$$ \tilde{I}_v^{gt,(k)} = M_v^{(k-1)} \odot I_v^{gt}, \qquad \tilde{I}_v^{r,(k)} = M_v^{(k-1)} \odot I_v^{r}(\Theta^{(k)}) $$ (式 3)

4.3 mask 在 phase 间的演化

论文不直接累加 mask:每个 phase $k$ 用 Θ⁽ᵏ⁻¹⁾重新计算 $D$ 与 $M$。但存在间接累积——Θ⁽ᵏ⁻¹⁾ 越纯,后续 phase 的 mask 越准(Fig.8 可视化)。最终重建阶段用 $M_v^\star$ = 来自 $k=K-1=3$ 的最终 mask。

图 4:渐进 distractor mask 精炼。每行从左到右:训练视角 → Phase 1 → 2 → 3 的 mask 演化,红 overlay = masked 像素。早期未 mask 的背景车辆在后期被正确识别。

5渐进过滤阶段:四机制逐层剥离动态干扰

过滤阶段 = 一个闭环 × 3 轮

过滤阶段的核心目标是提纯场景结构,而非精细还原外观。每一轮都遵循「差异检测 → 生成掩码 → 重新初始化 → 带掩码训练」的闭环,逐步剔除不一致的动态干扰。本节拆解为 4 个关键机制:

  1. 机制① 语义级差异检测(详见 §4)——定位 distractor;
  2. 机制② 渐进掩码:阈值逐层收紧——决定屏蔽多严;
  3. 机制③ 每轮重新初始化高斯——隔绝误差累积;
  4. 机制④ 专用训练策略(结构导向损失 + 稀疏颜色更新,详见 §6)——抑制过拟合干扰。

5.1 机制②:渐进掩码——阈值逐层收紧

论文 4.3.3 节明确:"we progressively decrease the threshold τ_k used in Eq. 2"。采用递减阈值策略:

早期 phase(保守,宽松)

τ_k 大,只把"差异非常明显"的极端 outlier 标为 distractor,避免误杀静态区域(此时 Θ 还不纯,$D$ 不可靠)。

后期 phase(严格,收紧)

τ_k 小,把之前容忍的"边缘 borderline"区域也排除。此时 Θ 已净化、$D$ 准确,可以放心用严格阈值。掩码精度随轮次持续提升。

消融验证:递减调度 vs 静态固定阈值,ΔPSNR = +0.26 dB。

★ 代码佐证:阈值方向的等价表述(避免误读)

论文用 L2 距离 $D$ + 阈值 $\tau_k$(keep if $D \leq \tau_k$),称"递减 τ_k"。而代码 train.py:25-32 用的是 余弦相似度 cos + 阈值 sim_thr(keep if cos >= sim_thr),README 默认 --sim_thr 0.6 0.7 0.8——递增。

这并不矛盾:对归一化特征,余弦相似度与 L2 距离单调反相关($\|x-y\|^2 = 2-2\cos$)。递增的相似度阈值 = 递减的等价距离阈值,两者都表达"渐进收紧过滤"。子代理初读时曾误判为矛盾,实为同一策略的两种等价数学表述。

5.2 机制③:每轮重新初始化高斯——隔绝误差累积

★ PDF-GS 最核心的机制之一

每进入新一轮过滤阶段,都不沿用前一轮的高斯参数,而是从原始 SfM 点云重新初始化一整套全新的高斯,再用当前轮的掩码图像从零开始训练。

该设计的核心作用是避免误差累积:如果持续优化同一组高斯,早期的颜色漂移、几何偏差会在多轮迭代中持续放大,形成顽固伪影;重新初始化相当于每次都在"更干净的监督数据"上重建几何结构,从根源上隔绝前序误差的传递,保证每一轮过滤都处于干净的几何起点。

策略filtering 阶段间reconstruction 阶段PSNRΔPSNR
默认(filtering 重 SfM、reconstruction 继承)重 SfM继承 Θ⁽ᴷ⁻¹⁾23.320

默认策略最优。"Never" 在 LPIPS 上反而最好(0.13)但 PSNR 大幅下降,说明色彩漂移让 LPIPS 略好但整体几何受损。

5.3 机制④预览:专用训练策略

为强化结构一致性、抑制模型过拟合干扰物,过滤阶段对标准 3DGS 损失做了两处关键修改(详见 §6):

  • 结构导向监督:第一轮过滤仅使用 SSIM 结构相似性损失,不使用 L1 像素损失。优先保证几何结构的跨视角一致性,避免模型过早拟合动态物体的颜色、纹理细节。
  • 稀疏颜色更新:高斯的颜色参数每 N 步才更新一次,几何与不透明度参数则每步正常更新。防止颜色参数被单视角的干扰信号带偏,维持多视角颜色一致性,稳定整体几何结构。

5.4 Phase 数量选择

消融(Fig.5):1→2 phases 提升最显著(单次 pass 不足以抑制 distractor);2→3 继续提升但幅度减小;3 phases 之后饱和。默认 K=4(3 个 filtering + 1 reconstruction),平衡质量与效率。

6机制④详解:各阶段损失与稀疏颜色更新

本节展开 §5 提到的"专用训练策略"。过滤阶段为强化结构一致性、抑制过拟合干扰,对标准 3DGS 损失做了两处关键修改:结构导向监督(仅 SSIM)与稀疏颜色更新。重建阶段则恢复标准损失、专注外观恢复。

6.1 Filtering Phase 1:纯结构损失(式 4 第一行)

$$ \mathcal{L}_{\text{filter}}^{(k=1)} \;=\; \sum_{v \in \mathcal{V}} \mathcal{L}_{\text{ssim}}\!\left(I_v^{r,(1)},\, I_v^{gt}\right) $$ (式 4, k=1)

仅 SSIM 损失,无 L1,无 mask。动机:SSIM 强调 patch 级几何一致性,对局部颜色变化/transient 不敏感,防止过早拟合 distractor。论文特别说明该结构损失被量级对齐到标准 3DGS 损失以稳定优化。

6.2 Filtering Phase 2/3:masked 3DGS 损失(式 4 第二行)

$$ \mathcal{L}_{\text{filter}}^{(k)} \;=\; \sum_{v \in \mathcal{V}} \mathcal{L}_{\text{3DGS}}\!\left(\tilde{I}_v^{r,(k)},\, \tilde{I}_v^{gt,(k)}\right), \quad \mathcal{L}_{\text{3DGS}} = \mathcal{L}_1 + \mathcal{L}_{\text{ssim}} $$ (式 4, 1<k<K)

标准 3DGS 组合损失(L1 + SSIM),作用于 masked 图像(distractor 区域被零化)。

6.3 Reconstruction Phase:恢复精细画质(式 6-7)

为何需要专门的重建阶段

经过 3 轮过滤,已得到几何稳定、基本无干扰的高斯,但为优先抗干扰牺牲了纹理、颜色的精细度。Phase 4 专门用于恢复高保真外观细节:

  • 不重新 SfM:直接沿用第三轮过滤的最终高斯参数作为起点,完整保留已提纯的几何结构;
  • 恢复标准 3DGS 损失(L1+SSIM 组合),优化纹理、阴影、颜色渐变等精细外观,同时重新初始化高阶球谐系数,释放外观优化空间;
  • 保留最后一轮的 mask,持续屏蔽干扰区域,防止优化过程中干扰信号重新激活、伪影复发。
$$ \tilde{I}_v^{gt,\star} = M_v^\star \odot I_v^{gt}, \quad \tilde{I}_v^{r,\star} = M_v^\star \odot I_v^{r}(\Theta^{(K)}) $$ $$ \mathcal{L}_{\text{rec}} \;=\; \sum_{v \in \mathcal{V}} \mathcal{L}_{\text{3DGS}}\!\left(\tilde{I}_v^{r,\star},\, \tilde{I}_v^{gt,\star}\right) $$ (式 6-7)

用 $M_v^\star$(来自 $k=K-1$ 的最终 mask)防止 distractor 复活,同时恢复细粒度外观。

6.4 稀疏颜色更新(Sparse Color Updates,式 5)

$$ \Theta_{\text{color}}^{t,k} \;\leftarrow\; \begin{cases} \Theta_{\text{color}}^{t,k} - \eta\,\nabla_{\Theta_{\text{color}}^{t,k}} \mathcal{L}_{\text{filter}}^{(k)}, & t \bmod N = 0 \\[3pt] \Theta_{\text{color}}^{t,k}, & \text{otherwise} \end{cases} $$ (式 5)

几何与 opacity 参数每步都更新;只有 color(SH 系数)每 N 步更新一次。动机:SfM 初始化的高斯颜色本就跨视角稳定,频繁 color 更新会让高斯漂移到单视角 transient 外观;稀疏更新维持多视角一致性。

作用范围

稀疏颜色更新仅在 filtering 阶段(1 ≤ k < K)生效;reconstruction 阶段每步都更新 color,以便充分恢复细粒度外观(代码 train.py:191:if phase != num_phases and ...)。

无额外正则化

论文未引入任何显式正则化(无 TV、无 opacity 正则、无 scale 正则、无 anchor loss)。所有鲁棒性都通过四机制隐式实现:(1) 多阶段迭代;(2) mask;(3) 稀疏 color 更新;(4) 结构损失。这点在代码中亦得到证实——train.py 损失段无任何 reg 项。

11代码实现 vs 论文叙述(源码佐证)

本节是知识库特色分析:克隆 kangrnin/PDF-GS 仓库,对照 train.py 与 utils/mask_utils.py,检验论文"宣称 vs 实现"差异。

11.1 sim_thr 方向:看似矛盾,实为等价 ★

论文式 2 用 L2 距离 $D$ + 阈值 $\tau_k$,keep if $D \leq \tau_k$,称"递减 τ_k"。

代码 train.py:26-27 用 余弦相似度:cos = cosine_similarity(gt_feat, prev_feat);clean = (cos >= sim_thr)。README 默认 --sim_thr 0.6 0.7 0.8(递增)。

两者等价:归一化特征下 $\|x-y\|^2 = 2 - 2\cos(x,y)$,递增相似度阈值 = 递减距离阈值。子代理初读时误判为矛盾,实为同一策略的两种数学表述。

11.2 phase 内 mask 累积相乘(论文未述)★

论文只描述 phase 间 mask 演进。代码 train.py:132-135:

prev = prev_mask_dict.get(viewpoint_cam.image_name)
if prev is not None:
    clean_mask = clean_mask * prev.to(clean_mask.device)
prev_mask_dict[viewpoint_cam.image_name] = clean_mask.detach().cpu()

同一 phase 内每次访问相机,新 mask 与历史累积 mask 相乘。乘积=交集,clean 区域只缩不涨——过滤在单 phase 内也渐进收紧。这是论文未明示但实质影响行为的关键细节。

11.3 损失重缩放作用于所有 phase(非仅 phase 1)

论文称 phase 1 的结构损失"量级对齐到标准 3DGS 损失"。但代码 train.py:143-146 显示重缩放作用于所有 phase:

dssim = 1.0 if phase == 1 else 0.2
loss = (1.0 - dssim) * Ll1 + dssim * (1.0 - ssim_value)
loss_dssim_default = 0.8 * Ll1 + 0.2 * (1.0 - ssim_value)
loss = loss * (loss_dssim_default.item() / max(loss.item(), 1e-8))

phase 1: dssim=1.0 → 纯 SSIM(符合论文);phase 2+: dssim=0.2 → 标准 3DGS 权重(0.8 L1 + 0.2 SSIM)。最后用 .item() 标量缩放梯度量级。

11.4 reconstruction 阶段致密化只跑半程

代码 train.py:314-315:if phase == args.num_phases: opt.densify_until_iter = args.iter_per_phase // 2。重建阶段致密化仅在迭代前半程(5K/10K)进行,论文未述此细节——合理,因为 Θ⁽ᴷ⁻¹⁾ 已是良好初始化,无需大量致密化。

11.5 prev_model 传递控制重初始化

代码 train.py:332-333:if phase != args.num_phases - 1: prev_model = None。除 phase K-1 外,每 phase 后 prev_model 置 None → 下个 phase 从 SfM 默认初始化;仅 phase K-1 后保留 → reconstruction 阶段继承 Θ⁽ᴷ⁻¹⁾。这以最简方式实现了"filtering 重 SfM、reconstruction 继承"的非对称设计。同时 train.py:74-77 继承时重置 _features_rest(高阶 SH)= 论文所述"1 阶以上 SH 重新初始化"。

11.6 DINOv3 提取器细节

utils/mask_utils.py:DINOv3 ViT-B/16,1 CLS + 4 register tokens 前置于 patch token(_DINOV3_NUM_SPECIAL = 1 + 4)。feature_size=50 → 把图 Resize 到 $50\times16=800$ 分辨率,取 2500 个 patch token 重排为 $50\times50\times C$ 特征图。特征每 phase 提取一次(train.py:55-66),完全解耦内层循环——这是 wall-clock 反而更快的原因。

11.7 膨胀参数

train.py:31:F.max_pool2d(distractor, kernel_size=15, stride=1, padding=7)。padding=7 = kernel//2 → 膨胀半径 7 像素,与论文"膨胀 7 像素"一致。

12可改进方向分析

[高优先级] phase 内 mask 单调累积可能误杀静态区域

问题:代码 train.py:134 在 phase 内对同相机的 mask 做乘积累积,clean 区域只缩不涨。若某次迭代因 Θ 临时欠拟合导致某静态区域被误判为 distractor,该区域将被永久 mask,后续无法"翻案"。

代码佐证:prev_mask_dict 无衰减/重置机制,一旦乘进 0 就回不来。

改进:引入 EMA 累积(mask = α·new + (1-α)·prev)或 phase 内周期性重置,允许 clean 区域恢复。或设下限 mask.clamp(min=ε) 保留少量监督。

[高优先级] 关键超参未在论文公开,需读代码

问题:τ_k 各 phase 具体值、稀疏 color 更新的 N 值,论文仅用符号 $\tau_k$、$N$ 表示,无数字。读者无法仅凭论文复现,必须读 GitHub README.md 才知默认 --sim_thr 0.6 0.7 0.8、--color_update_interval 30。

改进:在论文附录显式列出各 phase 阈值表与 N 值,并给敏感性分析。当前 N=30 与 phase 1=10K 迭代的关系意味着 color 仅更新 ~333 次,该选择的影响值得交代。

[中优先级] 仅在 2 个数据集(9 场景)验证

问题:RobustNeRF(4 场景)+ On-the-go(5 场景),均为受控采集,未在大规模野外采集数据(如 KITTI、DL3DV、TankandTemples)上验证。对真正复杂的 distractor(快速运动、大面积遮挡、动态光照)是否仍鲁棒未知。

改进:增加 DL3DV-10K 等野外场景测试;或与知识库内 3DGS 鲁棒重建调研 中提到的微动人体场景结合验证。

[中优先级] 结构损失导致细节损失,依赖 reconstruction 弥补

问题:论文 §3.1.3 Remark 自承"filtering 阶段牺牲细粒度外观",需 reconstruction phase 弥补。但 reconstruction 仅 10K 迭代,且致密化只跑半程,对高频纹理恢复是否充分存疑。

改进:reconstruction 阶段可借鉴 2DGS/SuGaR 的表面先验或 Mip-Splatting 抗锯齿,提升高频细节;或动态分配各 phase 迭代数(filtering 少、reconstruction 多)。

[中优先级] DINOv3 依赖增加部署门槛

问题:默认依赖 DINOv3 ViT-B/16(HuggingFace facebook/dinov3-vitb16-pretrain-lvd1689m)。虽消融证明用 PSNR 也能跑赢 vanilla(+2.50 dB),但默认设置仍需下载预训练权重,离线/边缘部署不便。

改进:提供一个 PSNR-metric 的"零依赖"变体作为 fallback;或蒸馏一个轻量 patch 特征提取器替代 DINOv3。

[低优先级] 论文未讨论失败案例

问题:论文无专门 Limitations 章节、无失败案例。从机制推断,对大面积、慢移动、半数视角都出现的 distractor(即"接近多视角一致"的 transient),自过滤机制可能失效——因为它依赖"distractor 缺乏跨视角支持",而半数视角出现就不算"缺乏"。

改进:补充失败案例分析,明确方法的 distractor 占比上限。

个人认为最关键的三点

  1. mask 单调累积的脆弱性:这是论文未述而代码实存的机制,最可能在实际部署中产生不可逆的静态区域误杀,值得优先验证。
  2. 超参黑盒:τ_k 与 N 的具体值未公开,削弱了论文的可复现性与学术透明度。
  3. 大规模野外验证缺失:9 个受控场景不足以支撑"new state-of-the-art"的普适宣称。

13总结

PDF-GS 的核心贡献是认知层面的:它没有发明新模块,而是重新发现并放大了 3DGS 的内禀自过滤特性,通过 4 阶段渐进优化将其工程化为一个 distractor 过滤器。这种"不预测 mask、把训练本身当 filter"的范式,比 mask-predictor / 静态-瞬态分解等显式建模更轻量,且与任意 3DGS 框架即插即用。

轻量化

完全基于原生 3DGS 优化流程,无需引入额外网络模块,推理时无任何计算开销。

渐进提纯

通过多轮"检测-屏蔽-重训"循环逐层去除干扰,效果远优于单轮过滤。

鲁棒性强

重新初始化 + 结构导向损失的组合,从训练机制上避免误差累积和干扰过拟合,在真实复杂场景下表现稳定。

技术路线定位

在 3DGS 鲁棒性谱系中:SpotLessSplats(语义聚类)→ WildGaussians/RobustSplat(显式 mask predictor)→ PDF-GS(自过滤放大)。PDF-GS 代表了"化繁为简"路线——不增加模型复杂度,而是调度已有的训练过程。它与 mask-predictor 路线并非互斥(消融 A.3 证明可叠加),为后续工作提供了干净的基座。

对知识库相关工作的意义

在 3DGS 鲁棒重建调研 中,PDF-GS 被定位为"鲁棒性首选"——因为其即插即用、零推理成本,可直接挂到 3DGS 基础综述 提到的 2DGS/GaussianPro 等 baseline 上,处理肢体微动 + 生成帧不一致等 distractor 场景。
