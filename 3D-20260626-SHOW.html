1论文摘要与核心贡献

SHOW(arXiv 2606.27720,2026-06-26,UPenn GRASP Lab,Lingjie Liu 组)提出用掩码提示(mask-as-prompt)驱动的视觉几何基础模型,把「人体网格恢复(HMR)」与「前馈 3D 场景重建」耦合进统一度量空间(unified metric space)——从单目以人为中心的视频出发,一次前馈同时输出场景(相机/深度/点图)与所有人体的 SMPL-X 网格,且人体天然落在场景坐标系下、尺度一致。

核心贡献四个:

  1. 人感知几何编码:在 VGGT 基座上注入轻量 mask encoder(人体分割掩码作为提示)+ DensePose 辅助头,让几何特征「认得出人」——为下游 SMPL-X 解码提供尺度/位置线索,并使点图尺度分布与训练管线归一化约定对齐。
  2. 几何感知 SMPL-X 解码器:三 token(SMPL/scale/register)解码器,自注意力 + 与「几何特征 × 人体特征」交叉注意力 K 轮迭代;PromptHMR 人体特征 + 场景几何特征融合,ray encoder 注入焦距感知信息,直接在世界系下回归 pose/shape/translation/scale。
  3. 人景对齐联合训练:log 空间尺度监督 + 跨帧尺度一致性正则 + SMPL 引导的点图对齐损失(chamfer + stop-gradient),显式强制人体网格与场景点图在同一度量空间一致。
  4. 人景一致性评价新指标:HS-CF(人体-点图归一化倒角)与 HS-V(水平/垂直方差 ℓ1 距离),配合百分位截断(5%/10%),首次把「人-景对齐质量」变成可量化、可复现的基准。
一句话定位:Human3R/UniSH 把「人」和「景」各自重建完再拼接对齐,SHOW 让一个模型在前馈中「同时看见」两者——场景几何约束人体尺度/位置,人体先验反过来规整场景点图,彼此互为监督。

2研究动机:人景分离重建的失败模式

论文开篇论点:现实中人动作改变环境、环境影响行为,人与场景共存于同一物理世界,其空间/物理关系是理解人类行为的基础(AR/VR、游戏、机器人)。但既有管线大多把人与场景当两个独立目标分别估计,再事后对齐到公共坐标系——这条「先分后合」路线有三个结构性失败模式:

失败模式一:脆弱的定位线索

依赖启发式 body anchor、检测框估计或 post-hoc 对齐。Human3R 靠头部检测定位人——头被遮挡或姿势怪异时直接预测失败;UniSH 靠bbox 提示——多人紧密交互时框互相重叠无法消歧。

失败模式二:场景只当辅助上下文

场景几何没有作为人体重建的主动约束。人/景各自看着都合理,放到一起尺度、位置、物理交互对不上——尤其是单目视频,深度/尺度歧义让「身体是否放对了地方」无从判断。

失败模式三:尺度系不统一

视觉几何模型(如 VGGT)的点图按自身归一化约定输出,与 SMPL-X 人体模型的度量尺度不匹配;直接拿原始 VGGT 特征引导人体尺度/位置估计,尺度恢复困难(消融:w/o pretrain alignment HS-CF₅ 从 9.44 恶化到 38.51)。

关键假设:分割掩码(而非检测框/头部位置)是最鲁棒的人体定位提示——遮挡、部分可见、多人重叠下依然保持实例区分度;且基础模型的几何先验可以被「人体语义」调制,使场景点图带上度量可对齐的人体线索。

假设失效条件:①掩码本身质量差(SAM 分割失败/漏检)时提示失效;②人体在画面中占比极小或尺度极端变化时(论文 Limitation 自认),掩码提示的像素证据不足;③真实域与合成训练域(BEDLAM2.0)差异过大时,sim-to-real 鸿沟显现。

5Stage 1:人感知几何编码

动机:VGGT 的隐特征为通用几何重建优化,预测的深度/点图不必与真实世界尺度或人体模型尺度对齐——原始特征直接引导人体尺度/位置估计会失配。解法是让几何编码「保留人体相关线索」。

5.1 掩码编码器与特征融合

对每帧 $I_t$ 先用现成分割模型(SAM2/SAM3)取人体前景掩码 $M_t$,经轻量 mask encoder 编码:

$$F_{t}^{m}=E_{msk}(M_{t})$$Eq.1

并行地,VGGT 编码器提取几何特征:

$$F_{t}^{g}=E_{geo}(I_{t})$$Eq.2

经适配模块 $A$ 融合为人感知几何特征:

$$\tilde{F}_{t}^{g}=A(F_{t}^{g},F_{t}^{m})$$Eq.3

$\tilde{F}_t^g$ 用于深度/点图预测,并传给 SMPL-X 解码器作为场景级线索。源码印证(vggt/models/mask_encoder.py):MaskEncoder 采用 SAM 式 mask_downscaling(mask_in_chans=16,四层 MLP + zero_conv 输出),适配用 FQSimpleAdapter——与论文 Eq.1-3 一一对应。

5.2 DensePose 辅助监督

Stage 1 在 VGGT 头侧加 DensePose 辅助头,以 smplx_densepose.npz UV 映射(仓库自带)把 SMPL-X 顶点映射到 DensePose 24 部位标签作监督,鼓励几何特征「认出人体区域」——不直接输出人体,只让特征带上人体语义。

5.3 训练配置(源码实测)

exp_44_pretrain_with_projected_depth_dpt_VGGT_feature.yaml:VGGT-1B 初始化,stage: "pretrain",enable_densepose: True,enable_vggt_mask_encoder: True,enable_smplx: False(SMPL-X 分支关闭);损失为 camera(w=5, l1)+ depth(w=1)+ point(w=1)+ mask_supervision(w=1)+ densepose(w=1);frozen_module_names: ["*camera_head*"](相机头冻结);AdamW lr=5e-5, wd=0.05, cosine 衰减,bf16 AMP,4×B200,100 epochs,checkpoint save_freq=5。

源码细节:mask 特征注入方式历经迭代——exp_42 用 mask 预训练、exp_43 试 geometry token,最终 exp_44 定稿「projected depth DPT + VGGT feature」recipe(cmd.txt 记录了演进链)。发版 README 明确说 configs 中的 resume 路径是作者自己 run 的续训路径,复现时 Stage 1 应从 VGGT-1B model.pt 起步(strict: False 跨架构加载)。

6Stage 2:几何感知 SMPL-X 解码

6.1 解码器架构:三 token 设计

解码器以三个可学习 token 为查询——SMPL token(携带人体参数先验)、scale token(尺度)、register token(辅助寄存),与「加了位置编码的几何 patch 特征 × 人体 patch 特征」做 K 轮「自注意力 → 交叉注意力」迭代:

$$q^{K}_{smpl},q^{K}_{scale} = \mathrm{TransformerDecoder}(\{q_{smpl},q_{scale},q_{reg}\},\ \mathrm{PE}(F^{geo})\otimes F^{hmr},\ K)$$Eq.7-11 要义

输出头分离:SMPL 头预测 pose/shape/translation,几何头预测 scale。论文图 3 给出架构示意(本库配图 decoder.svg)。

图3(论文 Figure 3):SMPL-X 解码器。SMPL/scale/register 三 token 经 K 次自注意力与交叉注意力(与加位置编码的几何/人体特征),更新后送入 MLP 预测 scale、pose、shape、translation。

6.2 源码印证:三 token 实测

vggt/phmr/smpl_decoder_phmr.py 实测:smpl_token=nn.Embedding(2),scale_token=nn.Embedding(1),loc_token 独立;heads 分立——pose(22×6D)、shape(10)、transl(2)、depth(1)、scale(1, softplus 激活);decode_transl 用 cam_int[:,0,0](预测焦距)做归一(呼应附录 B Eq.21);_share_scale_token_across_frames 同一人跨帧共享 scale token——三 token 设计与论文 Eq.7-11 完全吻合。

6.3 ray encoder:焦距感知注入

视觉几何基座在大规模数据上训练,能准确估计相机内参。ray encoder 利用这一点,把 intrinsic-aware 信息注入人体分支,确保场景分支与人体分支共享同一套相机内参——消融显示去掉 ray encoder 后 HS-V₅ 从 0.028 恶化到 0.734(最严重的单项退化),是「人体分支吃透场景相机几何」的关键。

6.4 Stage 2 训练目标

第二阶段冻结人感知几何编码器,只训 SMPL-X 解码器,用标准人体重建损失:

$$\mathcal{L}_{\mathrm{hmr}}=\lambda_{2d}\mathcal{L}_{2d}+\lambda_{3d}\mathcal{L}_{3d}+\lambda_{smpl}\mathcal{L}_{smpl}+\lambda_{v}\mathcal{L}_{v}+\lambda_{\tau}\mathcal{L}_{\tau}+\lambda_{s}\mathcal{L}_{s}$$Eq.12

本阶段教会解码器从「人体特征 + 几何特征」恢复 pose/shape/translation/scale;与场景的一致性留给下一阶段。源码实测(training/loss.py compute_smplx_loss + exp_45/46 yaml):loss_joints_2d ×50、loss_joints_3d ×5、loss_smplx_param ×1、loss_vertices_3d ×1、loss_smplx_transl ×10、loss_scale ×10;exp_45 冻结 aggregator/camera/point/depth/image/prompt 各头只训解码器;2×B200,100 epochs。

7Stage 3:人景对齐联合训练

前两阶段后,几何编码器给出人感知场景特征、解码器能从人+场景线索出人体,但分开学不保证人体网格与预测点图一致。最终阶段联合微调,显式对齐三者:归一化点图 × 预测尺度 × 人体表面。

7.1 尺度与放置一致性

解码器预测 $\hat{s}_{t,i}$(重缩放归一化点图至人体尺度)与 $\hat{\tau}_{t,i}$(世界系放置)。尺度在 log 空间监督:

$$\mathcal{L}_{\mathrm{scale}}=\left\|\log\hat{s}_{t,i}-\log s_{t,i}^{*}\right\|_{2}^{2}$$Eq.13

7.2 时序尺度一致性

视频里同一个人跨帧尺度应稳定——正则化预测尺度趋向其序列级均值:

$$\bar{s}_{i}=\frac{1}{|\mathcal{T}_{i}|}\sum_{t\in\mathcal{T}_{i}}\hat{s}_{t,i},\qquad \mathcal{L}_{\mathrm{temp}}=\sum_{t\in\mathcal{T}_{i}}\left\|\log\hat{s}_{t,i}-\log\bar{s}_{i}\right\|_{2}^{2}$$Eq.14/15

其中 $\mathcal{T}_i$ 为实例 $i$ 出现的帧集合。源码印证(training/loss.py):loss_scale_supervised = F.l1_loss(log(pred), log(gt)) + 0.2 × loss_scale_consistency(跨帧一致性权重 0.2),与 Eq.13/15 呼应;另 loss.py:845 有 gamma=0.6 # temporal decay weight 用于多阶段时序衰减。

7.3 SMPL 引导的点图对齐

除了尺度,还用重建人体表面规整人体区域的点图几何。点图是归一化尺度的,先用预测尺度重缩放人体区域:

$$\hat{\mathbf{P}}_{t,i}^{h}=\hat{s}_{t,i}\,\hat{\bar{\mathbf{P}}}_{t}[m_{t,i}]$$Eq.16

渲染预测 SMPL-X 网格取可见表面点 $\hat{V}_{t,i}^{vis}$;因可见性操作不可微,对其 detach(stop-gradient),再算 chamfer:

$$\mathcal{L}_{\mathrm{align}}=\mathcal{D}_{chamfer}\left(\hat{\mathbf{P}}_{t,i}^{h},\ \mathrm{sg}(\hat{V}_{t,i}^{\mathrm{vis}})\right)$$Eq.17

该损失把重缩放后的点图几何拉向 detach 的人体表面,鼓励人体区域点图与 SMPL-X 体兼容。源码印证(training/loss.py compute_chamfer_distance):SMPL 顶点与深度图点乘尺度,注释明确 no gradient for smplx branch——stop-gradient 方向与论文一致(梯度流向点图分支)。

论文-代码差异(重要):发布代码中 loss_chamfer 的主调用与 10× 权重在 loss.py:141,290 处于注释状态(compute_chamfer_distance 全仓库仅定义未启用)——最终发布版把 Eq.17 的对齐角色交给了 10×loss_scale + Stage 1 的 backbone 尺度分布对齐 + e2e 微调。复现论文 Table 4 数字时需注意:paper 表格可能对应含 chamfer 的内部版本,开源版用 scale 监督替代,二者不等价。

7.4 联合微调目标

$$\mathcal{L}_{\mathrm{total}}=\mathcal{L}_{\mathrm{geo}}+\mathcal{L}_{\mathrm{hmr}}+\lambda_{\mathrm{scale}}\mathcal{L}_{\mathrm{scale}}+\lambda_{\mathrm{temp}}\mathcal{L}_{\mathrm{temp}}+\lambda_{\mathrm{align}}\mathcal{L}_{\mathrm{align}}$$Eq.18

Stage 3(对应 exp_46 full_params 配置)放开所有模块联合微调(仅 camera_head/image_encoder/prompt_encoder/cam_encoder 冻结),4×B200 再训 200 epochs——论文主表数字即此设定。消融表中 full+e2e tuning(HS-CF₅ 9.44→6.21)证明了最后这步联合微调的价值。

8附录 B:位置参数化与焦距归一

在相机空间回归人体位置比在裁剪图像空间难得多,SHOW 不直接回归 $\tau$,而是回归焦距归一的 2D 平移 $p_{xy}\in\mathbb{R}^2$ 与逆深度 $p_z\in\mathbb{R}$,再变换:

$$t_{xy}=\frac{p_{xy}}{p_{z}},\qquad t_{z}=\frac{1}{p_{z}}\times\frac{f}{f_{c}},\qquad \tau=[t_{xy},t_z]$$Eq.21

$f$ 为图像 ground-truth 或估计焦距,$f_c$ 为规范焦距。预测归一化逆深度沿袭单目深度文献(Ranftl et al. 2022)——逆深度与人在图像中的大小线性相关,直觉友好;$p_{xy}$ 等价于归一化像平面上的人体 2D 位置。源码印证(smpl_decoder_phmr.py):transl 头只出 2 维 + depth 头 1 维,decode_transl 用 cam_int[:,0,0] 焦距恢复 $\tau$,与 Eq.21 逐项对应。

12人景一致性新指标与结果

12.1 指标定义(附录 A)

场景以最一般形式表示为点云(图像/点图分辨率可变、含无效点),统一用 N×3 点云表示;人体侧渲染网格到相机系得点图。两指标都在过滤后的点云间计算(去外点/无效点),公式:

$$\text{HS-CF}=\frac{\sum_{i=1}^{N}\min_{p\in\mathcal{S}}\|h_{i}-p\|_{2}}{\sum_{i=1}^{N}|z_{i}^{\text{human}}-\bar{z}^{\text{human}}|}$$Eq.19

分子:人体模型可见点集 $\mathcal{H}=\{h_i\}$ 到场景点集 $\mathcal{S}$(人体掩码下场景点图)的单向倒角和;分母:人体点 $z$ 坐标偏差绝对值之和(深度方向展布)——归一化掉场景深度量纲。低 HS-CF = 可见人体表面与场景点云空间对齐好。

$$\mathrm{HS\text{-}V}=\frac{1}{2}\left(\left|\mathrm{Var}_{x}(\mathcal{V}_{h})-\mathrm{Var}_{x}(\mathcal{P}_{h})\right|+\left|\mathrm{Var}_{y}(\mathcal{V}_{h})-\mathrm{Var}_{y}(\mathcal{P}_{h})\right|\right)$$Eq.20

人体模型点 $\mathcal{V}_h$ 与人体点图 $\mathcal{P}_h$ 在相机系 x/y 轴方差的 ℓ1 距离取半。低 HS-V = 人体模型尺度合理、与场景点图一致;高 HS-V = 尺度失衡(人显得不现实地小/大)。

为压制边界外点与不完美掩码的误差,只保留 5%–95% / 10%–90% 百分位内的点 → $HS\text{-}CF_5$、$HS\text{-}V_5$、$HS\text{-}CF_{10}$、$HS\text{-}V_{10}$ 四个变体。指标天然可扩展到其它参数化表示(刚体/铰接/软体)。

13.2 逐项解读

  • 预训练对齐(最大坑):训练中每步把预测点图归一化(如单位均值),这是 scale 分支的尺度约定;未在 BEDLAM 上微调的 VGGT 输出的点图是另一套尺度分布 → 骨干输出与 scale 分支不一致,尺度恢复失败(38.51 vs 9.44,4× 恶化)。这解释了为什么 Stage 1 必须微调骨干而不能直接用 VGGT-1B。
  • 联合建模:去掉人体分支改从骨干语义直接估尺度,HS-CF 17.32——SMPL-X 参数先验对尺度/放置的贡献不可替代。
  • 掩码提示:HS-CF 14.12(掉 50%)但不灾难性——几何特征仍可从图像内容「猜」人体区域,只是不精准。
  • ray encoder:HS-V 崩到 0.734——没有焦距感知,人体分支与场景分支「各看各的相机」,尺度方差失控;注意它对 HS-CF 影响相对小(11.23),说明 ray encoder 主要救的是尺度而非位置。
  • e2e 微调:150 ep 分段训练后再 100 ep 端到端,HS-CF 9.44→6.21——联合微调把分段训练损失的耦合收益兑现。

16局限、演进定位与改进方向

16.1 论文自认局限

  • sim-to-real 鸿沟:虽在大规模合成人-景数据上训练,难泛化的真实世界场景仍在——OOD 情形(极端尺度变化、人体只占画面极小部分)依然棘手。

16.2 笔记补充的观察

  • 静相机场景吃亏:RICH 上全面落后 GVHMR——视觉几何模型的红利在动相机/多视角,静相机单目输入下 SHOW 的「统一空间」优势发挥不出来。
  • 局部精度让位于统一性:3DPW PA 41.0 不敌纯裁剪 SOTA(NLF 37.3 / PromptHMR 36.6)——世界系联合任务天然更难,目标函数分散了局部姿态的优化压力。
  • 三阶段训练重:100+100+200 epochs、两档卡型切换(4×B200↔2×B200),复现门槛高;UniSH 式「冻结+轻对齐」虽弱但便宜,工程取舍不同。

16.3 改进方向

  • 补真实数据微调闭环 sim-to-real(论文没做;HS-CF/HS-V 指标可直接当真实域评测器)。
  • 恢复/重估 chamfer 对齐损失:发布版注释掉 Eq.17 用 10×scale 替代,二者理论上不等价(一个管分布对齐一个管点级贴合),系统对比后择优或叠加。
  • 多人实例扩展:当前推理 --human_idx 单人输出;mask 提示天然支持多实例,解码器 batch 化即可,是显然的下一步。
  • 动态场景:点图是每帧独立预测,无 4D 一致性约束——与人-景时序联合(如 PERSIST 式持久状态)结合是开放方向。

  • 直接建立在 VGGT 之上——VGGT 提供几何基座与多任务头框架,SHOW 是「VGGT + 人体」的第一篇完整系统工作(把 VGGT 笔记里的「下游任务扩展」预言兑现到人-景统一)。库内 VGGT-Omega、Pi3(UniSH 的基座)、ReSplat 同属前馈几何家族,可对照看「基座改造 vs 冻结」的路线分歧。
  • 与 高斯人物与人脸重建调研、微动人体三维重建调研 构成「人体重建」主线:SHOW 补上了「单目前馈 + 世界系放置」这一格,与 vggt_human 多 session 人体重建管线(SAM3 mask ID 映射、3DGS 拆分)的哲学呼应——都是把「人」当场景中的一等公民而非孤立目标。
  • HS-CF / HS-V 指标对 R2MBench 类重建评测工作有直接借鉴价值:人-景一致性此前缺乏量化基准,SHOW 给出了可复用的公式与百分位截断协议。
  • SAM 掩码提示路线与 SAM-3D-Body、Fast-SAM-3D-Body 同源——掩码作为最鲁棒的人体定位提示,在这几篇里反复得到验证。
总结:SHOW 用「掩码提示 + 骨干微调 + 三损失联合对齐」把 HMR 与前馈场景重建焊进同一个度量空间,以 EMDB-2 WA 109.1 / HS-CF₅ 5.69 / HS-V₅ 0.030 的三好成绩证明了统一建模的代价可控、收益真实;新指标 HS-CF/HS-V 填补了人-景一致性评测的空白,预计会成为后续 4D 人-景重建工作的标配基准。
